## `return 1`, `return 2` என்றால் என்ன?

---

## OS-க்கு Signal!

`main()` return பண்றது **Operating System-க்கு** போகும்:

```cpp
return 0;   // Success — எல்லாம் சரி ✅
return 1;   // Error — ஏதோ தப்பு ❌
return 2;   // Different error — வேற problem ❌
```

---

## OS என்ன பண்ணும்?

```bash
./calculator
echo $?      # return value பார்க்கும்

0  → success
1  → error
2  → unknown exception
```

---

## இந்த Code-ல:

```cpp
catch (std::exception& e) {
    std::cerr << "Error: " << e.what() << '\n';
    return 1;   // "known error வந்தது" — OS-க்கு சொல்லுது
}

catch (...) {
    std::cerr << "Unknown exception\n";
    return 2;   // "unknown error வந்தது" — வேற signal
}
```

---

## Real-world Use — Scripts-ல

```bash
#!/bin/bash
./calculator
if [ $? -eq 0 ]; then
    echo "Calculator worked!"
elif [ $? -eq 1 ]; then
    echo "Known error!"
elif [ $? -eq 2 ]; then
    echo "Unknown crash!"
fi
```

---

## Convention

| Return Value | அர்த்தம் |
|---|---|
| `0` | Success |
| `1` | General error |
| `2` | Misuse / Unknown |
| `127` | Command not found |

---

**Simple rule:**

> `return 0/1/2` = OS-க்கு exit code. `0` = success, non-zero = error. Shell scripts இந்த value பார்த்து "program success-ஆ fail-ஆ" decide பண்ணும். User-க்கு directly தெரியாது — OS/scripts-க்கு signal!
