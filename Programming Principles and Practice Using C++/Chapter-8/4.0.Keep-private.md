இந்த **§8.4.3 Keep details private**-ல் Stroustrup OOP-இன் மிக முக்கியமான கருத்தான **Encapsulation**-ஐ அறிமுகப்படுத்துகிறார்.

முக்கிய message:

> **"Object-ன் data-வை எல்லாரும் நேரடியாக மாற்ற முடியாதபடி மறைத்து வையுங்கள்."**

---

# Previous Design Problem

நம்மிடம் இருந்தது:

```cpp
struct Date
{
    int y;
    int m;
    int d;

    Date(int y, int m, int d);
    void add_day(int n);
};
```

இதில்:

```cpp
Date birthday{1960,12,31};

++birthday.d;
```

Compiler:

```text
No Error
```

---

Result:

```text
32/12/1960
```

Calendar-ல் அப்படி ஒரு நாள் இல்லை.

ஆனால் compiler-க்கு தெரியாது.

ஏன்?

ஏனெனில்:

```cpp
d
```

public member.

# Another Dangerous Example

```cpp
Date today{1924,2,3};

today.m = 14;
```

Result:

```text
3/14/1924
```

14th month இல்லை.

---

ஆனால் compiler:

```text
No Error
```

# Why This Happens?

Because:

```cpp
today.y
today.m
today.d
```

எல்லாம் public.

யாரும் எப்போது வேண்டுமானாலும் மாற்றலாம்.

---

# Stroustrup's Solution

Representation hide செய்ய வேண்டும்.

# First Class Version

```cpp
class Date
{
    int y;
    int m;
    int d;

    Date(int y, int m, int d);

    void add_day(int n);

    int month()
    {
        return m;
    }

    int day()

        return d;
    }

    int year()
```


are before:

```cpp
class Date
```

# Complete Book-Oriented Example

```cpp
#include <iostream>
#include <stdexcept>

class Date
{
private:
    int y;
    int m;
    int d;

public:
    Date(int year, int month, int day)
    {
        if(month < 1 || month > 12)
            throw std::runtime_error("invalid month");

        if(day < 1 || day > 31)
            throw std::runtime_error("invalid day");

        y = year;
        m = month;
        d = day;
    }

    int year()
    {
        return y;
    }

    int month()
    {
        return m;
    }

    int day()
    {
        return d;
    }

    void add_day(int n)
    {
        d += n;
    }
};

int main()
{
    Date birthday{1970,12,30};

    std::cout
        << birthday.day() << '/'
        << birthday.month() << '/'
        << birthday.year()
        << '\n';
}
```

Output:

```text
30/12/1970
```

# Invariant (Very Important)

Stroustrup introduces:

> Invariant

---

Invariant means:

```text
Rule that must always remain true
```

---

Example:

For Date:

```text
1 <= month <= 12

1 <= day <= valid days of month
```

must always be true.

---

Valid:

```text
24/12/2025
01/01/2026
29/02/2000
```

---

Invalid:

```text
32/12/2025
14/05/2025
31/02/2025
```

---

These violate the invariant.

---

# Why Private Helps

Suppose:

```cpp
Date d{2025,12,24};
```

Constructor validates.

After creation:

```cpp
d.m = 99;
```

not allowed.

Therefore:

```text
valid object
     ↓
still valid
     ↓
still valid
```

# Real-Life Example: Bank Account

Bad design:

```cpp
struct BankAccount
{
    int balance;
};
```

User can do:

```cpp
account.balance = -500000;
```

---

Good design:

```cpp
class BankAccount
{
private:
    int balance;

public:
    void deposit(int amount);
    void withdraw(int amount);
};
```

Now balance changes only through safe operations.

# When Should You Use struct?

Stroustrup says:

If there is **no meaningful invariant**, use struct.

Example:

```cpp
struct Point
{
    int x;
    int y;
};
```

Any x,y values are acceptable.

---

```cpp
Point p;

p.x = 100;
p.y = -200;
```

Nothing invalid.

---

So struct is fine.

---

# When Should You Use class?

When validity matters.

Examples:

```cpp
Date
BankAccount
Student
Temperature
FileHandle
NetworkConnection
```

These have rules.

Therefore:

```cpp
private data
+
public operations
```

# Core Lesson of §8.4.3

Stroustrup is evolving:

```cpp
struct Date
{
    int y;
    int m;
    int d;
};
```

↓

```cpp
class Date
{
private:
    int y;
    int m;
    int d;

public:
    Date(...);

    int day();
    int month();
    int year();

    void add_day(...);
};
```

The goal is:

```text
Hide representation
Protect invariants
Prevent invalid states
Force users through safe operations
```

இதுதான் professional C++ class design-ன் அடிப்படை.
