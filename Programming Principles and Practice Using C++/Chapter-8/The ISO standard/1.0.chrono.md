## `December / 16 / 1770` — step by step:

### C++ இதை இப்படி படிக்கும்:

```cpp
// Left to right evaluate ஆகும்:
(December / 16) / 1770
```

---

### Step 1 — `December / 16`:

```cpp
// December என்பது:
constexpr month December {12};

// இது call ஆகும்:
constexpr month_day operator/(month m, int d)

// return:
month_day { month{12}, day{16} }
```

```
result → month_day object (temp)
```

---

### Step 2 — `month_day{...} / 1770`:

```cpp
// Step 1-இன் result month_day — அதை இது பிடிக்கும்:
constexpr year_month_day operator/(month_day md, int y)

// return:
year_month_day { year{1770}, month{12}, day{16} }
```

```
result → year_month_day object
```

---

### `auto` என்ன அடையாளம் கண்டுகொள்ளும்:

```cpp
auto birthday = December / 16 / 1770;
//   ^^^^^^^^
//   compiler பார்க்கும்:
//   operator/ return type என்ன? → year_month_day
//   அதனால் auto = year_month_day
```

**Compiler தானாகவே type கண்டுபிடிக்கும் — நீங்கள் சொல்ல வேண்டாம்!**

---

### சுருக்கமா:

```
December / 16         → operator#1 → month_day    (temp)
month_day / 1770      → operator#2 → year_month_day

auto birthday = year_month_day{1770, 12, 16}
```

> **`auto` = return type-ஐ compiler-ே கண்டுபிடிக்கும்** — இங்கே `year_month_day` என்று தெரிந்துகொள்ளும்!

-----------------

`அதாவது `December / 16   ` operator முன்னாள் இருப்பது மட்டும் கால் ஆகுமா?`

ஆமா! அதுதான் C++ operator overloading-இன் rule!

---

### Operator எப்படி match ஆகும்:

```cpp
December / 16
```

Compiler பார்க்கும்:
```
Left side  : December → type = month
Right side : 16       → type = int

எந்த operator/ இருக்கு month, int-க்கு? → இது!
constexpr month_day operator/(month m, int d)  ✅
```

---

### இரண்டாவது operator ஏன் call ஆகவில்லை:

```cpp
// இது match ஆகாது:
constexpr year_month_day operator/(month_day md, int y)
//                                 ^^^^^^^^^
//                                 left side month_day வேணும்
//                                 ஆனால் December = month — match இல்லை! ❌
```

---

### Simple rule:

```
operator/(A, B) → A-இன் type, B-இன் type பார்க்கும்

December / 16   → month    / int → operator#1 ✅
month_day / 1770 → month_day / int → operator#2 ✅
```

---

### இப்படி நினைச்சுக்கோங்க:

```
December / 16 / 1770

= (December / 16)      / 1770
=  month / int            ↓
=  month_day          / int
=  year_month_day
```

> **Left side-இன் type மட்டும் தான் எந்த operator call ஆகும் என்று decide பண்ணும்!**

--------------------------

```
birthday object — memory-ல் இப்படி இருக்கும்:

base address: 6000
┌─────────┬─────────┬─────────┐
│  1770   │   12    │   16    │
│  year y │ month m │  day d  │
│ base+0  │ base+4  │ base+8  │
└─────────┴─────────┴─────────┘
```

```
y.get() call:
→ base + 0 → 1770 read → return 1770

m.get() call:
→ base + 4 → 12 read   → return 12

d.get() call:
→ base + 8 → 16 read   → return 16
```

```

```

---

### Temp object உருவாகுமா?

```
y.get() → ❌ temp இல்லை — already living member
m.get() → ❌ temp இல்லை — already living member
d.get() → ❌ temp இல்லை — already living member
```

> **`birthday` already memory-ல் உயிரோடு இருக்கு** — `print()` call ஆகும்போது base + offset மட்டும் படிக்கும், புதுசா எதுவும் உருவாகாது!

## `auto` உள்ளே என்ன இருக்கு:

### Trace பண்ணுவோம்:

```cpp
// Step 1:
December / 16
// operator/(month, int) call → return type = month_day
// result: month_day{ month{12}, day{16} }

// Step 2:
month_day{12,16} / 1770
// operator/(month_day, int) call → return type = year_month_day
// result: year_month_day{ year{1770}, month{12}, day{16} }
```

---

### Final — auto உள்ளே:

```cpp
auto birthday = year_month_day{ year{1770}, month{12}, day{16} };
//   ^^^^^^^^
//   type = year_month_day
```

---

### Memory-ல்:

```
birthday (year_month_day object):

┌─────────┬─────────┬─────────┐
│  1770   │   12    │   16    │
│  year y │ month m │  day d  │
│ base+0  │ base+4  │ base+8  │
└─────────┴─────────┴─────────┘
```

---

### Verify பண்ண:

```cpp
// இப்படி எழுதினாலும் same result:
year_month_day birthday = December / 16 / 1770;

// auto என்பது compiler-ே type கண்டுபிடிக்கும்
// உள்ளே year_month_day தான் இருக்கு!
```

> **`auto` = `year_month_day`** — compiler operator/ -இன் return type பார்த்து தானாகவே கண்டுபிடித்தது!

`sys_days பற்றி சொல்லு ?`


## `sys_days` என்றால் என்ன:

### Code பாருங்க:

```cpp
class sys_days {
private:
    long long total_days;

public:
    explicit sys_days(long long d = 0)
        : total_days(d) {
    }

    sys_days& operator+=(days d) {
        total_days += d.count();
        return *this;
    }

    void print() const {
        std::cout << "stored days : " << total_days << '\n';
    }
};
```

---

### இது என்ன செய்யும்:

**நாட்களை ஒரே ஒரு number-ஆக store செய்யும்.**

Real `std::chrono`-ல் இது 1970 Jan 1 முதல் எத்தனை நாட்கள் என்று count செய்யும் — இங்கே simplified version.

---

### Main-ல் என்ன நடக்கிறது:

```cpp
// Step 1 — 100 நாட்கள் வச்சு create பண்ணு
sys_days day_point(100);
day_point.print();
// output: stored days : 100
```

```cpp
// Step 2 — 7 நாட்கள் கூட்டு
day_point += days{7};
day_point.print();
// output: stored days : 107
```

---

### `operator+=` உள்ளே என்ன நடக்கும்:

```cpp
sys_days& operator+=(days d) {
    total_days += d.count();  // 100 + 7 = 107
    return *this;             // same object return
}
```

```
days{7} → d.count() → 7
total_days = 100 + 7 = 107
```

---

### `return *this` ஏன்:

```cpp
// இப்படி chain பண்ண உதவும்:
day_point += days{7} += days{3};
//           ^^^^^^^^   ^^^^^^^^
//           same object return ஆவதால் chain possible
```

---

### Memory-ல்:

```
day_point object:
┌──────────────────┐
│   total_days     │
│   100 → 107      │
│   8 bytes        │
└──────────────────┘
```

> **`sys_days` = நாட்களை எண்ணிக்கையாக store செய்து, கூட்டல் கழித்தல் பண்ண உதவும் simple wrapper class!**

---------------------

`constructor call `class sys_days {

private:

    long long total_days;

public:

    explicit sys_days(
        long long d = 0
    )
        : total_days(d) {
    }` 0 அசைன் செய்யப்பட்டுள்ளது?`

    ஆமா! அது **default argument**!

---

### என்னன்னா:

```cpp
explicit sys_days(long long d = 0)
//                             ^^^
//                             நீ value கொடுக்கலைன்னா
//                             automatically 0 use ஆகும்
```

---

### எப்படி வேலை செய்யும்:

```cpp
// value கொடுத்தால்:
sys_days day_point(100);
// d = 100 → total_days = 100

// value கொடுக்கவில்லை என்றால்:
sys_days day_point;
// d = 0 (default) → total_days = 0
```

---

### உங்கள் code-ல்:

```cpp
sys_days day_point(100);
//                 ^^^
//                 100 கொடுத்தீர்கள்
//                 default 0 use ஆகவில்லை
//                 total_days = 100
```

---

### Default argument rule:

```cpp
// கொடுத்தால்  → கொடுத்தது use ஆகும்
// கொடுக்கலை → default (0) use ஆகும்
```

> **`= 0` என்பது safety net** — value கொடுக்க மறந்தாலும் `total_days` garbage value ஆகாமல் `0` ஆக இருக்கும்!

-------------------------

`என்னுடைய கேள்வி 0 இருக்கும் இடத்தில் எப்படி 100 வந்தது 100 தன்னாலே அசைன் ஆனது?`

ஆமா! `100` தானாகவே `d`-க்கு assign ஆனது!

---

### எப்படி என்றால்:

```cpp
explicit sys_days(long long d = 0)
//                             ^^^
//                             இது default மட்டும்!
//                             நீ value கொடுத்தால் இது replace ஆகும்
```

---

### நீங்கள் call பண்ணும்போது:

```cpp
sys_days day_point(100);
```

```
நீ 100 கொடுத்தாய்
        ↓
d = 100  ← 0 replace ஆகிவிட்டது!
        ↓
total_days = 100
```

---

### Simple analogy:

```
= 0 என்பது → "யாரும் வரலைன்னா நான் இருக்கேன்"
100 என்பது → "நான் வந்துட்டேன், நீ போ!"

0 → வெளியே போகும்
100 → உள்ளே வரும்
```

---

### இரண்டு cases:

```cpp
sys_days a(100);  // d=100 → 0 replace → total_days=100
sys_days b;       // d=0 (default)     → total_days=0
```

> **`= 0` என்பது permanent value இல்லை — நீ value கொடுத்தால் அது போய் உன் value வரும், கொடுக்கலைன்னா மட்டும் 0 இருக்கும்!**

--------------------------------------

`அந்த இடத்தில் ஜீரோ போடாமல் வெறும் d மட்டும் போட்டாலே வேலை செய்யும் தானே ?`

இல்லை! வேலை செய்யாது — பாருங்க:

---

### `= 0` இல்லாமல்:

```cpp
explicit sys_days(long long d)
//                             ^^^
//                             default இல்லை!
```

```cpp
sys_days a(100);  // ✅ சரி — value கொடுத்தாய்
sys_days b;       // ❌ ERROR! — value கொடுக்கலை
```

---

### `= 0` இருந்தால்:

```cpp
explicit sys_days(long long d = 0)
```

```cpp
sys_days a(100);  // ✅ சரி — d = 100
sys_days b;       // ✅ சரி — d = 0 (default)
```

---

### உங்கள் code-ல் என்ன நடக்கும்:

```cpp
// = 0 இல்லாமல் இப்படி call பண்ணினால்:
sys_days b;
// d-க்கு என்ன போட வேண்டும்?
// compiler-க்கு தெரியாது → ERROR!
```

---

### `= 0` -இன் உண்மையான பயன்:

```
value கொடுத்தால்  → அது use ஆகும்
value கொடுக்கலை  → 0 use ஆகும் — crash இல்லை!
```

> **`= 0` என்பது "backup value"** — இல்லாமல் போனால் value கொடுக்காமல் object create பண்ண முடியாது!

--------------------------------

`அப்படின்னா இதெல்லாம் மட்டும் எப்படி வேலை செய்யுது `constexpr explicit day(unsigned d)
        : value(d) {
    }`?`


நல்ல கேள்வி! இதுல `= 0` இல்லை — அதனால்:

---

### இந்த constructor-ல்:

```cpp
constexpr explicit day(unsigned d)
    : value(d) {
}
```

**value கொடுக்காமல் call பண்ண முடியாது!**

```cpp
day d1{10};   // ✅ சரி — d = 10
day d2;       // ❌ ERROR! — value கொடுக்கலை
```

---

### ஏன் இங்கே `= 0` இல்லை:

```cpp
// day-க்கு default value என்ன போடுவது?
day d;  // value = 0? → invalid date!
        // 0 என்பது valid day இல்லை!
```

`ok()` பாருங்க:
```cpp
bool ok() const {
    return value >= 1 &&  // 0 invalid!
           value <= 31;
}
```

---

### `sys_days` ஏன் `= 0` இருக்கு:

```cpp
explicit sys_days(long long d = 0)
// 0 நாட்கள் = valid! 
// "எந்த நாளும் இல்லை" என்று அர்த்தம் — சரியானதே
```

---

### Rule:

```
default value போடுவது எப்போது?
→ "value இல்லாமல் இருந்தாலும் valid" என்றால் மட்டும்!

day   → 0 invalid date → default வேண்டாம்
sys_days → 0 valid     → default = 0 சரி
```

> **`= 0` என்பது convenience — ஆனால் எல்லா இடத்திலும் போட முடியாது, logic பொறுத்து decide ஆகும்!**

----------------------------

`அதாவது இந்த டைப் ஆஃப் braces () போடும்போது default value set செய்து கொள்ளலாம் அப்படித்தான்?`


ஆமா! சரியா புரிஞ்சீங்க!

---

### `()` உள்ளே `= value` போட்டால் default:

```cpp
// default இல்லாமல்:
explicit day(unsigned d)
// → கட்டாயம் value கொடுக்கணும்

// default இருந்தால்:
explicit sys_days(long long d = 0)
// → value கொடுக்காவிட்டாலும் 0 use ஆகும்
```

---

### இன்னும் examples:

```cpp
// ஒரு parameter-க்கு default:
void print(int x = 10) { }

print(5);   // x = 5
print();    // x = 10 (default)

// multiple parameters:
void setup(int x = 0, int y = 0, int z = 0) { }

setup(1, 2, 3);  // x=1, y=2, z=3
setup(1);        // x=1, y=0, z=0
setup();         // x=0, y=0, z=0
```

---

### Rule ஒன்று இருக்கு:

```cpp
// ❌ தவறு — default இல்லாதது, default-க்கு பின் வர முடியாது!
void foo(int x = 0, int y) { }

// ✅ சரி — default உள்ளவை கடைசியில் இருக்கணும்!
void foo(int x, int y = 0) { }
```

> **`= value` என்பது "இந்த parameter-க்கு நீ value கொடுக்கலைன்னா இதை use பண்ணு" என்று compiler-க்கு சொல்வது!**
