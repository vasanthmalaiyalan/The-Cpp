## `December / 16 / 1770` — step by step:

### C++ இதை இப்படி படிக்கும்:

```cpp
// Left to right evaluate ஆகும்:
(December / 16) / 1770
```

---

### Step 1 — `December / 16`:

```cpp
// December என்பது:
constexpr month December {12};

// இது call ஆகும்:
constexpr month_day operator/(month m, int d)

// return:
month_day { month{12}, day{16} }
```

```
result → month_day object (temp)
```

---

### Step 2 — `month_day{...} / 1770`:

```cpp
// Step 1-இன் result month_day — அதை இது பிடிக்கும்:
constexpr year_month_day operator/(month_day md, int y)

// return:
year_month_day { year{1770}, month{12}, day{16} }
```

```
result → year_month_day object
```

---

### `auto` என்ன அடையாளம் கண்டுகொள்ளும்:

```cpp
auto birthday = December / 16 / 1770;
//   ^^^^^^^^
//   compiler பார்க்கும்:
//   operator/ return type என்ன? → year_month_day
//   அதனால் auto = year_month_day
```

**Compiler தானாகவே type கண்டுபிடிக்கும் — நீங்கள் சொல்ல வேண்டாம்!**

---

### சுருக்கமா:

```
December / 16         → operator#1 → month_day    (temp)
month_day / 1770      → operator#2 → year_month_day

auto birthday = year_month_day{1770, 12, 16}
```

> **`auto` = return type-ஐ compiler-ே கண்டுபிடிக்கும்** — இங்கே `year_month_day` என்று தெரிந்துகொள்ளும்!

-----------------

`அதாவது `December / 16   ` operator முன்னாள் இருப்பது மட்டும் கால் ஆகுமா?`

ஆமா! அதுதான் C++ operator overloading-இன் rule!

---

### Operator எப்படி match ஆகும்:

```cpp
December / 16
```

Compiler பார்க்கும்:
```
Left side  : December → type = month
Right side : 16       → type = int

எந்த operator/ இருக்கு month, int-க்கு? → இது!
constexpr month_day operator/(month m, int d)  ✅
```

---

### இரண்டாவது operator ஏன் call ஆகவில்லை:

```cpp
// இது match ஆகாது:
constexpr year_month_day operator/(month_day md, int y)
//                                 ^^^^^^^^^
//                                 left side month_day வேணும்
//                                 ஆனால் December = month — match இல்லை! ❌
```

---

### Simple rule:

```
operator/(A, B) → A-இன் type, B-இன் type பார்க்கும்

December / 16   → month    / int → operator#1 ✅
month_day / 1770 → month_day / int → operator#2 ✅
```

---

### இப்படி நினைச்சுக்கோங்க:

```
December / 16 / 1770

= (December / 16)      / 1770
=  month / int            ↓
=  month_day          / int
=  year_month_day
```

> **Left side-இன் type மட்டும் தான் எந்த operator call ஆகும் என்று decide பண்ணும்!**

--------------------------

## `birthday.print()` — step by step:

### birthday என்ன type:

```cpp
auto birthday = December / 16 / 1770;
// birthday = year_month_day{year{1770}, month{12}, day{16}}
```

---

### `print()` call ஆகும்போது:

```cpp
void print() const {
    std::cout
        << y.get()   // ← இங்கே என்ன நடக்கும்?
        << '-'
        << m.get()
        << '-'
        << d.get()
        << '\n';
}
```

---

### உள்ளே step by step:

```
birthday object — memory-ல் இப்படி இருக்கும்:

base address: 6000
┌─────────┬─────────┬─────────┐
│  1770   │   12    │   16    │
│  year y │ month m │  day d  │
│ base+0  │ base+4  │ base+8  │
└─────────┴─────────┴─────────┘
```

```
y.get() call:
→ base + 0 → 1770 read → return 1770

m.get() call:
→ base + 4 → 12 read   → return 12

d.get() call:
→ base + 8 → 16 read   → return 16
```

---

### Output:

```
1770-12-16
```

---

### Temp object உருவாகுமா?

```
y.get() → ❌ temp இல்லை — already living member
m.get() → ❌ temp இல்லை — already living member
d.get() → ❌ temp இல்லை — already living member
```

> **`birthday` already memory-ல் உயிரோடு இருக்கு** — `print()` call ஆகும்போது base + offset மட்டும் படிக்கும், புதுசா எதுவும் உருவாகாது!

## `auto` உள்ளே என்ன இருக்கு:

### Trace பண்ணுவோம்:

```cpp
// Step 1:
December / 16
// operator/(month, int) call → return type = month_day
// result: month_day{ month{12}, day{16} }

// Step 2:
month_day{12,16} / 1770
// operator/(month_day, int) call → return type = year_month_day
// result: year_month_day{ year{1770}, month{12}, day{16} }
```

---

### Final — auto உள்ளே:

```cpp
auto birthday = year_month_day{ year{1770}, month{12}, day{16} };
//   ^^^^^^^^
//   type = year_month_day
```

---

### Memory-ல்:

```
birthday (year_month_day object):

┌─────────┬─────────┬─────────┐
│  1770   │   12    │   16    │
│  year y │ month m │  day d  │
│ base+0  │ base+4  │ base+8  │
└─────────┴─────────┴─────────┘
```

---

### Verify பண்ண:

```cpp
// இப்படி எழுதினாலும் same result:
year_month_day birthday = December / 16 / 1770;

// auto என்பது compiler-ே type கண்டுபிடிக்கும்
// உள்ளே year_month_day தான் இருக்கு!
```

> **`auto` = `year_month_day`** — compiler operator/ -இன் return type பார்த்து தானாகவே கண்டுபிடித்தது!

## `sys_days` என்றால் என்ன:

### Code பாருங்க:

```cpp
class sys_days {
private:
    long long total_days;

public:
    explicit sys_days(long long d = 0)
        : total_days(d) {
    }

    sys_days& operator+=(days d) {
        total_days += d.count();
        return *this;
    }

    void print() const {
        std::cout << "stored days : " << total_days << '\n';
    }
};
```

---

### இது என்ன செய்யும்:

**நாட்களை ஒரே ஒரு number-ஆக store செய்யும்.**

Real `std::chrono`-ல் இது 1970 Jan 1 முதல் எத்தனை நாட்கள் என்று count செய்யும் — இங்கே simplified version.

---

### Main-ல் என்ன நடக்கிறது:

```cpp
// Step 1 — 100 நாட்கள் வச்சு create பண்ணு
sys_days day_point(100);
day_point.print();
// output: stored days : 100
```

```cpp
// Step 2 — 7 நாட்கள் கூட்டு
day_point += days{7};
day_point.print();
// output: stored days : 107
```

---

### `operator+=` உள்ளே என்ன நடக்கும்:

```cpp
sys_days& operator+=(days d) {
    total_days += d.count();  // 100 + 7 = 107
    return *this;             // same object return
}
```

```
days{7} → d.count() → 7
total_days = 100 + 7 = 107
```

---

### `return *this` ஏன்:

```cpp
// இப்படி chain பண்ண உதவும்:
day_point += days{7} += days{3};
//           ^^^^^^^^   ^^^^^^^^
//           same object return ஆவதால் chain possible
```

---

### Memory-ல்:

```
day_point object:
┌──────────────────┐
│   total_days     │
│   100 → 107      │
│   8 bytes        │
└──────────────────┘
```

> **`sys_days` = நாட்களை எண்ணிக்கையாக store செய்து, கூட்டல் கழித்தல் பண்ண உதவும் simple wrapper class!**
