## `: value{v}` — Member Initializer List!

## `()` vs `: value{v}` வித்தியாசம்:

```cpp
// பழைய style — constructor body-ல் assign:
Counter(int v)
{
    value = v;  // முதல் default init ஆகும், பிறகு assign!
}

// புதிய style — member initializer list:
Counter(int v) : value{v}
{
    // நேரடியா init! default init நடக்கவே நடக்காது!
}
```

---

## Internally என்னாகுது:

```cpp
Counter(int v) : value{v} {}

// Step 1: : பார்க்கும்
//         member initializer list ஆரம்பம்!
//              ↓
// Step 2: value{v}
//         value-ஐ v-ஓட value-ஆல் directly init!
//              ↓
// Step 3: {} — constructor body
//         வெறுமனே — செய்ய ஒன்றுமில்லை!
```

---

## ஏன் இது better:

```cpp
// Body-ல் assign — 2 steps:
value = v;
// Step 1: value = 0  (default init)
// Step 2: value = v  (assign)

// Initializer list — 1 step:
: value{v}
// Step 1: value = v  (directly init — faster!)
```

---

## Multiple members இருந்தால்:

```cpp
Date(int yy, int mm, int dd)
    : y{yy},   // ← y init
      m{mm},   // ← m init
      d{dd}    // ← d init
{
    // body
}
```

சுருக்கமா — `:` என்பது **constructor body execute ஆவதற்கு முன்பே** members-ஐ directly initialize செய்யும் — faster and better!
