# நல்ல கேள்வி! 🎯

---

## `unordered_map` என்றால் என்ன?

```cpp
// சாதாரண array:
int arr[3] = {10, 20, 30};
arr[0]; // index மட்டும் பயன்படுத்தலாம்

// unordered_map:
unordered_map<string, size_t> layout;
layout["age"]    = 0;
layout["height"] = 4;
// name-ஐ வைத்து தேடலாம்! ✅
```

```
Key   →  Value
"age"    →  0
"height" →  4
"weight" →  8
```

**Key-value pair — name கொடுத்தால் offset கிடைக்கும்!**

---

## ஏன் `<string, size_t>` போட்டோம்?

```cpp
unordered_map<string, size_t>
//            ^^^^^^  ^^^^^^
//            Key     Value
//            name    offset
```

```
map-க்கு இரண்டு types சொல்ல வேண்டும்:
1. Key type   → எதை வைத்து தேடுவோம்? → string (name)
2. Value type → என்ன கிடைக்கும்?      → size_t (offset)
```

---

## ஏன் `<MemberInfo>` வேலை செய்யாது?

```cpp
struct MemberInfo {
    string name;    // Key?
    size_t offset;  // Value?
};

// map-க்கு தெரியாது:
unordered_map<MemberInfo> layout; // ❌ Error!
// "Key எது? Value எது?" — புரியவில்லை!
```

```
MemberInfo உள்ளே இரண்டும் இருக்கிறது —
map-க்கு எது key, எது value என்று
தனியாக சொல்ல வேண்டும்!
```

---

## `MemberInfo` பயன்படுத்த வேண்டுமென்றால்:

```cpp
// இப்படி செய்யலாம்:
vector<MemberInfo> layout = {
    {"age",    0},
    {"height", 4},
    {"weight", 8}
};

// தேட:
for (auto& m : layout) {
    if (m.name == "height") {
        cout << m.offset; // 4
    }
}
```

---

## சுருக்கம்:

| | `unordered_map<string,size_t>` | `unordered_map<MemberInfo>` |
|---|---|---|
| Key | string (name) | ❌ தெரியாது |
| Value | size_t (offset) | ❌ தெரியாது |
| வேலை செய்யுமா? | ✅ | ❌ Error |

> **`unordered_map`-க்கு Key, Value தனித்தனியாக சொல்ல வேண்டும் — `MemberInfo` உள்ளே இரண்டும் சேர்ந்து இருப்பதால் map புரிந்துகொள்ள முடியாது!** 🎯
