அருமையான கேள்வி. 🔥

நீங்கள் இப்போது:

> `age -> offset 0`
>
> `height -> offset 4`

இதை compiler எப்படி கண்டுபிடிக்கிறது?

அதற்காக பயன்படுத்தும்:

```cpp
offsetof(Person, age)
```

உள்ளே எப்படி வேலை செய்கிறது?

என்று கேட்கிறீர்கள்.

---

## முதலில் பயன்பாடு

```cpp
#include <iostream>
#include <cstddef>

struct Person
{
    int age;
    int height;
};

int main()
{
    std::cout << offsetof(Person, age) << '\n';
    std::cout << offsetof(Person, height) << '\n';
}
```

Output:

```text
0
4
```

---

# பழைய Compiler Macro Implementation

பல C compilers-ல் historically இது இப்படி இருந்தது:

```cpp
#define MY_OFFSETOF(TYPE, MEMBER) \
    ((size_t)&(((TYPE*)0)->MEMBER))
```

இப்போது இதை line by line உடைப்போம்.

---

## Step 1

```cpp
(TYPE*)0
```

உதாரணம்:

```cpp
(Person*)0
```

Result:

```text
Pointer to Person
Address = 0
```

Conceptually:

```text
0x00000000
```

---

## Step 2

```cpp
((Person*)0)->age
```

Compiler பார்க்கிறது:

```text
Person layout:

age    offset 0
height offset 4
```

---

அதனால்:

```cpp
((Person*)0)->age
```

என்பது:

```text
address 0 + offset(age)
```

---

Age:

```text
0 + 0
```

Result:

```text
address 0
```

---

Height:

```cpp
((Person*)0)->height
```

Compiler:

```text
0 + 4
```

Result:

```text
address 4
```

---

## Step 3

இப்போது:

```cpp
&(((Person*)0)->height)
```

becomes:

```text
&address(4)
```

Result:

```text
4
```

---

## Step 4

Cast:

```cpp
(size_t)
```

Result:

```cpp
4
```

# Demo Program

இந்த program macro எப்படி வேலை செய்கிறது என்பதை காட்டும்:

```cpp
#include <iostream>

#define MY_OFFSETOF(TYPE, MEMBER) \
    ((size_t)&(((TYPE*)0)->MEMBER))

struct Person
{
    int age;
    int height;
    int weight;
};

int main()
{
    std::cout
        << MY_OFFSETOF(Person, age)
        << '\n';

    std::cout
        << MY_OFFSETOF(Person, height)
        << '\n';

    std::cout
        << MY_OFFSETOF(Person, weight)
        << '\n';
}
```

Output:

```text
0
4
8
```

# ஆனால் Modern C++ Compiler?

இன்று GCC / Clang / MSVC பொதுவாக இதை macro trick-ஆக செய்யாது.

Compiler builtin பயன்படுத்தும்.

Example:

```cpp
__builtin_offsetof(Person, height)
```

---

ஏன்?

ஏனெனில்:

```cpp
(Person*)0
```

null pointer.

அதை dereference பண்ணுவது technically undefined behavior.

---

அதனால் compiler parse stage-லேயே:

```text
Type = Person
Member = height
```

பார்த்து நேரடியாக:

```text
4
```

என்று compile-time constant உருவாக்கிவிடும்.

---

# Compiler Layout Engine

Compiler class parse செய்தவுடன்:

```cpp
struct Person
{
    int age;
    int height;
    int weight;
};
```

Internal layout table:

```text
Person

age      offset 0
height   offset 4
weight   offset 8

size = 12
```

---

பிறகு:

```cpp
offsetof(Person, weight)
```

பார்த்தவுடன்:

Compiler:

```text
lookup:
weight -> 8
```

Return:

```cpp
8
```

# Best Educational Version

Compiler போல யோசிக்க வேண்டும் என்றால் இந்த code மிகவும் useful:

```cpp
#include <iostream>
#include <cstddef>

struct Person
{
    int age;
    int height;
    int weight;
};

int main()
{
    std::cout
        << "age offset    : "
        << offsetof(Person, age)
        << '\n';

    std::cout
        << "height offset : "
        << offsetof(Person, height)
        << '\n';

    std::cout
        << "weight offset : "
        << offsetof(Person, weight)
        << '\n';

    std::cout
        << "sizeof(Person): "
        << sizeof(Person)
        << '\n';
}
```

இதிலிருந்து compiler-ன் layout engine என்ன செய்கிறது என்பதை நேரடியாகப் பார்க்கலாம்:

```text
base address
   |
   +-- age    (offset 0)
   +-- height (offset 4)
   +-- weight (offset 8)
```

அதனால்தான் பின்னர்:

```cpp
this_ptr->height
```

என்பது compiler மனதில்:

```cpp
*(int*)((char*)this_ptr + 4)
```

என்ற address calculation-ஆக மாறுகிறது. `offsetof()` என்பது அந்த `4`-ஐ compile-time-ல் கண்டுபிடிக்கும் வசதி மட்டுமே.
