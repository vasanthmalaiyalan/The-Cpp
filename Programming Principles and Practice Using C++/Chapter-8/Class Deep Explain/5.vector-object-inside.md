# Step 2: Range-for compiler expansion

நாம் எழுதுகிறோம்:

```cpp
for (auto& field : fields)
{
    std::cout << field.name << '\n';
}
```

Compiler conceptually expand செய்கிறது:

```cpp
auto __begin = fields.begin();

auto __end = fields.end();

for ( ; __begin != __end ; ++__begin )
{
    auto& field = *__begin;

    std::cout << field.name << '\n';
}
```

---

இதுதான் உண்மையான idea.

# Exact Minimal Demo

இதுதான் vector iterator concept-ஐ raw pointer-ஆக காட்டும் code:

```cpp
#include <iostream>

struct Item
{
    int value;
};

int main()
{
    Item arr[3];

    arr[0].value = 10;
    arr[1].value = 20;
    arr[2].value = 30;

    Item* begin = &arr[0];

    Item* end = &arr[3];

    while(begin != end)
    {
        std::cout
            << begin->value
            << '\n';

        ++begin;
    }
}
```

Output:

```text
10
20
30
```

# Very Important

நீ கேட்ட:

> எப்படி அது next object-க்கு move ஆகிறது?

Answer:

`field` move ஆகவில்லை.

Move ஆகுவது:

```cpp
__begin
```

iterator (அல்லது pointer).

---

Conceptually:

```text
__begin

0x5000  -> age

++

0x5038  -> salary

++

0x5070  -> grade

++

0x50A8  -> end
```

---

இதனால்:

```cpp
for(auto& field : fields)
```

என்பது compiler பார்வையில்:

```cpp
FieldInfo* ptr = fields.begin();

while(ptr != fields.end())
{
    FieldInfo& field = *ptr;

    ++ptr;
}
```

என்ற pointer traversal தான். Vector-ல் objects contiguous memory-ல் இருப்பதால், compiler `sizeof(FieldInfo)`-ஐ பயன்படுத்தி pointer-ஐ அடுத்த object address-க்கு நகர்த்துகிறது. இதுவே range-for loop-ன் அடிப்படை ரகசியம். 🚀
