# `offsetof` — How It Works Internally

---

## What is `offsetof`?

```cpp
offsetof(struct_name, member_name)
// Returns: byte distance of member from struct's start
```

---

## Internal Working

`offsetof` is actually a **macro**, not a real function.

### Classic Implementation:
```cpp
#define offsetof(type, member) \
    (size_t)( (char*)&((type*)0)->member - (char*)0 )
```

### Step-by-step breakdown:

```
Memory Address 0
│
▼
(type*)0        ← "Pretend" a struct exists at address 0
│
▼
&((type*)0)->member   ← Get address of member
│
▼
- (char*)0      ← Subtract 0 (start address)
│
▼
= member's byte offset from start ✅
```

---

## Modern Compiler Implementation

Modern compilers use a **built-in intrinsic** instead:

```cpp
// GCC / Clang internally use:
#define offsetof(type, member) __builtin_offsetof(type, member)

// This is safer — no null pointer tricks
```

## C++ Code — Full Demo

```cpp
#include <iostream>
#include <cstddef>  // offsetof lives here

using namespace std;

// ======================================
// Simple struct
// ======================================

struct Employee
{
    char  id;       // 1 byte
    // padding here (3 bytes typically)
    int   age;      // 4 bytes
    double salary;  // 8 bytes
    char  grade;    // 1 byte
};


// ======================================
// Manual offsetof (how it works inside)
// ======================================

#define MY_OFFSETOF(type, member) \
    (size_t)((char*)&((type*)0)->member - (char*)0)


// ======================================
// main
// ======================================

int main()
{
    cout << "=== struct Employee Layout ===" << "\n\n";

    // Using standard offsetof
    cout << "offsetof(Employee, id)     = "
         << offsetof(Employee, id)     << " bytes\n";

    cout << "offsetof(Employee, age)    = "
         << offsetof(Employee, age)    << " bytes\n";

    cout << "offsetof(Employee, salary) = "
         << offsetof(Employee, salary) << " bytes\n";

    cout << "offsetof(Employee, grade)  = "
         << offsetof(Employee, grade)  << " bytes\n";

    cout << "\nTotal struct size = "
         << sizeof(Employee) << " bytes\n";

    cout << "\n=== Manual offsetof (internal trick) ===\n\n";

    cout << "MY_OFFSETOF(Employee, id)     = "
         << MY_OFFSETOF(Employee, id)     << " bytes\n";

    cout << "MY_OFFSETOF(Employee, age)    = "
         << MY_OFFSETOF(Employee, age)    << " bytes\n";

    cout << "MY_OFFSETOF(Employee, salary) = "
         << MY_OFFSETOF(Employee, salary) << " bytes\n";

    return 0;
}
```

## Key Points

| Topic | Detail |
|---|---|
| **What it is** | A macro (not a function) |
| **Lives in** | `<cstddef>` |
| **Returns** | `size_t` (byte count) |
| **Trick used** | Null pointer cast to find byte distance |
| **Modern way** | `__builtin_offsetof` (compiler intrinsic) |
| **Main use** | Memory layout inspection, serialization, low-level programming |

> ⚠️ **Warning:** `(type*)0` is technically **undefined behavior** in C++ — that's why modern compilers replaced it with `__builtin_offsetof` which is safe.
