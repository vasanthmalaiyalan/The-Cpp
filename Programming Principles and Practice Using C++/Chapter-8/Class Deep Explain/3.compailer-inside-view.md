# Compiler போல simulate செய்யும் .cpp

இந்த program compiler layout builder மாதிரி வேலை செய்கிறது:

```cpp
#include <iostream>
#include <string>

struct Member
{
    std::string name;
    size_t size;
    size_t offset;
};

int main()
{
    size_t current_offset = 0;

    Member age;

    age.name = "age";
    age.size = sizeof(int);
    age.offset = current_offset;

    current_offset += age.size;

    // align for double

    size_t alignment = alignof(double);

    if (current_offset % alignment != 0)
    {
        current_offset +=
            alignment -
            (current_offset % alignment);
    }

    Member salary;

    salary.name = "salary";
    salary.size = sizeof(double);
    salary.offset = current_offset;

    current_offset += salary.size;

    Member grade;

    grade.name = "grade";
    grade.size = sizeof(char);
    grade.offset = current_offset;

    current_offset += grade.size;

    std::cout
        << age.name
        << " offset="
        << age.offset
        << '\n';

    std::cout
        << salary.name
        << " offset="
        << salary.offset
        << '\n';

    std::cout
        << grade.name
        << " offset="
        << grade.offset
        << '\n';
}
```

Output:

```text
age offset=0
salary offset=8
grade offset=16
```

# முழு Flow

```text
class Person
{
    int age;
    double salary;
    char grade;
}

        ↓

Compiler Parse

        ↓

Type sizes known

int    = 4
double = 8
char   = 1

        ↓

Layout Builder

age    -> offset 0

salary -> offset 8

grade  -> offset 16

        ↓

Metadata Table

        ↓

p.salary

        ↓

lookup salary

        ↓

offset = 8

        ↓

(char*)&p + 8

        ↓

actual memory access
```

இதுதான் compiler class-ஐ பார்த்து built-in type sizes-ஐ பயன்படுத்தி object layout உருவாக்கும் அடிப்படை செயல்முறை. இது புரிந்தால் அடுத்ததாக `this` pointer, member functions, constructors, virtual table ஆகியவை மிகவும் எளிதாக புரியும்.

அதனால்:

> "char size 1 byte தானே? அப்படியென்றால் offset 1 ஆக வர வேண்டாமா?"

இல்லை.

**offset என்பது member size அல்ல.**

offset என்றால்:

> Object ஆரம்பத்திலிருந்து அந்த member எத்தனையாவது byte-ல் தொடங்குகிறது?

---

இதனால்:

```text
age     starts at byte 0

salary  starts at byte 8

grade   starts at byte 16
```

அதனால்தான்:

```text
age offset=0
salary offset=8
grade offset=16
```

என்று output வந்தது. 🔥

இதிலிருந்து அடுத்த முக்கிய concept:

**Compiler ஏன் `double`-ஐ offset 4-ல் வைக்காமல் padding போட்டு 8-ல் வைத்தது? CPU alignment-க்கு என்ன benefit?**

அதுதான் class layout-ஐ உண்மையாகப் புரிய வேண்டிய அடுத்த படி.
