சரி. இப்போது `offsetof()`-லிருந்து ஆரம்பிக்க வேண்டாம். அது compiler-ன் கடைசி step. நீ கேட்பது:

> Class பார்த்தவுடன் compiler முதலில் என்ன செய்கிறது?
>
> `int`, `double`, `char` size-ஐ எப்படி பயன்படுத்துகிறது?
>
> offset எப்படி உருவாகிறது?

அதுதானே?

அதை compiler engineer மாதிரி step-by-step பார்ப்போம்.

# Compiler போல simulate செய்யும் .cpp

இந்த program compiler layout builder மாதிரி வேலை செய்கிறது:

```cpp
#include <iostream>
#include <string>

struct Member
{
    std::string name;
    size_t size;
    size_t offset;
};

int main()
{
    size_t current_offset = 0;

    Member age;

    age.name = "age";
    age.size = sizeof(int);
    age.offset = current_offset;

    current_offset += age.size;

    // align for double

    size_t alignment = alignof(double);

    if (current_offset % alignment != 0)
    {
        current_offset +=
            alignment -
            (current_offset % alignment);
    }

    Member salary;

    salary.name = "salary";
    salary.size = sizeof(double);
    salary.offset = current_offset;

    current_offset += salary.size;

    Member grade;

    grade.name = "grade";
    grade.size = sizeof(char);
    grade.offset = current_offset;

    current_offset += grade.size;

    std::cout
        << age.name
        << " offset="
        << age.offset
        << '\n';

    std::cout
        << salary.name
        << " offset="
        << salary.offset
        << '\n';

    std::cout
        << grade.name
        << " offset="
        << grade.offset
        << '\n';
}
```

Output:

```text
age offset=0
salary offset=8
grade offset=16
```

# முழு Flow

```text
class Person
{
    int age;
    double salary;
    char grade;
}

        ↓

Compiler Parse

        ↓

Type sizes known

int    = 4
double = 8
char   = 1

        ↓

Layout Builder

age    -> offset 0

salary -> offset 8

grade  -> offset 16

        ↓

Metadata Table

        ↓

p.salary

        ↓

lookup salary

        ↓

offset = 8

        ↓

(char*)&p + 8

        ↓

actual memory access
```

இதுதான் compiler class-ஐ பார்த்து built-in type sizes-ஐ பயன்படுத்தி object layout உருவாக்கும் அடிப்படை செயல்முறை. இது புரிந்தால் அடுத்ததாக `this` pointer, member functions, constructors, virtual table ஆகியவை மிகவும் எளிதாக புரியும்.
