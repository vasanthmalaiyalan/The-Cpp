ஆமாம்! இதுதான் pointer arithmetic-ன் முக்கியமான point. 🔥

நீ கேட்டது:

```cpp
FieldInfo* end = begin + fields.size();
```

இங்கே `sizeof(FieldInfo)=56` என்றால் என்ன நடக்கும்?

---

Suppose:

```cpp
FieldInfo* begin = 0x5000;
```

and

```cpp
fields.size() = 3;
```

---

நீங்க நினைப்பது போல:

```cpp
0x5000 + 3
```

ஆகாது.

ஏனெனில் `begin` type:

```cpp
FieldInfo*
```

---

Compiler rule:

```cpp
ptr + n
```

=

```cpp
(char*)ptr + (n * sizeof(T))
```

where:

```cpp
T = FieldInfo
```

---

அதனால்:

```cpp
begin + fields.size()
```

↓

```cpp
begin + 3
```

↓

```cpp
(char*)0x5000 + (3 * 56)
```

↓

```cpp
(char*)0x5000 + 168
```

---

168 decimal:

```text
168 = 0xA8
```

---

Result:

```text
0x5000 + 0xA8
=
0x50A8
```

---

அதனால்:

```cpp
FieldInfo* end = begin + fields.size();
```

becomes:

```text
end = 0x50A8
```

---

இதைக் compiler conceptually இப்படி பார்க்கலாம்:

```cpp
FieldInfo* begin = 0x5000;

FieldInfo* end =
    reinterpret_cast<FieldInfo*>(
        reinterpret_cast<char*>(begin)
        +
        fields.size() * sizeof(FieldInfo)
    );
```

---

Visual:

```text
sizeof(FieldInfo)=56

Address

0x5000  age
0x5038  salary
0x5070  grade
0x50A8  end
```

---

அதனால்:

```cpp
++begin;
```

என்றாலும்:

```cpp
begin = begin + 1;
```

↓

```cpp
(char*)begin + 56
```

---

மற்றும்:

```cpp
begin + 3
```

↓

```cpp
(char*)begin + (3 * 56)
```

---

அதனால் STL iterator traversal-ன் அடிப்படை rule:

```cpp
T* ptr;
```

என்றால்

```cpp
ptr + 1
```

என்பது:

```cpp
address + sizeof(T)
```

ஆகும்.

`1 byte` அல்ல. `sizeof(T)` bytes jump ஆகும்.

அதனால்தான்:

```cpp
FieldInfo* end = begin + fields.size();
```

இங்கே `56` ஒரு முறை மட்டும் அல்ல,

```text
56 × 3 = 168 bytes
```

jump செய்து `0x50A8` கிடைக்கிறது. 🚀

--------------------------

`இந்த ஒரு `fields.push_back(
    {
        "age",
        sizeof(int),
        alignof(int),
        0
    });
`object மட்டும் 56byte?`

ஆம், **அந்த ஒரு `FieldInfo` object** தான் சுமார் 56 bytes இருக்கலாம் (உங்கள் compiler/STL implementation-ஐப் பொறுத்து மாறும்).

நாம் இதைப் பார்ப்போம்:

```cpp
struct FieldInfo
{
    std::string name;
    size_t size;
    size_t alignment;
    size_t offset;
};
```

64-bit Linux-ல் பொதுவாக:

```text
std::string    = 32 bytes
size_t         = 8 bytes
size_t         = 8 bytes
size_t         = 8 bytes
-------------------------
Total          = 56 bytes
```

---

அதனால்:

```cpp
FieldInfo temp =
{
    "age",
    sizeof(int),
    alignof(int),
    0
};
```

இந்த **ஒரே object** memory layout:

```text

Offset

    std::string name
31  -----------------

32  -----------------
    size
39  -----------------

40  -----------------
    alignment
47  -----------------

    offset
55  -----------------
```

---

அதனால்:

```cpp
fields.push_back(
{
    "age",
    sizeof(int),
    alignof(int),
    0
});
```

முதலில் temporary object:

```cpp
FieldInfo temp;
```

உருவாகும்.

அதன் size:

```cpp
sizeof(FieldInfo)
```

உதாரணமாக:

```text
56 bytes
```

---

பிறகு vector-ல் copy/move ஆகும்.

Heap:

```text

+------------------------+
| FieldInfo age (56 B)   |

```

---

இரண்டாவது:

```cpp

{
    "salary",
    sizeof(double),
    alignof(double),
    0

```

மற்றொரு 56-byte object.

---

Heap:

```text
0x5000  age      (56 bytes)

```

ஏனெனில்:

```text
56 decimal = 0x38
```

---

மூன்றாவது:

```cpp

{
    "grade",
    sizeof(char),
    alignof(char),
    0

```

மீண்டும் 56 bytes.

---

Heap:


## முக்கியமான விஷயம்

இந்த object:

```cpp
{
    "age",
    sizeof(int),
    alignof(int),
    0
}
```

உள்ளே `"age"` string இருப்பதால் பலர்:

> object size 3 bytes தானே?

என்று நினைப்பார்கள்.

ஆனால் இல்லை.

`std::string` தானே ஒரு object.

பொதுவாக:

```cpp
sizeof(std::string)
```

சுமார்:

```text
24 அல்லது 32 bytes
```

---

அதனால்:

```cpp
sizeof(FieldInfo)
```

என்பது:

```text
string object size
+
size_t
+
size_t
+
size_t
```

ஆக கணக்கிடப்படும்.

---

நீங்கள் உங்கள் machine-ல் exact size பார்க்க:

```cpp
#include <iostream>
#include <string>

struct FieldInfo
{
    std::string name;
    size_t size;
    size_t alignment;
    size_t offset;
};

int main()
{
    std::cout
        << sizeof(std::string)
        << '\n';

    std::cout
        << sizeof(FieldInfo)
        << '\n';
}
```

Run செய்தால் உங்கள் compiler/STL implementation-க்கு exact value தெரியும்.

அதனால் **ஆம்**, `push_back({...})`-ல் உருவாகும் அந்த ஒரு `FieldInfo` temporary object itself சுமார் **56 bytes** இருக்கலாம்; vector heap-ல் store செய்வதும் அதே size கொண்ட object-ஐத்தான்.
