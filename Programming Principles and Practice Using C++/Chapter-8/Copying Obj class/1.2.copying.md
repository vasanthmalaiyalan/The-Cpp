# Compiler Default Copy

Book:

```cpp id="ljlwm0"
Date holiday
{
    Year{1978},
    Month::jul,
    4
};

Date d2 = holiday;
```

---

Compiler automatically does:

```text id="c39mnn"
d2.y = holiday.y
d2.m = holiday.m
d2.d = holiday.d
```

# Book-Oriented Example

```cpp id="btjlwm"
#include <iostream>

enum class Month
{
    jan = 1,
    feb,
    mar,
    apr,
    may,
    jun,
    jul,
    aug,
    sep,
    oct,
    nov,
    dec
};

struct Year
{
    int y;
};

class Date
{
public:

    Date(Year yy, Month mm, int dd)
        : y{yy},
          m{mm},
          d{dd}
    {
    }

    void print() const
    {
        std::cout
            << y.y
            << '/'
            << static_cast<int>(m)
            << '/'
            << d
            << '\n';
    }

private:

    Year y;
    Month m;
    int d;
};

int main()
{
    Date holiday
    {
        Year{1978},
        Month::jul,
        4
    };

    Date d2 = holiday;

    d2.print();
}
```

Output:

```text id="4a7z9z"
1978/7/4
```

# Initialization Copy vs Assignment Copy

Book shows two different things.

---

# 1. Copy Initialization

```cpp id="6m6oht"
Date d2 = holiday;
```

This happens during creation.

Meaning:

```text id="o0vtxh"
Create d2
using holiday
```

---

# 2. Assignment

```cpp id="lw6gb8"
d3 = holiday;
```

Here:

```cpp id="v0l4b4"
d3
```

already exists.

Meaning:

```text id="mu1yqe"
Replace d3's contents
with holiday's contents
```

---

# Example Showing Difference

```cpp id="k6ybew"
#include <iostream>

class Number
{
public:

    Number(int v)
        : value{v}
    {
        std::cout
            << "constructor\n";
    }

    void print() const
    {
        std::cout
            << value
            << '\n';
    }

private:

    int value;
};

int main()
{
    Number a{10};

    Number b = a;

    Number c{20};

    c = a;
}
```

---

Meaning:

```text id="fj7crg"
b = a
↓
copy initialization

c = a
↓
assignment
```

# What If Default Copy Is Wrong?

Book says:

Sometimes member-by-member copy is dangerous.

---

Example:

```cpp id="n0n3n3"
class Bad
{
private:

    int* ptr;
};
```

Suppose:

```cpp id="rztv5l"
Bad a;
Bad b = a;
```

Compiler default copy:

```text id="0ib48n"
b.ptr = a.ptr
```

Both point same memory.

Dangerous.

---

This causes:

```text id="83c4ae"
double delete
memory corruption
bugs
```

---

# Therefore

Sometimes we:

```text id="q8imj4"
Define our own copy behavior
```

or:

```text id="uxj2je"
Disable copying completely
```

# Full Book-Oriented Demo

```cpp id="uxjlwm"
#include <iostream>

enum class Month
{
    jan = 1,
    feb,
    mar,
    apr,
    may,
    jun,
    jul,
    aug,
    sep,
    oct,
    nov,
    dec
};

struct Year
{
    int y;
};

class Date
{
public:

    Date(Year yy, Month mm, int dd)
        : y{yy},
          m{mm},
          d{dd}
    {
    }

    void print() const
    {
        std::cout
            << y.y
            << '/'
            << static_cast<int>(m)
            << '/'
            << d
            << '\n';
    }

private:

    Year y;
    Month m;
    int d;
};

int main()
{
    Date holiday
    {
        Year{1978},
        Month::jul,
        4
    };

    Date d2 = holiday;

    Date d3 =
        Date
        {
            Year{1978},
            Month::dec,
            24
        };

    holiday =
        Date
        {
            Year{1978},
            Month::dec,
            25
        };

    d2.print();
    d3.print();
    holiday.print();
}
```

Output:

```text id="mw9t7z"
1978/7/4
1978/12/24
1978/12/25
```

# Final Big Idea of §8.7.2

For simple value-like classes:

```cpp id="c1r3u5"
Date
Month
Year
Point
Complex
```

default copying:

```text id="55llf2"
copy all members
```

usually correct.

---

Compiler automatically provides:

```text id="7ynv7p"
copy constructor
copy assignment
```

---

But for classes managing resources:

```text id="yc3nzm"
heap memory
file handles
network sockets
mutexes
```

default copying may be dangerous.

Then we must:

```text id="5k59ew"
define custom copy behavior
or disable copying
```

This is the beginning of one of the deepest topics in C++:

```text id="n9r0bg"
Object ownership and resource management
```
