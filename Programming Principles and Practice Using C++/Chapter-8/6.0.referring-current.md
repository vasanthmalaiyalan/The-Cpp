இந்த **§8.4.5 Referring to the current object** என்பது OOP-இல் மிகவும் முக்கியமான concept.

Stroustrup கேட்கிறார்:

> `month()` function-க்கு argument இல்லை.
> அப்படியிருக்க `d1.m`-ஐ return செய்ய வேண்டுமா அல்லது `d2.m`-ஐ return செய்ய வேண்டுமா என்று எப்படி தெரிகிறது?

---

# Book Example

```cpp
class Date {
public:
    int month()
    {
        return m;
    }

private:
    int y;
    int m;
    int d;
};
```

---

Usage:

```cpp
void f(Date d1, Date d2)
{
    std::cout
        << d1.month()
        << ' '
        << d2.month()
        << '\n';
}
```

---

Question

```cpp
d1.month();
```

இதில்:

```cpp
return m;
```

means:

```cpp
return d1.m;
```

---

But next:

```cpp
d2.month();
```

இதில்:

```cpp
return m;
```

means:

```cpp
return d2.m;
```

---

How?

Function argument இல்லையே?

---

# Hidden Secret

Compiler secretly passes:

```text
current object
```

as an extra hidden argument.

---

Think like this:

When you write:

```cpp
d1.month();
```

Compiler roughly thinks:

```cpp
month(&d1);
```

---

And:

```cpp
d2.month();
```

Compiler roughly thinks:

```cpp
month(&d2);
```

---

So actual idea is:

```cpp
month(current_object);
```

---

# Manual Simulation

Let's pretend C++ had no classes.

We could write:

```cpp
#include <iostream>

struct Date
{
    int y;
    int m;
    int d;
};

int month(Date* current)
{
    return current->m;
}

int main()
{
    Date d1{2025,12,24};
    Date d2{2024,8,15};

    std::cout
        << month(&d1)
        << ' '
        << month(&d2)
        << '\n';
}
```

Output:

```text
12 8
```

---

This is conceptually what happens behind the scenes.

# The `this` Pointer

C++ exposes this hidden argument through:

```cpp
this
```

---

Book hasn't introduced it fully yet, but this is what it is.

---

Example:

```cpp
class Date
{
public:
    int month()
    {
        return this->m;
    }

private:
    int y;
    int m;
    int d;
};
```

---

This:

```cpp
return m;
```

and

```cpp
return this->m;
```

mean the same thing.

# More Interesting Example

```cpp
#include <iostream>

class Counter
{
public:
    Counter(int v)
        : value{v}
    {
    }

    void increase()
    {
        value++;
    }

    int get()
    {
        return value;
    }

private:
    int value;
};

int main()
{
    Counter c1{10};
    Counter c2{100};

    c1.increase();

    std::cout << c1.get() << '\n';
    std::cout << c2.get() << '\n';
}
```

Output:

```text
11
100
```

---

Why didn't `c2` change?

Because:

```cpp
c1.increase();
```

passes current object:

```text
c1
```

---

Inside:

```cpp
value++;
```

means:

```cpp
c1.value++;
```

not:

```cpp
c2.value++;
```

# Stroustrup's Main Message

Every member function automatically receives a hidden reference/pointer to the object on which it is called.

So:

```cpp
d1.month()
```

↓

roughly

```cpp
month(&d1)
```

and

```cpp
d2.month()
```

↓

roughly

```cpp
month(&d2)
```

Therefore inside:

```cpp
return m;
```

the compiler automatically understands:

```cpp
return current_object->m;
```

This hidden **current object** is later exposed as the famous:

```cpp
this
```

pointer.
