இந்த **§8.4.1 struct and functions**-ல் Stroustrup சொல்லும் முக்கிய lesson:

> **"ஒரு struct மட்டும் போதாது; அதனுடன் operations (functions) தேவை."**

அவர் Date class-ஐ ஒரே நேரத்தில் class ஆக உருவாக்கவில்லை. முதலில் ஒரு simple `struct`-ஆக ஆரம்பித்து, அதன் பிரச்சனைகளை காட்டுகிறார்.

---

# Book Version 1

```cpp
struct Date
{
    int y;   // year
    int m;   // month
    int d;   // day
};
```

Usage:

```cpp
Date today;

today.y = 2025;
today.m = 12;
today.d = 24;
```

Memory:

```text
today
 ├── y = 2025
 ├── m = 12
 └── d = 24
```

---

# Problem #1

தவறான values எளிதாக assign செய்யலாம்.

```cpp
Date today;

today.y = 2025;
today.m = 24;     // invalid month
today.d = 12;
```

Compiler:

```text
No Error
```

ஏனெனில்:

```cpp
int m;
```

என்பது எந்த integer-யும் accept செய்யும்.

---

# Problem #2

Code repetitive

ஒவ்வொரு முறையும்:

```cpp

today.d = ...
```

எழுத வேண்டும்.

# Problem #3

Hard validation

```cpp
Date leap;

leap.y = 2000;
leap.m = 2;
leap.d = 29;
```

Question:

```text
29 Feb 2000 valid date தானா?
```

இதைக் every time manually check பண்ண வேண்டுமா?

Impossible.

# Stroustrup's Solution

Helper functions.

---

## Book-oriented Example

```cpp
#include <iostream>

struct Date
{
    int y;
    int m;
    int d;
};

bool is_valid_date(int y, int m, int d)
{
    if (m < 1 || m > 12)
        return false;

    if (d < 1 || d > 31)
        return false;

    return true;
}

void init_day(Date& dd, int y, int m, int d)
{
    if (!is_valid_date(y, m, d))
    {
        std::cout << "Invalid date\n";
        return;
    }

    dd.y = y;
    dd.m = m;
    dd.d = d;
}
```

---

Usage:

```cpp
int main()
{
    Date today;

    init_day(today, 2025, 12, 24);

    std::cout
        << today.d << '/'
        << today.m << '/'
        << today.y
        << '\n';
}
```

Output:

```text
24/12/2025
```

---

# Why pass by reference?

Book:

```cpp
void init_day(Date& dd, int y, int m, int d)
```

Notice:

```cpp
Date&
```

not:

```cpp
Date
```

Because:

```cpp
dd
```

must modify original object.

---

Example:

```cpp
Date today;

init_day(today, 2025, 12, 24);
```

Inside function:

```cpp
dd.y = 2025;
```

actually changes:

```cpp
today.y
```

# Next Helper Function

Book:

```cpp
void add_day(Date& dd, int n)
{
    // increase date by n days
}
```

Simplified version:

```cpp
void add_day(Date& dd, int n)
{
    dd.d += n;
}
```

Usage:

```cpp
Date today;

init_day(today, 2025, 12, 24);

add_day(today, 1);
```

Result:

```text
25/12/2025
```

# Full Book-Oriented Example

```cpp
#include <iostream>

struct Date
{
    int y;
    int m;
    int d;
};

bool is_valid_date(int y, int m, int d)
{
    if (m < 1 || m > 12)
        return false;

    if (d < 1 || d > 31)
        return false;

    return true;
}

void init_day(Date& dd, int y, int m, int d)
{
    if (!is_valid_date(y, m, d))
    {
        std::cout << "Invalid date\n";
        return;
    }

    dd.y = y;
    dd.m = m;
    dd.d = d;
}

void add_day(Date& dd, int n)
{
    dd.d += n;
}

void print_date(const Date& dd)
{
    std::cout
        << dd.d << '/'
        << dd.m << '/'
        << dd.y
        << '\n';
}

int main()
{
    Date today;

    init_day(today, 2025, 12, 24);

    print_date(today);

    add_day(today, 1);

    print_date(today);
}
```

Output:

```text
24/12/2025
25/12/2025
```

# What Stroustrup Wants You To Notice

Initially:

```cpp
today.y = ...
today.m = ...
today.d = ...
```

everywhere.

---

After helper functions:

```cpp
init_day(today, 2025, 12, 24);

add_day(today, 1);
```

Much cleaner.

# Evolution Path of the Chapter

This section intentionally starts with:

```cpp

{
```

Then evolves into:

```text

    ↓

```
