இந்த **§8.4 Evolving a class: Date** chapter-ன் நோக்கம்:

> ஒரு simple data structure (`day`, `month`, `year`) எப்படி மெதுவாக ஒரு professional C++ class ஆக evolve ஆகிறது?

Stroustrup ஒரே நாளில் பெரிய class எழுதவில்லை. அவர் step-by-step improve செய்கிறார்.

---

# Step 1 — Simple struct

முதலில் date-ஐ வெறும் data ஆக represent செய்வோம்.

```cpp
#include <iostream>

struct Date
{
    int day;
    int month;
    int year;
};

int main()
{
    Date today;

    today.day = 23;
    today.month = 5;
    today.year = 2026;

    std::cout
        << today.day << '/'
        << today.month << '/'
        << today.year << '\n';
}
```

Output:

```text
23/5/2026
```

---

## Problem

User தவறான value கொடுக்கலாம்.

```cpp
today.day = 99;
today.month = 45;
```

Compiler error கொடுக்காது.

அதனால் invalid dates உருவாகலாம்.

# Step 2 — Add functions

Date-க்கு operations சேர்ப்போம்.

```cpp
#include <iostream>

struct Date
{
    int day;
    int month;
    int year;
};

void print(const Date& d)
{
    std::cout
        << d.day << '/'
        << d.month << '/'
        << d.year << '\n';
}

int main()
{
    Date today {23, 5, 2026};

    print(today);
}
```

---

இப்போது data + operation இருக்கிறது.

ஆனால் இன்னும்:

```cpp
today.day = 999;
```

possible.

# Step 3 — Convert to Class

Data-ஐ hide பண்ணலாம்.

```cpp
#include <iostream>

class Date
{
private:
    int day;
    int month;
    int year;

public:
    Date(int d, int m, int y)
    {
        day = d;
        month = m;
        year = y;
    }

    void print()
    {
        std::cout
            << day << '/'
            << month << '/'
            << year << '\n';
    }
};

int main()
{
    Date today(23, 5, 2026);

    today.print();
}
```

---

## Benefit

Outside code cannot do:

```cpp
today.day = 50;
```

Compile error.

# Step 4 — Validate input

Constructor-ல் checking செய்வோம்.

```cpp
#include <iostream>
#include <stdexcept>

class Date
{
private:
    int day;
    int month;
    int year;

public:
    Date(int d, int m, int y)
    {
        if (d < 1 || d > 31)
            throw std::runtime_error("Invalid day");

        if (m < 1 || m > 12)
            throw std::runtime_error("Invalid month");

        day = d;
        month = m;
        year = y;
    }

    void print() const
    {
        std::cout
            << day << '/'
            << month << '/'
            << year << '\n';
    }
};

int main()
{
    try
    {
        Date today(23, 5, 2026);

        today.print();
    }
    catch(const std::exception& e)
    {
        std::cout << e.what() << '\n';
    }
}
```

---

Now:

```cpp
Date bad(99, 50, 2026);
```

throws error.

# Step 5 — Add member functions

Date object-க்கு useful operations.

```cpp
#include <iostream>

class Date
{
private:
    int day;
    int month;
    int year;

public:
    Date(int d, int m, int y)
        : day(d), month(m), year(y)
    {
    }

    int get_day() const
    {
        return day;
    }

    int get_month() const
    {
        return month;
    }

    int get_year() const
    {
        return year;
    }

    void print() const
    {
        std::cout
            << day << '/'
            << month << '/'
            << year << '\n';
    }

    void add_day(int n)
    {
        day += n;
    }
};

int main()
{
    Date today(23, 5, 2026);

    today.print();

    today.add_day(5);

    today.print();
}
```

Output:

```text
23/5/2026
28/5/2026
```

# Professional Version

இது Stroustrup style-க்கு நெருக்கமான clean implementation:

```cpp
#include <iostream>
#include <stdexcept>

class Date
{
private:
    int day_;
    int month_;
    int year_;

    bool valid(int d, int m) const
    {
        return d >= 1 &&
               d <= 31 &&
               m >= 1 &&
               m <= 12;
    }

public:
    Date(int d, int m, int y)
        : day_(d),
          month_(m),
          year_(y)
    {
        if (!valid(d, m))
        {
            throw std::runtime_error("Invalid date");
        }
    }

    int day() const
    {
        return day_;
    }

    int month() const
    {
        return month_;
    }

    int year() const
    {
        return year_;
    }

    void add_day(int n)
    {
        day_ += n;
    }

    void print() const
    {
        std::cout
            << day_
            << '/'
            << month_
            << '/'
            << year_
            << '\n';
    }
};

int main()
{
    Date birthday(14, 8, 1954);

    birthday.print();

    birthday.add_day(10);

    birthday.print();
}
```
