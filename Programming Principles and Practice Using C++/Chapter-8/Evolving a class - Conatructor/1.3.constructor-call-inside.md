## `Date today(23, 5, 2026);` — Constructor Call

### முன்பு என்ன இருந்தது vs இப்போது என்ன இருக்கு?

| | Struct (முன்பு) | Class (இப்போது) |
|---|---|---|
| Initialization | `{23, 5, 2026}` | `(23, 5, 2026)` |
| Method | Aggregate Init | Constructor Call |
| Members | Public | **Private** |
| Control | இல்லை | உள்ளது |

---

### Step 1 — Class-ஐ Compiler பார்க்கும்

```cpp
class Date
{
private:
    int day;    // வெளியே access ❌
    int month;  // வெளியே access ❌
    int year;   // வெளியே access ❌

public:
    Date(int d, int m, int y)  // ← இதுதான் Constructor
    { ... }
};
```

Members **private** ஆனதால் — direct `{23, 5, 2026}` aggregate init **இனி வேலை செய்யாது!**

```cpp
Date today {23, 5, 2026};  // ❌ Compile Error — private members!
Date today (23, 5, 2026);  // ✅ Constructor மூலம் மட்டும்
```

---

### Step 2 — `Date today(23, 5, 2026);` என்ன செய்யும்?

```
Date today (23,  5,  2026);
            ↓    ↓     ↓
           int  int   int
            ↓    ↓     ↓
            d    m     y      ← Constructor parameters
```

Constructor call ஆகும்:
```cpp
Date(int d, int m, int y)
{
    day   = d;   // day   = 23
    month = m;   // month = 5
    year  = y;   // year  = 2026
}
```

---

### Step 3 — Stack-ல் Memory

```
Stack frame (main):
┌──────────────────────────────┐
│  today                       │
│  ┌────────┬────────┬───────┐ │
│  │  day   │ month  │  year │ │
│  │   23   │   5    │  2026 │ │
│  └────────┴────────┴───────┘ │
│   [private — direct access இல்லை]  │
└──────────────────────────────┘
```

Memory layout **same** — ஆனால் இப்போது **constructor மட்டுமே** write செய்யும்.

---

### Step 4 — `today.print()` எப்படி வேலை செய்யும்?

```cpp
void print()
{
    std::cout << day << '/' << month << '/' << year << '\n';
}
```

`print()` — class-க்கு **உள்ளே** இருக்கும் — அதனால் private members-ஐ access செய்யலாம்.

```
today.print() → 23/5/2026
```

---

### முக்கியமான Difference

```cpp
// Struct — யாரும் மாற்றலாம் ⚠️
Date d;
d.day = 999;   // ✅ allowed — ஆனால் valid-ஆ?

// Class — constructor மட்டுமே மாற்றும் ✅
Date today(23, 5, 2026);
today.day = 999;  // ❌ Compile Error — private!
```

> **Private + Constructor** = Data-ஐ **யார் வேண்டுமானாலும் மாற்றமுடியாது** — இதுதான் **Encapsulation!**

---

### சுருக்கம்

```
Date today (23, 5, 2026);
     ↓           ↓
  Object       Constructor arguments
  உருவாகும்    உள்ளே pass ஆகும்
                    ↓
             day=23, month=5, year=2026
             private-ஆக safe-ஆக store ஆகும்
```

**Struct → யாரும் directly போடலாம்**
**Class → Constructor வழியாக மட்டுமே போகும்!**

-----------------------

`அதாவது pass ஆகக்கூடிய argument கூட this pointer -ரும் சேர்ந்து பாஸ் ஆகுமா?`

ஆமா! சரியாக புரிந்துகொண்டீர்கள்!

## `this` Pointer — Internally என்ன நடக்குது?

### நீங்கள் எழுதுவது:
```cpp
Date today(23, 5, 2026);
```

### Compiler internally இப்படி treat செய்யும்:
```cpp
Date::Date(&today, 23, 5, 2026);
//          ↑
//     this pointer — secretly pass ஆகும்!
```

---

### Constructor-உள்ளே என்ன நடக்குது?

நீங்கள் எழுதுவது:
```cpp
Date(int d, int m, int y)
{
    day   = d;
    month = m;
    year  = y;
}
```

Compiler பார்ப்பது:
```cpp
Date(Date* this, int d, int m, int y)
{
    this->day   = d;   // today.day   = 23
    this->month = m;   // today.month = 5
    this->year  = y;   // today.year  = 2026
}
```

`this` = **`today` object-இன் memory address.**

---

### Memory-ல் எப்படி இருக்கும்?

```
Stack:
┌─────────────────────────────────┐
│  today  (address: 0x100)        │
│  ┌────────┬────────┬──────────┐ │
│  │  day   │ month  │   year   │ │
│  │   23   │   5    │   2026   │ │
│  └────────┴────────┴──────────┘ │
└─────────────────────────────────┘
        ↑
   this = 0x100  ← இந்த address constructor-க்கு pass ஆகும்
```

---

### `this`-ஐ explicitly எழுதலாம்:

```cpp
Date(int d, int m, int y)
{
    this->day   = d;   // same result
    this->month = m;
    this->year  = y;
}
```

Parameter பெயர் member பெயரோடு same-ஆக இருந்தால் **`this` அவசியம்:**

```cpp
Date(int day, int month, int year)
{
    day   = day;        // ❌ wrong — parameter தன்னையே assign!
    this->day = day;    // ✅ correct — member = parameter
}
```

---

### சுருக்கம்:

```
Date today(23, 5, 2026);
              ↓
compiler internally:
Date::Date( &today,  23,    5,   2026 )
              ↓       ↓     ↓      ↓
            this      d     m      y
              ↓
        this->day=23, this->month=5, this->year=2026
```

> **`this`** என்பது **hidden first argument** — எல்லா member functions-க்கும் automatically pass ஆகும்!
