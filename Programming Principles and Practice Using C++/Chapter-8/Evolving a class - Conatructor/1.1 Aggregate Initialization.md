## `Date today {23, 5, 2026};` — Aggregate Initialization

இது **aggregate initialization** என்று அழைக்கப்படும்.

### `Date` struct என்ன?

```cpp
struct Date {
    int day;    // member 1
    int month;  // member 2
    int year;   // member 3
};
```

`Date` ஒரு **aggregate** — ஏனென்றால்:
- User-declared constructor இல்லை
- Private/protected members இல்லை
- Base classes இல்லை

---

### Internally என்ன நடக்குது?

```cpp
Date today {23, 5, 2026};
```

Compiler இதை இப்படி interpret செய்யும்:

```
today.day   = 23
today.month = 5
today.year  = 2026
```

**Declaration order படி**, ஒவ்வொரு value-உம் ஒவ்வொரு member-க்கு **in-order** assign ஆகும். இதை **brace-enclosed initializer list** மூலம் செய்கிறோம்.

---

### Memory-ல் எப்படி இருக்கும்?

```
Stack:
┌────────┬─────────┬──────────┐
│  day   │  month  │   year   │
│  (23)  │   (5)   │  (2026)  │
└────────┴─────────┴──────────┘
  4 bytes  4 bytes   4 bytes
```

`today` என்பது stack-ல் allocate ஆகும்.

---

### முக்கியமான விஷயங்கள்

| சூழல் | என்ன ஆகும் |
|---|---|
| `Date d {23, 5}` | `year = 0` (zero-initialized) |
| `Date d {}` | எல்லாமே `0` |
| `Date d {23, 5, 2026, 99}` | **Compile error** — members அதிகமாக இருக்கு |
| `Date d (23, 5, 2026)` | **Compile error** — constructor இல்லை |

---

### `=` உடன் vs இல்லாமல்

```cpp
Date today = {23, 5, 2026};  // copy-list-initialization — same result
Date today {23, 5, 2026};    // direct-list-initialization — same result
```

இரண்டும் C++11-ல் ஒரே மாதிரி செயல்படும். Modern C++-ல் `{}` syntax preferred.
