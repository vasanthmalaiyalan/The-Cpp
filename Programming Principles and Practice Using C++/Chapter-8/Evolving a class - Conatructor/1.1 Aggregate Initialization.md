## `Date today {23, 5, 2026};` — Aggregate Initialization

இது **aggregate initialization** என்று அழைக்கப்படும்.

### `Date` struct என்ன?

```cpp
struct Date {
    int day;    // member 1
    int month;  // member 2
    int year;   // member 3
};
```

`Date` ஒரு **aggregate** — ஏனென்றால்:
- User-declared constructor இல்லை
- Private/protected members இல்லை
- Base classes இல்லை

---

### Internally என்ன நடக்குது?

```cpp
Date today {23, 5, 2026};
```

Compiler இதை இப்படி interpret செய்யும்:

```
today.day   = 23
today.month = 5
today.year  = 2026
```

**Declaration order படி**, ஒவ்வொரு value-உம் ஒவ்வொரு member-க்கு **in-order** assign ஆகும். இதை **brace-enclosed initializer list** மூலம் செய்கிறோம்.

---

### Memory-ல் எப்படி இருக்கும்?

```
Stack:
┌────────┬─────────┬──────────┐
│  day   │  month  │   year   │
│  (23)  │   (5)   │  (2026)  │
└────────┴─────────┴──────────┘
  4 bytes  4 bytes   4 bytes
```

`today` என்பது stack-ல் allocate ஆகும்.

---

### முக்கியமான விஷயங்கள்

| சூழல் | என்ன ஆகும் |
|---|---|
| `Date d {23, 5}` | `year = 0` (zero-initialized) |
| `Date d {}` | எல்லாமே `0` |
| `Date d {23, 5, 2026, 99}` | **Compile error** — members அதிகமாக இருக்கு |
| `Date d (23, 5, 2026)` | **Compile error** — constructor இல்லை |

---

### `=` உடன் vs இல்லாமல்

```cpp
Date today = {23, 5, 2026};  // copy-list-initialization — same result
Date today {23, 5, 2026};    // direct-list-initialization — same result
```

இரண்டும் C++11-ல் ஒரே மாதிரி செயல்படும். Modern C++-ல் `{}` syntax preferred.

-----------------

`internally இப்படி போடும்போது `Date d1 {23, 5, 2026};` compailer எப்படி assign செய்கிறது?`

## Compiler எப்படி Assign செய்கிறது?

### Step 1 — Compiler struct-ஐ பார்க்கும்

```cpp
struct Date
{
    int day;    // index 0
    int month;  // index 1
    int year;   // index 2
};
```

Compiler **declaration order-ல்** members-ஐ list செய்து வைத்துக்கொள்ளும்.

---

### Step 2 — Brace values-ஐ order-ப்படி match செய்யும்

```cpp
Date d1 {23, 5, 2026};
//        ↓   ↓    ↓
//       day month year
```

```
Position 0  →  day   = 23
Position 1  →  month = 5
Position 2  →  year  = 2026
```

**Left to right, top to bottom** — இதுதான் rule.

---

### Step 3 — Stack-ல் memory allocate செய்யும்

```
Stack frame (main):
┌──────────────────────────────┐
│  d1                          │
│  ┌────────┬────────┬───────┐ │
│  │  day   │ month  │  year │ │
│  │   23   │   5    │  2026 │ │
│  └────────┴────────┴───────┘ │
│   address: 100  104     108  │
└──────────────────────────────┘
   (ஒவ்வொரு int-உம் 4 bytes)
```

---

### Step 4 — Compiler உள்ளே என்ன generate செய்யும்?

நீங்கள் எழுதுவது:
```cpp
Date d1 {23, 5, 2026};
```

Compiler இதை internally இப்படி treat செய்யும்:
```cpp
Date d1;
d1.day   = 23;
d1.month = 5;
d1.year  = 2026;
```

**ஒரே result — வேறு syntax மட்டும்.**

---

### Order மாறினால் என்ன ஆகும்?

```cpp
struct Date
{
    int year;   // இப்போது year முதலில்!
    int month;
    int day;
};

Date d1 {23, 5, 2026};
//        ↓   ↓    ↓
//       year month day   ← தவறான data!
```

```
year  = 23    ❌
month = 5     ✅
day   = 2026  ❌
```

> Compiler **struct declaration order-ஐ மட்டும்** பார்க்கும் — variable பெயரை பார்க்காது!

---

### சுருக்கம்

```
{23,  5,  2026}
  ↓   ↓     ↓
 [0] [1]   [2]   ← brace position
  ↓   ↓     ↓
 day month year  ← struct member order
```

**Rule: Brace position = Struct member position. இவ்வளவுதான்!**
