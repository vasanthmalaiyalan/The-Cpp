இந்த **§8.5 Enumerations**-ல் Stroustrup சொல்லும் முக்கிய கருத்து:

> **"Magic numbers-ஐ பயன்படுத்தாதீர்கள். அதற்கு பதிலாக meaningful names பயன்படுத்துங்கள்."**

உதாரணம்:

```cpp
int month = 2;
```

இந்த `2` என்ன?

* February?
* Version 2?
* Error code 2?

புரியாது.

---

# Enumeration என்றால் என்ன?

Enumeration (`enum`) என்பது:

```text
related named constants
```

உருவாக்கும் ஒரு user-defined type.

---

# Book Example

```cpp
enum class Month {
    jan = 1,
    feb,
    mar,
    apr,
    may,
    jun,
    jul,
    aug,
    sep,
    oct,
    nov,
    dec

```

---

Compiler internally:

```text
jan = 1
feb = 2
mar = 3
apr = 4
...
dec = 12
```

# Why no values after jan?

Because compiler automatically continues.

```cpp
enum class Month {
    jan = 1,
    feb,
    mar
};
```

becomes:

```text
jan = 1
feb = 2
mar = 3
```

---

# Manual version (avoid)

```cpp
enum class Month {
    jan = 1,
    feb = 2,
    mar = 3,
    apr = 4,
    may = 5
};
```

Works.

But tedious.

---

# Why enum class?

Old C style:

```cpp
enum Month {
    jan,
    feb,
    mar
};
```

Then:

```cpp
Month m = feb;
```

works.

---

Modern C++:

```cpp
enum class Month {
    jan,
    feb,
    mar
};
```

Now:

```cpp
Month m = Month::feb;
```

must be written.

---

This avoids name conflicts.

# Book Example Errors

### Error #1

```cpp
Month m2 = feb;
```

Compiler error.

Because:

```cpp
feb
```

not in current scope.

Must write:

```cpp
Month m2 = Month::feb;
```

---

### Error #2

```cpp
Month m3 = 7;
```

Compiler error.

---

Why?

Because:

```cpp
Month
```

and

```cpp
int
```

are different types.

---

Compiler protects you.

# Explicit Conversion

Book:

```cpp
Month m4 = Month{7};
```

Allowed.

---

Meaning:

```text
I know what I am doing.
Convert 7 into Month.
```

---

Example

```cpp
#include <iostream>

enum class Month
{
    jan = 1,
    feb,
    mar,
    apr,
    may,
    jun,
    jul,
    aug,
    sep,
    oct,
    nov,
    dec
};

int main()
{
    Month m{7};

    std::cout << "created\n";
}
```

---

But dangerous:

```cpp
Month m{999};
```

Compiler allows.

---

Yet:

```text
999 is not a real month
```

# Therefore Book Creates Checking Function

```cpp
Month int_to_month(int x)
{
    if(x < 1 || x > 12)
    {
        throw std::runtime_error("bad month");
    }

    return Month{x};
}
```

---

Usage

```cpp
Month m = int_to_month(7);
```

Valid.

---

```cpp
Month m = int_to_month(999);
```

Throws exception.

# Complete Book-Oriented Example

```cpp
#include <iostream>
#include <stdexcept>

enum class Month
{
    jan = 1,
    feb,
    mar,
    apr,
    may,
    jun,
    jul,
    aug,
    sep,
    oct,
    nov,
    dec
};

int to_int(Month m)
{
    return static_cast<int>(m);
}

Month int_to_month(int x)
{
    if(x < to_int(Month::jan)
       ||
       x > to_int(Month::dec))
    {
        throw std::runtime_error("bad month");
    }

    return Month{x};
}

int main()
{
    try
    {
        Month m = int_to_month(7);

        std::cout
            << to_int(m)
            << '\n';
    }
    catch(const std::exception& e)
    {
        std::cout
            << e.what()
            << '\n';
    }
}
```

Output:

```text
7
```

# Why to_int()?

Book:

```cpp
int to_int(Month m)
{
    return static_cast<int>(m);
}
```

---

Because:

```cpp
Month m = Month::feb;
```

cannot automatically become:

```cpp
int x = m;
```

Compiler error.

---

Need explicit conversion:

```cpp
int x = to_int(m);
```

---

or:

```cpp
int x = static_cast<int>(m);
```

# Why Enum Better Than int?

Bad:

```cpp

```

Compiler accepts.

---

Good:

```cpp

```

Only valid choices exist.

# What Stroustrup Wants You To Learn

Instead of:

```cpp
int month = 2;
```

use:

```cpp
Month month = Month::feb;
```

Benefits:

```text
Readable
Type-safe
Prevents invalid assignments
Avoids magic numbers
Represents concepts directly
```

This matches the same philosophy used for the `Date` class:

> Create types that model real-world concepts and prevent invalid values whenever possible.
