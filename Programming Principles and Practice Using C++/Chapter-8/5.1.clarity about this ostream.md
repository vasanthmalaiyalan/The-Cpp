```

                              இவை மட்டும் handle செய்தார்கள்
```

சுருக்கமா — `cout` prebuilt types மட்டும் அறியும், நம்முடைய custom class-ஐ **நாமே சொல்லிக் கொடுக்கணும்!**

`today.month()` value return செய்யுது — cout அந்த int-ஐ print செய்யும். ஆனால் `today` என்பது **முழு object** — அதை எப்படி print செய்வது cout-க்கு தெரியாது!

`அதாவது `<<`இந்த operator call ஆன உடனே இது வேலை செய்ய ஆரம்பித்துவிடுமா `operator<<(std::ostream& os, Date d)

## Analogy:

```
+ போட்டால் → addition வேலை செய்யும்
- போட்டால் → subtraction வேலை செய்யும்
<< போட்டால் → நாம் define செய்த operator<< வேலை செய்யும்
```

Compiler `<<` பார்க்கும்போது:

```
இடதுபுறம் → ostream (cout)?
வலதுபுறம் → Date object?

✅ இரண்டும் match ஆச்சு!

```

சுருக்கமா — `<<` என்பது ஒரு **trigger**, அது பார்த்த உடனே compiler நம்முடைய `operator<<` function-ஐ automatically call செய்துவிடும்!

---------------------------

`அப்படி வேலை செய்து அதுடைய `os << d.year() << '/' << d.month() << '/'` first address return செய்துவிடுமா? இல்லை மொத்தத்தையும் ரிட்டர்ன் செய்யுமா?`

`os` (cout) reference return செய்யும் — value இல்லை!

ஒவ்வொரு step-லயும் **print ஆகிவிடும்** — கடைசியில் `os` return ஆகும்!

**மொத்தத்தையும் collect செய்து return இல்லை** — ஒவ்வொன்னா print ஆகும், கடைசியில் chain-க்காக `os` return ஆகும்!

`os` return ஆனதால் — அதே cout-ல் `'\n'` directly built-in handle செய்துவிடும்!

-------------------------

`operator<< , அதாவது நம்முடைய ஆப்பரேட்டர் எதிர்பார்ப்பது object but char உள்ளதால் அது வேலை செய்யாது right`

ஆமா! 100% சரி!

## ஏன் வேலை செய்யாது:

```cpp
operator<<(std::ostream& os, Date d)
//                            ↑
//                       Date மட்டும் எதிர்பார்க்கும்!
//                       '\n' char — match ஆகாது!
```

---

## அதனால் என்னாகும்:

```cpp
os << '\n'
// ↑
// நம்முடைய operator<< — Date எதிர்பார்க்கும், char வந்தது — skip!
// cout-ஓட built-in operator<< — char தெரியும் — இது handle செய்யும்!
```

---

## Compiler எப்படி decide செய்யும்:

```
'\n' வந்தது
    ↓
நம்முடைய operator<< பார்க்கும் — Date? இல்லை! — skip
    ↓
cout built-in operator<< பார்க்கும் — char? ஆமா! — handle!
    ↓
'\n' print ஆகும்
```

சுருக்கமா — compiler argument-ஐ பார்த்து **matching operator<< தேர்வு செய்யும்** — இதை **Function Overload Resolution** என்று சொல்வார்கள்!
