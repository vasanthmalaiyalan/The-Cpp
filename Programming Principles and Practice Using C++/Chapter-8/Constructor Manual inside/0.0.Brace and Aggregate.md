`இது மட்டும் `{} — Internally எப்படி:
Date today{2025, 12, 31};` first initialisation ஆகிவிட்டு constructor call ஆகும் அதுதானே`

இல்லை! அந்த புரிதல் தவறு.

## உண்மை என்னன்னா:

```cpp
Date today{2025, 12, 31};
```

இங்க **முதலில் initialization இல்லை**, நேரடியாக constructor call ஆகும் — `()` மாதிரியே!

---

## நீங்கள் நினைப்பது:

```
Step 1: today.y = 2025  ← direct set
Step 2: today.m = 12    ← direct set  
Step 3: today.d = 31    ← direct set
Step 4: Constructor call  ← அதுக்கு அப்புறம்
```
❌ இப்படி இல்லை!

---

## உண்மையில் நடப்பது:

```
Step 1: Constructor call — Date::Date(&today, 2025, 12, 31)
Step 2: Constructor உள்ளே y, m, d set ஆகும்
```
✅ இப்படித்தான்!

---

## Aggregate init மட்டும் தான் direct set:

```cpp
// Constructor இல்லாத struct மட்டும்:
struct Point { int x, y; };

Point p{10, 20};
// இங்க மட்டும்தான்:
// Step 1: p.x = 10  ← direct
// Step 2: p.y = 20  ← direct
// Constructor இல்லையே!
```

---

## Key Rule:

| Struct | `{}` என்னாகும் |
|---|---|
| Constructor இருந்தால் | நேரடியாக Constructor call |
| Constructor இல்லாவிட்டால் | Aggregate init (direct set) |

`{}` பார்க்கும்போது compiler **முதலில் constructor தேடும்** — இருந்தால் அதை call செய்யும், இல்லாவிட்டால் மட்டும் direct set செய்யும்!
