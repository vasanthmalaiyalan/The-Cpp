``Month operator++(Month& m)
{
    m =
        (m == Month::dec)
        ? Month::jan
        : Month{to_int(m)+1};

    return m;
}`இதில் இந்த பகுதி என்ன செய்யும் என்பதை சொல்லு `Month{to_int(m)+1};` because இப்படி ஆகும் போது Month{11} -> without constructor aggregate initialisation ஆகும் தானே ஆனால் இது வெறும் 11 என்று உள்ளதால் இது எங்கே போய் எதனுடன் initialisation ஆகும்?`

மிக நல்ல கேள்வி. இது C++11 **enum class conversion syntax**-ஐ புரிந்துகொள்ளும் இடம்.

இந்த code:

```cpp
Month{to_int(m)+1}
```

ஐப் பார்த்து நீங்கள் நினைப்பது:

```cpp
Month{11}
```

அதாவது:

> "Month-க்கு constructor இல்லையே? அப்படியானால் இந்த 11 எங்கே initialize ஆகிறது?"

என்பது.

---

## முதலில் Month என்ன?

```cpp
enum class Month {
    jan=1, feb, mar, apr, may, jun,
    jul, aug, sep, oct, nov, dec
};
```

இது class அல்ல.

இது enum type.

---

## enum class-க்கும் underlying value இருக்கும்

Compiler உள்ளே சுமார் இப்படி நினைக்கலாம்:

```cpp
jan = 1
feb = 2
mar = 3
...
nov = 11
dec = 12
```

---

## to_int(m)

Suppose:

```cpp
Month m = Month::oct;
```

அப்போ:

```cpp
to_int(m)
```

returns:

```cpp
10
```

---

பிறகு:

```cpp
to_int(m)+1
```

becomes:

```cpp
11
```

---

அப்போ expression:

```cpp
Month{to_int(m)+1}
```

becomes:

```cpp
Month{11}
```

---

## இது aggregate initialization அல்ல

இதுதான் முக்கியமான point.

பலர் இதை:

```cpp
struct X {
    int a;
};

X x{11};
```

போல aggregate initialization என்று நினைப்பார்கள்.

இல்லை.

`Month` struct அல்ல.

---

## இது direct-list-initialization

Compiler:

```cpp
Month{11}
```

பார்த்தவுடன்:

> "11 என்ற integer value-ஐ Month enum value ஆக explicit conversion செய்"

என்று புரிந்து கொள்கிறது.

சுமார் equivalent:

```cpp
static_cast<Month>(11)
```

---

அதாவது:

```cpp
Month{11}
```

≈

```cpp
static_cast<Month>(11)
```

---

## Constructor இல்லை

இதில் constructor call ஆகவில்லை.

ஏனெனில் enum class-க்கு constructor define செய்ய முடியாது.

Stroustrup இதையே சொல்கிறார்:

> We cannot define a constructor for an enumeration

---

அதனால்:

```cpp
Month{11}
```

என்பது:

```cpp
11
↓
explicit enum conversion
↓
Month value whose underlying representation is 11
```

```cpp
Month m = Month{11};
```

இப்போது:

```cpp
to_int(m)
```

returns:

```cpp
11
```

அதாவது:

```cpp
Month::nov
```

## Wrap-around code எப்படி வேலை செய்கிறது?

```cpp
Month operator++(Month& m)
{
    m =
        (m == Month::dec)
        ? Month::jan
        : Month{to_int(m)+1};

    return m;
}
```

Suppose:

```cpp
m = Month::oct;
```

---

Step 1:

```cpp
m == Month::dec
```

↓

```cpp
false
```

---

Step 2:

```cpp
Month{to_int(m)+1}
```

↓

```cpp
Month{10+1}
```

↓

```cpp
Month{11}
```

↓

```cpp
Month::nov
```

---

Step 3:

```cpp
m = Month::nov;
```

---

Result:

```cpp
++m;
```

changes:

```cpp
oct → nov
```

## Interesting detail

Compiler actually allows:

```cpp
Month bad = Month{999};
```

(implementation-dependent, but generally accepted as explicit enum conversion)

இதனால்:

```cpp
bad
```

ஒரு valid month அல்ல.

அதனால்தான் புத்தகத்தில்:

```cpp
Month int_to_month(int x)
{
    if(x < 1 || x > 12)
        error("bad month");

    return Month{x};
}
```

என்று validation function எழுதுகிறார்.

### Mental model

இதைப் பார்த்தால்:

```cpp
Month{11}
```

இப்படி நினைக்கவும்:

```cpp
Convert integer 11
        ↓
to Month enum value
```

**"11-ஐ Month object-ன் field-க்கு initialize செய்"** என்று அல்ல.

ஏனெனில் enum class-க்கு fields இல்லை, constructor இல்லை, aggregate members இல்லை.

இது வெறும் **explicit enum conversion** மட்டுமே.
