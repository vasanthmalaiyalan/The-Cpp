``Month operator++(Month& m)
{
    m =
        (m == Month::dec)
        ? Month::jan
        : Month{to_int(m)+1};

    return m;
}`இதில் இந்த பகுதி என்ன செய்யும் என்பதை சொல்லு `Month{to_int(m)+1};` because இப்படி ஆகும் போது Month{11} -> without constructor aggregate initialisation ஆகும் தானே ஆனால் இது வெறும் 11 என்று உள்ளதால் இது எங்கே போய் எதனுடன் initialisation ஆகும்?`

மிக நல்ல கேள்வி. இது C++11 **enum class conversion syntax**-ஐ புரிந்துகொள்ளும் இடம்.

இந்த code:

```cpp

```

ஐப் பார்த்து நீங்கள் நினைப்பது:

```cpp
Month{11}
```

அதாவது:

> "Month-க்கு constructor இல்லையே? அப்படியானால் இந்த 11 எங்கே initialize ஆகிறது?"

என்பது.

### Mental model

இதைப் பார்த்தால்:

```cpp
Month{11}
```

இப்படி நினைக்கவும்:

```cpp
Convert integer 11
        ↓
to Month enum value
```

**"11-ஐ Month object-ன் field-க்கு initialize செய்"** என்று அல்ல.

ஏனெனில் enum class-க்கு fields இல்லை, constructor இல்லை, aggregate members இல்லை.

இது வெறும் **explicit enum conversion** மட்டுமே.



-------------------------

`அதாவது இதை பார்க்கும் போது `Month{11}` இதில் வெறும் 11 என்று மட்டும் தான் உள்ளது அப்படி இருக்கும்போது அந்தப் 11 பார்த்தவுடன் compailer nov என்று முடிவு செய்து விடுமா?`

கிட்டத்தட்ட சரி. ஆனால் ஒரு முக்கியமான நுணுக்கம் இருக்கிறது.

Compiler **`11` பார்த்தவுடன் `nov` என்று lookup செய்து கண்டுபிடிக்காது**.

அது உண்மையில் செய்வது:

```cpp
Month{11}
```

↓

```cpp
(static_cast<Month>(11))
```

என்பதற்கு சமமான conversion.

அதாவது compiler நினைப்பது:

> "11 என்ற underlying integer value கொண்ட Month object ஒன்றை உருவாக்கு"

என்று.

---

mar = 3
...

nov = 11
dec = 12

என்று வைத்திருக்கும்.

## முதலில் Aggregate Initialization எப்போது?

## அப்போ compiler என்ன செய்கிறது?

C++ grammar-ல் enum-க்கு ஒரு special rule இருக்கிறது.

```cpp
Month{11}
```

என்றால்:

> underlying integer value 11-ஐ Month type-ஆக explicit conversion செய்

என்று பொருள்.

அதாவது:

```cpp
Month{11}
```

≈

```cpp
static_cast<Month>(11)
```

## Constructor இல்லையே?

ஆம்.

Enum-க்கு constructor எழுத முடியாது.

இது invalid:

```cpp
enum class Month
{
    jan,
    feb,

    Month(int); // ❌ impossible
};
```

Enum class-க்கு:

* constructor இல்லை
* member variables இல்லை
* aggregate members இல்லை

## Compiler எப்படி முடிவு செய்கிறது?

C++ standard சொல்கிறது:

Enum type மீது:

```cpp
E{value}
```

என்றால்

```cpp
explicit conversion to enum E
```

ஆக interpret செய்ய வேண்டும்.

அதனால் compiler:

```cpp
Month{11}
```

பார்த்தவுடன்:

```text
aggregate?
    no

constructor?
    no

enum?
    yes

=> explicit enum conversion
```

என்று தேர்வு செய்கிறது.

## நினைவில் வைக்க ஒரு Rule

`T{...}` பார்த்தால் compiler சுமார் இப்படி யோசிக்கும்:

```text
1. constructor இருக்கிறதா?
      yes -> constructor call

2. aggregate type ஆ?
      yes -> aggregate initialization

3. enum type ஆ?
      yes -> enum conversion

4. இல்லையெனில்
      normal list initialization rules
```

அதனால்:

```cpp
Month{11}
```

aggregate initialization அல்ல.

ஏனெனில் aggregate செய்ய member-கள் எதுவும் இல்லை.

அது enum என்பதால் compiler அதை **explicit enum conversion** ஆக எடுத்துக்கொள்கிறது.
