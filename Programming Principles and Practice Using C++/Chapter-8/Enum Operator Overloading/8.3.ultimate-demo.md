ஆம். இதை **"enum object என்றால் என்ன? enumerator என்றால் என்ன? address எதற்கு இருக்கும்?"** என்பதைக் கண் முன்னால் காட்டும் code பார்ப்போம்.

---

# Example 1 — `Month::feb` ஒரு object அல்ல

```cpp
#include <iostream>

enum class Month
{
    jan = 1,
    feb = 2,
    mar = 3
};

int main()
{
    Month m = Month::feb;

    std::cout << "Month object created\n";
}
```

இங்கே:

```cpp
Month::feb
```

ஒரு **enumerator constant**

```cpp
m
```

ஒரு **object**

---

Memory:

```text
Month::feb
    |
    +----> constant value 2

m
    |
    +----> stores value 2
```

---

# Example 2 — object-க்கு address இருக்கிறது

```cpp
#include <iostream>

enum class Month
{
    jan = 1,
    feb = 2,
    mar = 3
};

int main()
{
    Month m = Month::feb;

    std::cout << "address of m = "
              << &m
              << '\n';
}
```

Output:

```text
address of m = 0x7ff...
```

ஏனெனில்:

```cpp
m
```

object.

Object ⇒ memory ⇒ address.

# Example 3 — enumerator-க்கு address எடுக்க முடியாது

Compile error:

ஏன்?

ஏனெனில்:

```cpp
Month::feb
```

object அல்ல.

Constant value.

இதையே:

```cpp
&10;
```

எழுதினால் error வரும்.

# Example 4 — underlying value பார்க்க

```cpp
#include <iostream>

enum class Month
{
    jan = 1,
    feb = 2,
    mar = 3
};

int main()
{
    Month m = Month::feb;

    std::cout
        << static_cast<int>(m)
        << '\n';
}
```

Output:

```text
2
```

இதன் பொருள்:

```text
m stores value 2
```

---

Memory:

```text
m
 |
 +----> 2
```

# Example 5 — `Month{2}` என்ன செய்கிறது?

```cpp
#include <iostream>

enum class Month
{
    jan = 1,
    feb = 2,
    mar = 3
};

int main()
{
    Month m{2};

    if (m == Month::feb)
    {
        std::cout << "same value\n";
    }
}
```

Output:

```text
same value
```

---

இங்கே:

```cpp
Month{2}
```

aggregate initialization அல்ல.

Compiler roughly:

```cpp
Month m =
    static_cast<Month>(2);
```

போல செய்கிறது.

# Example 6 — aggregate initialization எப்படி இருக்கும்?

```cpp
#include <iostream>

struct Point
{
    int x;
    int y;
};

int main()
{
    Point p{10,20};

    std::cout
        << p.x << ' '
        << p.y
        << '\n';
}
```

Output:

```text
10 20
```

இங்கே:

```cpp
10 -> x
20 -> y
```

---

Memory:

```text
p
├── x = 10
└── y = 20
```

இதுதான் aggregate initialization.

# Compare Side-by-Side

### Struct

```cpp
struct Point
{
    int x;
    int y;
};

Point p{10,20};
```

Compiler:

```text
10 -> x
20 -> y
```

---

### Enum

```cpp
enum class Month
{
    jan=1,
    feb=2,
    mar=3
};

Month m{2};
```

Compiler:

```text

   ↓
convert to Month
```

---

Field இல்லை.

Assign செய்ய member இல்லை.

அதனால் aggregate initialization ஆகாது.

# Ultimate Demo

இந்த code எல்லாவற்றையும் ஒரே நேரத்தில் காட்டும்:

```cpp
#include <iostream>

enum class Month
{
    jan = 1,
    feb = 2,
    mar = 3
};

struct Point
{
    int x;
    int y;
};

int main()
{
    Month m = Month::feb;

    std::cout
        << "Month value = "
        << static_cast<int>(m)
        << '\n';

    std::cout
        << "Address of object m = "
        << &m
        << '\n';

    Month m2{2};

    if (m2 == Month::feb)
    {
        std::cout
            << "Month{2} == Month::feb\n";
    }

    Point p{10,20};

    std::cout
        << "Point = "
        << p.x << ", "
        << p.y
        << '\n';
}
```

### Output

```text
Month value = 2
Address of object m = 0x7ffd...
Month{2} == Month::feb
Point = 10, 20
```

இதிலிருந்து நினைவில் வைத்துக்கொள்ள வேண்டிய மிக முக்கியமான 4 விதிகள்:

1. `Month::feb` → **enumerator constant** (object அல்ல)
2. `Month m = Month::feb;` → `m` மட்டும் object
3. `&m` ✔️ (address உண்டு)
4. `Month{2}` → **explicit enum conversion**, aggregate initialization அல்ல.
