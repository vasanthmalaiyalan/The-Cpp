இந்த **§8.6 Operator Overloading**-ல் Stroustrup சொல்லும் முக்கிய கருத்து:

> **"நீங்கள் உருவாக்கும் type-ஐ built-in type போல பயன்படுத்த முடியும்."**

உதாரணம்:

```cpp
int x = 5;
++x;
```

இங்கே `++` operator ஏற்கனவே `int`-க்கு வேலை செய்கிறது.

Stroustrup கேட்கிறார்:

> நம்முடைய `Month` type-க்கும் `++` வேலை செய்தால் எப்படி இருக்கும்?

---

# Problem Before Operator Overloading

நம்மிடம்:

```cpp
enum class Month
{
    jan = 1,
    feb,
    mar,
    apr,
    may,
    jun,
    jul,
    aug,
    sep,
    oct,
    nov,
    dec
};
```

Suppose:

```cpp
Month m = Month::oct;
```

அடுத்த மாதத்திற்கு செல்ல:

```cpp
m = Month::nov;
```

manually எழுத வேண்டும்.

---

அல்லது:

```cpp
m = Month{to_int(m)+1};
```

messy.

---

# Stroustrup's Idea

Why not write:

```cpp
++m;
```

just like:

```cpp
++x;
```

?

---

# Overloading ++

Book:

```cpp
Month operator++(Month& m)
{
    m = (m == Month::dec)
        ? Month::jan
        : Month{to_int(m)+1};

    return m;
}
```

---

# Understanding Slowly

Function name:

```cpp
operator++
```

means:

```text
This function defines ++

```

---

Argument:

```cpp
Month& m
```

Reference.

Because we want to modify original month.

# The ?: Operator

Book uses:

```cpp
condition ? value1 : value2
```

Meaning:

```cpp
if(condition)
    value1;
else
    value2;
```

---

Example:

```cpp
int x = 10;

int y =
    (x > 5)
    ? 100
    : 200;
```

Result:

```text
100
```

# Month Example

Book:

```cpp
m = (m == Month::dec)
        ? Month::jan
        : Month{to_int(m)+1};
```

Meaning:

If:

```cpp
m == Month::dec
```

then:

```cpp
m = Month::jan;
```

otherwise:

```cpp
m = next month;
```

---

# Wrap Around

This is the important idea.

```text
Jan → Feb → Mar → ...
                ↓
Dec ← ← ← ← ← ←
```

After December:

```cpp
++m;
```

becomes:

```cpp
January
```

again.

# Complete Book-Oriented Example

```cpp
#include <iostream>

enum class Month
{
    jan = 1,
    feb,
    mar,
    apr,
    may,
    jun,
    jul,
    aug,
    sep,
    oct,
    nov,
    dec
};

int to_int(Month m)
{
    return static_cast<int>(m);
}

Month operator++(Month& m)
{
    m =
        (m == Month::dec)
        ? Month::jan
        : Month{to_int(m)+1};

    return m;
}

int main()
{
    Month m = Month::oct;

    ++m;
    std::cout << to_int(m) << '\n';

    ++m;
    std::cout << to_int(m) << '\n';

    ++m;
    std::cout << to_int(m) << '\n';
}
```

Output:

```text
11
12
1
```

Meaning:

```text
oct
 ↓
nov
 ↓
dec
 ↓
jan
```

---

# Why This Is Nice?

Without operator overloading:

```cpp
next_month(m);
```

or

```cpp
m = Month{to_int(m)+1};
```

---

With operator overloading:

```cpp
++m;
```

Much more natural.

# Book-Oriented Version

```cpp
#include <iostream>
#include <vector>

enum class Month
{
    jan = 1,
    feb,
    mar,
    apr,
    may,
    jun,
    jul,
    aug,
    sep,
    oct,
    nov,
    dec
};

int to_int(Month m)
{
    return static_cast<int>(m);
}

std::vector<std::string> month_tbl
{
    "Not a month",
    "January",
    "February",
    "March",
    "April",
    "May",
    "June",
    "July",
    "August",
    "September",
    "October",
    "November",
    "December"
};

std::ostream&
operator<<(std::ostream& os,
           Month m)
{
    return os
        << month_tbl[to_int(m)];
}

int main()
{
    Month m = Month::mar;

    std::cout << m << '\n';
}
```

Output:

```text
March
```

# Most Important Rule

You can overload existing operators only.

Allowed:

```cpp
+
-
*
/
[]
()
==
<
>
<<
>>
++
--
```

---

Not allowed:

```cpp
**
@@
%%%
```

Compiler rejects.

---

# Example

Allowed:

```cpp
Vector operator+
(
    const Vector& a,
    const Vector& b
);
```

---

Not allowed:

```cpp
Vector operator**
(
    const Vector& a,
    const Vector& b
);
```

Compiler error.

---

# Must Have User-Defined Type

Book:

```cpp
int operator+(int,int);
```

Error.

---

Because:

```cpp
int
```

already built-in.

C++ won't let you redefine built-in arithmetic.

---

But:

```cpp
Vector operator+
(
    const Vector& a,
    const Vector& b
);
```

OK.

Because:

```cpp
Vector
```

is user-defined.

---

# Stroustrup's Most Important Advice

Good:

```cpp
+
means addition

*
means multiplication

[]
means indexing

()
means call
```

---

Bad:

```cpp
+
means delete file

*
means send email

==
means connect database
```

---

Don't surprise readers.

std::vector<std::string> month_tbl
{

### What Stroustrup wants you to learn

Operator overloading lets your own types behave naturally:

```cpp
++month;
cout << month;
vector1 + vector2;
date1 == date2;
```

instead of awkward function calls:

```cpp
increment(month);
print(month);
add(v1,v2);
equal(d1,d2);
```

But only overload operators when the meaning is obvious and conventional. That makes code easier to read and closer to normal mathematical notation.
