| Parameter       | Meaning                 |

```cpp id="3jlwm0"

```

Allowed.

Why?

`a`

# Next

```cpp id="2jlwm8"

```

Allowed.

Why?

`r`
directly refers to caller object.

# Original variable modified

# Main Professional Rules

Author gives GOLDEN RULES.

These are extremely important.

---

# Rule 1

## Use pass-by-value for very small objects

Examples:

* int
* double
* bool

---

# Why?

Copy cheap.

Simple.

---

# Rule 2

## Use const reference for large read-only objects

Examples:

* string
* vector
* large classes

---

# Why?

Avoid expensive copy.

---

# Rule 3

## Prefer return values over modifying references

---

# BEST .CPP EXAMPLE

```cpp id="1jlwm3"
import std;


// =====================================
// Pass-by-value
// =====================================

int increase(int value)
{
    value++;

    return value;
}


// =====================================
// Pass-by-const-reference
// =====================================

void print_vector(const std::vector<int>& values)
{
    std::cout << "{ ";

    for (int value : values)
    {
        std::cout << value << ' ';
    }

    std::cout << "}\n";


    // ERROR:
    //
    // values[0] = 100;
}


// =====================================
// Pass-by-reference
// =====================================

void initialize(std::vector<int>& values)
{
    for (int i = 0; i < values.size(); ++i)
    {
        values[i] = i * 10;
    }
}


// =====================================
// Swap using references
// =====================================

void swap_values(int& a,
                 int& b)
{
    int temp = a;

    a = b;

    b = temp;
}


// =====================================
// Main
// =====================================

int main()
{
    // ---------------------------------
    // Pass-by-value
    // ---------------------------------

    int x = 5;

    int result = increase(x);


    std::cout << "x after increase() : "
              << x
              << '\n';

    std::cout << "returned result    : "
              << result
              << '\n';


    // ---------------------------------
    // Pass-by-const-reference
    // ---------------------------------

    std::vector<int> numbers(5);

    initialize(numbers);


    std::cout << "\nVector contents:\n";

    print_vector(numbers);


    // ---------------------------------
    // Pass-by-reference
    // ---------------------------------

    int a = 10;

    int b = 20;


    std::cout << "\nBefore swap:\n";

    std::cout << "a = "
              << a
              << " b = "
              << b
              << '\n';


    swap_values(a, b);


    std::cout << "\nAfter swap:\n";

    std::cout << "a = "
              << a
              << " b = "
              << b
              << '\n';
}
```

# What this code teaches

| Concept                      | Example               |
| ---------------------------- | --------------------- |
| Pass-by-value                | `increase(int value)` |
| Copy only                    | original unchanged    |
| Const reference              | `const vector<int>&`  |
| Safe read-only access        | `print_vector()`      |
| Reference modification       | `vector<int>&`        |
| Direct mutation              | `initialize()`        |
| Multiple object modification | `swap_values()`       |

# Real-world Modern C++ Style

Professional code usually prefers:

```cpp id="9jlwm2"
const T&
```

by default.

Plain:

```cpp id="7jlwm2"
T&
```

used only when mutation intended.

This is one of the biggest readability conventions in modern C++.
