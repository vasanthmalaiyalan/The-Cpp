# Important Professional Rule

# Good Things in Headers

* function declarations
* class definitions
* constants
* templates

# Dangerous Things

Non-inline function definitions.

---

# Why dangerous?

Suppose:

```cpp id="9twmc1"

{
    return 1;
}
```

inside header.

Included in:
10 cpp files.

Now:
10 copies of f().

Linker chaos.
