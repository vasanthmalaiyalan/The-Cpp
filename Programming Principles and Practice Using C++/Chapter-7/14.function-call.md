```cpp
#include <iostream>
#include <string>

class Token
{
public:
    char kind;

    Token(char ch)
        : kind(ch)
    {
    }
};


class Token_stream
{
public:

    Token get()
    {
        return Token('+');
    }
};


// =====================================
// Forward declarations
// =====================================

double expression(Token_stream& ts);

double term(Token_stream& ts);

double primary(Token_stream& ts);


// =====================================
// expression()
// =====================================

double expression(Token_stream& ts)
{
    double left = term(ts);

    Token t = ts.get();

    std::cout
        << "expression() called\n";

    return left;
}


// =====================================
// term()
// =====================================

double term(Token_stream& ts)
{
    double left = primary(ts);

    Token t = ts.get();

    double d = 0;

    std::cout
        << "term() called\n";

    return left;
}


// =====================================
// primary()
// =====================================

double primary(Token_stream& ts)
{
    Token t = ts.get();

    std::cout
        << "primary() called\n";

    return 1;
}


// =====================================
// main()
// =====================================

int main()
{
    Token_stream ts;

    double result =
        expression(ts);

    std::cout
        << "result = "
        << result
        << '\n';
}
```

இந்த code book-oriented ஆக exactly இந்த concepts show செய்கிறது:

| Concept                     | Example                         |
| --------------------------- | ------------------------------- |
| Function activation records | expression(), term(), primary() |
| Function calls each other   | expression → term → primary     |
| Pass-by-reference           | `Token_stream& ts`              |
| Local variables             | `left`, `t`, `d`                |
| Forward declarations        | function declarations above     |
| Separate stack frames       | every call gets own locals      |
| No sneaky global variable   | `ts` passed explicitly          |

இந்த example-ன் main goal:

* parser logic அல்ல
* function call implementation internally எப்படி நடக்கிறது
  என்பதை காட்டுவது.
