## `->` Trailing Return Type — விளக்கம்

---

## `->` என்றால் என்ன?

```cpp
auto divide(double x, double y) -> double
//   ──────────────────────────    ──────
//   function signature             return type "இங்கே சொல்கிறோம்"
```

`->` = **"இந்த function இந்த type return பண்ணும்"** என்று பின்னால் சொல்வது.

---

## Traditional vs Trailing — Same அர்த்தம்:

```cpp
// Traditional — return type முன்னால்:
double divide(double x, double y)
{
    return x / y;
}

// Trailing — return type பின்னால்:
auto divide(double x, double y) -> double
{
    return x / y;
}

// இரண்டும் exactly same — வேறுபாடே இல்லை!
```

---

## ஏன் `->` வந்தது? — Real Reason:

```cpp
// இந்த case-ல் traditional syntax வேலை செய்யாது:

template<typename A, typename B>
??? add(A a, B b)        // return type என்னவென்று தெரியாது!
{
    return a + b;
}

// A = int, B = double → result = double
// A = int, B = int   → result = int
// முன்னால் எழுத முடியாது!

// Trailing syntax solution:
template<typename A, typename B>
auto add(A a, B b) -> decltype(a + b)
//                             ^^^^^^
//                             a+b-ன் type பார்த்து decide பண்ணும்
{
    return a + b;
}
// இங்கே a,b parameters already known — பின்னால் use பண்ணலாம்!
```

---

## `make_names()` Example:

```cpp
// Traditional — கஷ்டமாக தெரியும்:
std::vector<std::string> make_names()

// Trailing — clean-ஆக தெரியும்:
auto make_names() -> std::vector<std::string>
//   ──────────    ───────────────────────────
//   "என்ன function"  "என்ன return பண்ணும்"
```

---

## `->` Symbol எங்கெல்லாம் வருகிறது:

```cpp
// 1. Function trailing return:
auto func() -> int

// 2. Lambda:
auto multiply = [](int a, int b) -> int
{
    return a * b;
};

// 3. Pointer to function (வேறு context):
int* ptr;   // இங்கே -> வேறு அர்த்தம்
ptr->member // object member access
```

---

## Summary:

| Syntax | எங்கே return type | எப்போது use |
|---|---|---|
| `double func()` | முன்னால் | Simple cases |
| `auto func() -> double` | பின்னால் | Template, complex types |

> **One line:** `->` = "இந்த function இந்த type return பண்ணும்" என்று **பின்னால்** சொல்வது — முன்னால் சொல்வதற்கு alternative syntax, same result.

---------------

`auto என்று போட்டு உள்ளோமே அதற்கு தெரியாதா?`

## நல்ல Question! `auto` தெரியும் — ஆனால் ஒரு limitation உள்ளது!

---

## `auto` மட்டும் போட்டால்:

```cpp
auto square(int x)
{
    return x * x;  // x*x = int → auto = int ✅
}
```

இங்கே `auto` தானே deduce பண்ணும் — works fine!

---

## ஆனால் Template-ல் Problem:

```cpp
template<typename A, typename B>
auto add(A a, B b)
{
    return a + b;
}
```

```
Compiler சிந்திக்கும்:

auto = ???

A = int,    B = double → a+b = double
A = int,    B = int    → a+b = int
A = double, B = double → a+b = double

Function signature பார்க்கும் போதே
return type தெரியவேண்டும்!

ஆனால் a, b values
compile time-ல் தெரியாது → auto alone fail! ❌
```

---

## `->` Solution:

```cpp
template<typename A, typename B>
auto add(A a, B b) -> decltype(a + b)
//                   ^^^^^^^^^^^^^^^^
//                   "a+b எந்த type-ஆக இருக்குமோ
//                    அதுவே return type"
```

```
இங்கே a, b parameters already declared
→ பின்னால் decltype(a+b) use பண்ணலாம் ✅
→ முன்னால் போட முடியாது ❌ (a,b இன்னும் தெரியாது!)
```

---

## Simple Cases-ல் `auto` போதும்:

```cpp
// ✅ auto alone works:
auto square(int x)     { return x * x; }   // int
auto getName()         { return "Alice"; }  // const char*
auto getValue()        { return 3.14; }     // double

// ❌ auto alone fails:
template<typename A, typename B>
auto add(A a, B b)     { return a + b; }
// warning: may work in C++14 but not always safe
```

---

## Summary:

| Case | `auto` alone | `auto ->` |
|---|---|---|
| Simple return | ✅ தெரியும் | Optional |
| Complex type | ✅ தெரியும் | Cleaner |
| Template params | ⚠️ risky | ✅ safe |

> **One line:** `auto` simple cases-ல் தெரியும் — template parameters-ல் `a+b` என்ன type என்று முன்னால் தெரியாது, எனவே `-> decltype(a+b)` பின்னால் சொல்ல `->` வேண்டும்.

# Very Important Modern Feature

## auto Return Type Deduction

---

# Example

```cpp id="9lwmy2"
auto expression(Token_stream& ts)
{
    double left = term(ts);

    return left;
}
```

---

# Here

Compiler automatically deduces:

```text id="0lwmy3"
return type = double
```

---

# Why?

Because:

```cpp id="7lwmy4"
return left;
```

and:

```cpp id="6lwmy5"
left
```

is double.

---

# Similar to auto Variables

Like:

```cpp id="1lwmy6"
auto x = 5;
```

Compiler deduces:

```text id="2lwmy7"
int
```

---

# Function deduction same idea

Compiler analyzes:

```cpp id="5lwmy8"
return statements
```

---

# Important Warning from Author

Do NOT overuse.

---

# Why dangerous?

Suppose:

Original:

```cpp id="8lwmy9"
auto f()
{
    return 5;
}
```

Return type:

```text id="4lwmz0"
int
```

---

# Later someone changes:

```cpp id="0lwmz1"
return 5.7;
```

Now return type silently becomes:

```text id="6lwmz2"
double
```

---

# Function type changed accidentally

Dangerous in large systems.

---

# Professional Rule

Use deduction:

* only when obvious
* only when readability improves

# When trailing return essential?

Advanced templates.

# Example

```cpp id="1lwmz3"
template<typename T, typename U>
auto add(T a, U b)
    -> decltype(a + b)
```

Return type depends on arguments.

Traditional syntax impossible here.

# BEST BOOK-ORIENTED .CPP EXAMPLE

```cpp id="9lwmz4"
#include <iostream>
#include <string>
#include <vector>


// ======================================
// Traditional return syntax
// ======================================

double multiply(int a, double b)
{
    return a * b;
}


// ======================================
// Trailing return syntax
// ======================================

auto divide(double x, double y)
    -> double
{
    return x / y;
}


// ======================================
// Longer return type
// ======================================

auto make_names()
    -> std::vector<std::string>
{
    return {
        "Alice",
        "Bob",
        "Charlie"
    };
}


// ======================================
// Auto return type deduction
// ======================================

auto square(int x)
{
    return x * x;
}


// ======================================
// Main
// ======================================

int main()
{
    double m =
        multiply(5, 2.5);


    double d =
        divide(20, 4);


    auto names =
        make_names();


    auto s =
        square(6);


    std::cout
        << "multiply : "
        << m
        << '\n';


    std::cout
        << "divide : "
        << d
        << '\n';


    std::cout
        << "square : "
        << s
        << '\n';


    std::cout
        << "names : ";


    for (const auto& n : names)
    {
        std::cout
            << n
            << ' ';
    }

    std::cout
        << '\n';
}
```
