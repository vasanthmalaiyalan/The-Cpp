# Very Convenient

But dangerous sometimes.

---

# Why dangerous?

Suppose:

```cpp id="6qwmb3"
namespace A
{
    class Text {};
}

namespace B
{
    class Text {};
}
```

---

# Then

```cpp id="8qwmb4"
using namespace A;
using namespace B;
```

---

# Problem

```cpp id="1qwmb5"
Text t;
```

Which `Text`?

Compiler confused.

---

# Name Clash Returns Again

Exactly what namespaces tried to solve.

---

# Author Warning

Do NOT overuse:

```cpp id="5qwmb6"
using namespace ...
```

---

# Especially Dangerous

Inside:

* header files
* libraries
* large projects

---

# Why Header Dangerous?

If header contains:

```cpp id="0qwmb7"
using namespace std;
```

EVERY file including header affected.

Huge hidden pollution.

---

# Professional Rule


inside:

# Very Bad


# BEST BOOK-ORIENTED .CPP EXAMPLE

```cpp id="5qwmc6"
#include <iostream>
#include <string>
#include <vector>


// ======================================
// Namespace
// ======================================

namespace Graphics
{
    class Line
    {
    };
}


// ======================================
// Using declarations
// ======================================

using std::cout;
using std::cin;
using std::string;


// ======================================
// Main
// ======================================

int main()
{
    string name;


    cout
        << "Please enter your name:\n";


    cin
        >> name;


    cout
        << "Hello, "
        << name
        << '\n';


    // fully qualified name

    Graphics::Line line;
}
```

# Using Directive Example

```cpp id="8qwmc7"
#include <iostream>

int main()
{
    string name;

    cout
        << "Enter name:\n";

    cin
        >> name;

    cout
        << "Hello "
        << name
        << '\n';
}
```

# What this code teaches

| Concept               | Example                 |
| --------------------- | ----------------------- |
| Fully qualified name  | `std::string`           |
| Using declaration     | `using std::cout`       |
| Import selected names | `string`, `cout`        |
| Using directive       | `using namespace std`   |
| Namespace access      | `Graphics::Line`        |
| Reduced typing        | remove repeated `std::` |
