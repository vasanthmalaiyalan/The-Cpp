## நல்ல Observation! Reference vs Pointer — இது எப்படி சாத்தியம்?

---

## உங்கள் Confusion என்னவென்றால்:

```cpp
// Pointer மூலம் address வாங்குவது:
int* p = &x;   // & operator வேண்டும்

// ஆனால் Reference:
int& r = x;    // & இல்லாமல் — எப்படி?
```

---

## இரண்டும் வேறு வேறு `&`:

```cpp
int x = 7;

int* p = &x;
//        ^
//        இந்த & = "address of" operator
//        x-ன் address எடு

int& r = x;
//  ^
//  இந்த & = "reference" declaration
//  operator அல்ல — type-ன் part!
```

```
int*  → "pointer to int"   type
int&  → "reference to int" type
        ─────────────────
        & இங்கே type declaration-ல் உள்ளது
        address எடுக்கவில்லை!
```

---

## Compiler உள்ளே என்ன பண்ணுகிறது:

```cpp
int x = 7;
int& r = x;

// Compiler internally:
// r என்பது x-ன் alias (மற்றொரு பெயர்)
// same address — new variable இல்லை!
```

```
Memory:
┌─────────┐
│    7    │ ← x இங்கே உள்ளது
└─────────┘
  ↑     ↑
  x     r   — இரண்டும் same box!
              r தனியாக இல்லை
```

---

## Pointer vs Reference — உள்ளே வேறுபாடு:

```cpp
// Pointer:
int* p = &x;
// p = தனி variable — address store பண்ணும்
// Memory: [x box] [p box → x-ன் address]

// Reference:
int& r = x;
// r = தனி variable இல்லை — x-க்கே மற்றொரு பெயர்
// Memory: [x box] — r என்று தனி box இல்லை!
```

```
Pointer:                    Reference:
┌─────┐    ┌─────────┐     ┌─────┐
│  7  │←───│0x1000   │     │  7  │
└─────┘    └─────────┘     └─────┘
  x           p               x
                               ↑
                               r (alias — தனி box இல்லை)
```

---

## ஏன் `&x` எழுதவில்லை Reference-ல்?

```cpp
int& r = x;
//       ^
//       x என்று எழுதினால் போதும்
//       compiler தானாக x-ன் address bind பண்ணும்

// &x எழுத வேண்டியதில்லை — automatic!
```

---

## Proof — Same Address:

```cpp
int x = 7;
int& r = x;

std::cout << &x << "\n";  // 0x1000
std::cout << &r << "\n";  // 0x1000 — same!
// இரண்டும் same address!

r = 100;
std::cout << x;  // 100 — x மாறிவிட்டது!
```

---

## Summary:

| | Pointer `int*` | Reference `int&` |
|---|---|---|
| `&` meaning | address-of operator | type declaration |
| தனி memory | ✅ உண்டு | ❌ இல்லை |
| Null possible | ✅ `p = nullptr` | ❌ impossible |
| Reassign | ✅ வேற address போடலாம் | ❌ முடியாது |
| Use | complex cases | simple alias |

> **One line:** `int& r = x` — இங்கே `&` என்பது address operator அல்ல, **reference type declaration**. Compiler தானாக x-ஐ bind பண்ணும் — r என்பது x-க்கே மற்றொரு பெயர் மட்டுமே.

# First Difference

## Pass-by-value

```cpp id="qjlwm1"
void f(int x)
```

Copy created.

Original unchanged.

---

# Pass-by-const-reference

```cpp id="9jlwm8"
void f(const int& x)
```

No copy.
But modification not allowed.

---

# Pass-by-reference

```cpp id="7jlwm0"
void f(int& x)
```

No copy.
AND modification allowed.

---

# Core Idea

Function directly original object-ஐ operate செய்கிறது.

# BEST .CPP EXAMPLE

```cpp id="1jlwm9"
import std;


// =====================================
// Pass-by-reference modifies original
// =====================================

void initialize(std::vector<double>& values)
{
    for (int i = 0; i < values.size(); ++i)
    {
        values[i] = i * 10;
    }
}


// =====================================
// Reference as alias
// =====================================

void reference_demo()
{
    int x = 7;

    int& r = x;


    std::cout << "\nBefore modification:\n";

    std::cout << "x = "
              << x
              << '\n';

    std::cout << "r = "
              << r
              << '\n';


    r = 100;


    std::cout << "\nAfter modifying r:\n";

    std::cout << "x = "
              << x
              << '\n';

    std::cout << "r = "
              << r
              << '\n';
}


// =====================================
// Swap using references
// =====================================

void swap_values(double& a,
                 double& b)
{
    double temp = a;

    a = b;

    b = temp;
}


// =====================================
// Main
// =====================================

int main()
{
    // ---------------------------------
    // Vector modification
    // ---------------------------------

    std::vector<double> numbers(5);

    initialize(numbers);


    std::cout << "Initialized vector:\n";

    for (double value : numbers)
    {
        std::cout << value << ' ';
    }

    std::cout << '\n';


    // ---------------------------------
    // Reference alias demo
    // ---------------------------------

    reference_demo();


    // ---------------------------------
    // Swap demo
    // ---------------------------------

    double x = 1.5;

    double y = 9.5;


    std::cout << "\nBefore swap:\n";

    std::cout << "x = "
              << x
              << " y = "
              << y
              << '\n';


    swap_values(x, y);


    std::cout << "\nAfter swap:\n";

    std::cout << "x = "
              << x
              << " y = "
              << y
              << '\n';
}
```

| ----------------------- | --------------- |
