# Why Person* powerful?

Because compiler already knows:

```cpp id="f21"
class Person
{
    int age;
    std::string name;
};
```

layout:

| Member | Offset |
| ------ | ------ |
| age    | 0      |
| name   | 8      |

---

So:

```cpp id="f22"
person->name
```

means:

```text id="f23"
base address + 8
```

🔥
