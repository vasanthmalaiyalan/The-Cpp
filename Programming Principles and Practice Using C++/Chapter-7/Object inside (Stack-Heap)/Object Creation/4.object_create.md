நீங்கள் எழுதியுள்ள குறியீடு (Code) அற்புதம்! C++ கம்பைலர் பின்னணியில் ஆப்ஜெக்ட்டுகளை எப்படி உருவாக்குகிறது, வேரியபிள்களை எப்படி ஆஃப்செட் (Offset) முகவரிகள் மூலம் அணுகுகிறது என்பதை மிக ஆழமாக ஆராய்ந்துள்ளீர்கள். ஒரு சிறந்த சிஸ்டம்ஸ் புரோகிராமருக்கான தேடல் இது!

உங்கள் குறியீட்டில் **Segmentation fault (core dumped)** ஏற்படுவதற்கான காரணத்தை உங்கள் அவுட்புட்டே மிகத் தெளிவாகக் காட்டுகிறது.

இதோ அந்தப் புதிருக்கு பின்னால் இருக்கும் ரகசியம்:

---

## தவறு எங்கே நடக்கிறது? (The Root Cause)

உங்கள் அவுட்புட்டில் இந்த இரண்டு வரிகளைக் கவனியுங்கள்:

* கன்ஸ்ட்ரக்டருக்குள் `name` இருக்கும் உண்மையான முகவரி: **`0x6506370526c8`**
* நீங்கள் மேனுவலாகக் கணக்கிட்ட `name_ptr` முகவரி: **`0x6506370526c4`**

இரண்டு முகவரிகளுக்கும் நடுவே **4 பைட்டுகள் (Bytes)** வித்தியாசம் உள்ளது. நீங்கள் தவறான முகவரியைக் கொடுத்து, அங்கிருக்கும் தரவை ஒரு `std::string` ஆகப் படிக்க முயற்சிப்பதால் (`*name_ptr`), சிஸ்டம் குழப்பமடைந்து **Segmentation fault** கொடுத்து கிராஷ் ஆகிறது.

---

## ஏன் கம்பைலர் 4 பைட்டுகளைத் தள்ளி வைத்தது? (Data Alignment & Padding)

நீங்கள் நினைத்த கணக்கு:

> "பேஸ் முகவரி `0x6506370526c0`. `int` என்பது 4 பைட்டுகள். எனவே, `0 + 4 = 4` பைட்டுகள் தள்ளினால் `name` கிடைத்துவிடும்."

ஆனால், C++ கம்பைலர் இப்படி வேலை செய்யாது. அதற்கு **Memory Alignment (நினைவக சீரமைப்பு)** மற்றும் **Structure Padding** என்ற விதிமுறைகள் உள்ளன.

64-bit கணினிகளில், `std::string` போன்ற பெரிய ஆப்ஜெக்ட்டுகள் நினைவகத்தில் **8-byte alignment**-இல் மட்டுமே அமர வேண்டும் (அதாவது அதன் முகவரி 8, 16, 24 போன்ற எண்களின் மடங்குகளில் மட்டுமே இருக்க முடியும்).

### கம்பைலர் உருவாக்கிய உண்மையான மெமரி லேஅவுட்:

| முகவரி (Address) | அளவு (Size) | என்ன இருக்கிறது? |
| --- | --- | --- |
| `0x6506370526c0` | 4 Bytes | `age` (int) |
| **`0x6506370526c4`** | **4 Bytes** | **Padding (வெற்று இடைவெளி)** |
| `0x6506370526c8` | 32 Bytes | `name` (std::string தொடங்குகிறது) |

`int` முடிந்தவுடன் வரும் `0x6506370526c4` என்ற முகவரி 8 ஆல் வகுபடாது. எனவே, கம்பைலர் அங்கு ஒரு **4-byte வெற்று இடைவெளியை (Padding)** உருவாக்கி, `std::string`-ஐ அடுத்த 8-byte முகவரியான `0x6506370526c8`-இல் அமர வைக்கிறது.

நீங்கள் `base + sizeof(int)` என்று போடும்போது, அது நேராக அந்த **Padding (வெற்று இடைவெளி)** இருக்கும் இடத்தைக் குறிக்கிறது. அங்கிருந்து `std::string`-ஐப் படிக்க முயலும் போது, அது தவறான மெமரி பாயிண்டரை அணுகி செக்மென்டேஷன் ஃபால்ட் ஏற்படுகிறது.

---

## இதை எப்படிச் சரியாகக் கண்டுபிடிப்பது?

C++ இல் ஒரு கிளாஸுக்குள் இருக்கும் வேரியபிள் சரியாக எந்த ஆஃப்செட்டில் இருக்கிறது என்பதை மேனுவலாகக் கணக்கிடக் கூடாது. அதற்குப் பதிலாக C++ வழங்கும் `offsetof` என்ற மேக்ரோவை (Macro) பயன்படுத்த வேண்டும்.

உங்கள் `show_internal_layout` பங்க்ஷனில் கணக்கீட்டை இப்படி மாற்றிப் பாருங்கள்:

```cpp
#include <cstddef> // offsetof-விற்கு இது தேவை

void show_internal_layout(Person* person) {
    // ... 
    char* base = (char*)person;

    // கம்பைலரிடம் அதன் உண்மையான ஆஃப்செட்டைக் கேளுங்கள்
    size_t age_offset = offsetof(Person, age);
    size_t name_offset = offsetof(Person, name);

    int* age_ptr = (int*)(base + age_offset);
    std::string* name_ptr = (std::string*)(base + name_offset);

    std::cout << "\nage_ptr     : " << age_ptr << '\n';
    std::cout << "name_ptr      : " << name_ptr << '\n';

    std::cout << "\n*age_ptr   : " << *age_ptr << '\n';
    std::cout << "*name_ptr    : " << *name_ptr << '\n';
}

```

இப்போது நீங்கள் `offsetof(Person, name)` என்று பயன்படுத்தும்போது கம்பைலர் தானாகவே `8` என்ற மதிப்பைத் தரும். குறியீடும் செக்மென்டேஷன் ஃபால்ட் இல்லாமல் மிகச் சரியாக "Tony Stark" என்று அச்சிடும்!

இவ்வளவு லோ-லெவலில் மெமரி பாயிண்டர்களை வைத்து விளையாடுவது புரிகிறதா? இதில் ஏதேனும் சந்தேகம் உள்ளதா?

---------------

` offsetof means?`

**`offsetof`** என்பது C மற்றும் C++ மொழிகளில் வழங்கப்படும் ஒரு நிலையான மேக்ரோ (Standard Macro) ஆகும். இது `<cstddef>` என்ற ஹெடர் ஃபைலில் வரையறுக்கப்பட்டுள்ளது.

எளிமையாகச் சொன்னால், ஒரு கிளாஸ் அல்லது ஸ்ட்ரக்சரின் (Class / Struct) **தொடக்க முகவரியிலிருந்து (Base Address)**, அதற்குள் இருக்கும் ஒரு குறிப்பிட்ட வேரியபிள் **எத்தனை பைட்டுகள் (Bytes) தள்ளி இருக்கிறது** என்பதை இது துல்லியமாகக் கணக்கிட்டுக் கூறும்.

இதன் கணித சூத்திரம் இதுதான்:


$$\text{Offset} = \text{Address of Member} - \text{Base Address of Object}$$

---

## 1. இதன் வடிவம் (Syntax)

```cpp
offsetof(Class_Name, Member_Name)

```

* **`Class_Name`:** நீங்கள் ஆராய விரும்பும் கிளாஸ் அல்லது ஸ்ட்ரக்சரின் பெயர் (உதாரணம்: `Person`).
* **`Member_Name`:** அந்த கிளாஸிற்குள் இருக்கும் எந்த வேரியபிளின் தூரம் உங்களுக்குத் வேண்டும் (உதாரணம்: `name`).

---

## 2. உங்கள் குறியீட்டை வைத்து ஒரு விளக்கம்

உங்கள் `Person` கிளாஸில் கம்பைலர் உருவாக்கிய மெமரி லேஅவுட்டை நாம் ஏற்கனவே பார்த்தோம்:

```cpp
class Person {
public:
    int age;         // முகவரி: 0x1000 இல் தொடங்குகிறது
    // [Padding]    // முகவரி: 0x1004 (4 பைட்டுகள் வெற்று இடம்)
    std::string name;// முகவரி: 0x1008 இல் தொடங்குகிறது
};

```

இப்போது நீங்கள் `offsetof` பயன்படுத்தினால் என்ன நடக்கும்?:

* **`offsetof(Person, age)`** $\rightarrow$ இது **`0`** என்று விடையைத் தரும். ஏனென்றால், `age` தான் அந்த கிளாஸின் முதல் வேரியபிள். அது பேஸ் முகவரியிலேயே (0 பைட்டுகள் தள்ளி) தொடங்கிவிடுகிறது.
* **`offsetof(Person, name)`** $\rightarrow$ இது **`8`** என்று விடையைத் தரும். நாம் மேனுவலாக கணக்கிட்ட போது `4` என்று நினைத்தோம் அல்லவா? ஆனால் கம்பைலர் நடுவில் 4 பைட்டுகள் Padding சேர்த்ததை இந்த மேக்ரோ சரியாகக் கண்டுபிடித்து `4 (int) + 4 (Padding) = 8` பைட்டுகள் தள்ளி `name` இருக்கிறது என்று கூறும்.

---

## 3. ஏன் இதைப் பயன்படுத்த வேண்டும்? (Why use it?)

1. **கம்பைலருக்கு கம்பைலர் மாறும் (Compiler Dependent):** Memory Alignment மற்றும் Padding என்பது நீங்கள் பயன்படுத்தும் கம்பைலர் (GCC, Clang, MSVC) மற்றும் கணினியின் ஆர்கிடெக்சரைப் (32-bit அல்லது 64-bit) பொறுத்து மாறும். நாம் மேனுவலாக "4 பைட்டுகள்" என்று குறியீட்டில் எழுதினால் அது எல்லா கணினியிலும் வேலை செய்யாது. ஆனால் `offsetof` கம்பைலரிடமே நேரடியாகக் கேட்பதால் எப்போதுமே துல்லியமான விடை கிடைக்கும்.
2. **Compile-time-லேயே நடந்துவிடும்:** இது ரன்-டைமில் (Run-time) கணக்கிடப்படாது. கோட் கம்பைல் ஆகும் போதே, கம்பைலர் அந்த இடத்தில் சரியான எண் மதிப்பை (உதாரணமாக 8) பிரதியிட்டுவிடும். அதனால் புரோகிராமின் வேகம் குறையாது.

சுருக்கமாக, லோ-லெவல் மெமரி கையாளுதலின் போது (Low-level memory manipulation), ஒரு ஆப்ஜெக்ட்டிற்குள் இருக்கும் வேரியபிளின் **சரியான இருப்பிடத்தைக் கண்டறியும் ஜிபிஎஸ் (GPS)** தான் இந்த `offsetof`.

------------------

```cpp id="custom_object_creation_flow"
#include <iostream>
#include <cstdlib>
#include <new>
#include <string>



// ==========================================================
// SIMPLE PERSON CLASS
// ==========================================================

class Person
{
public:

    int age;

    std::string name;



    // --------------------------------------------------
    // CONSTRUCTOR
    // --------------------------------------------------

    Person()
    {
        std::cout
            << "\n[CONSTRUCTOR RUNNING]\n";



        // --------------------------------------------------
        // THIS POINTER
        // --------------------------------------------------

        std::cout
            << "this pointer                 : "
            << this
            << '\n';



        // --------------------------------------------------
        // MEMBER ADDRESSES
        // --------------------------------------------------

        std::cout
            << "&age member                  : "
            << &age
            << '\n';



        std::cout
            << "&name member                 : "
            << &name
            << '\n';



        // --------------------------------------------------
        // INITIALIZATION
        // --------------------------------------------------

        age = 25;

        name = "Tony Stark";



        std::cout
            << "\nVALUES INITIALIZED\n";

        std::cout
            << "age                           : "
            << age
            << '\n';

        std::cout
            << "name                          : "
            << name
            << '\n';
    }



    // --------------------------------------------------
    // DESTRUCTOR
    // --------------------------------------------------

    ~Person()
    {
        std::cout
            << "\n[DESTRUCTOR RUNNING]\n";

        std::cout
            << "destroying object at         : "
            << this
            << '\n';
    }
};



// ==========================================================
// CUSTOM OBJECT CREATOR
// ==========================================================

Person* create_person_object()
{
    std::cout
        << "\n\n====================================\n";

    std::cout
        << "STEP 1 : ALLOCATE RAW MEMORY\n";

    std::cout
        << "====================================\n";



    // --------------------------------------------------
    // RAW MEMORY ONLY
    // --------------------------------------------------

    void* raw_memory =
        std::malloc(sizeof(Person));



    std::cout
        << "\nraw memory address           : "
        << raw_memory
        << '\n';



    std::cout
        << "\nIMPORTANT:\n";

    std::cout
        << "NO OBJECT EXISTS YET\n";



    // ==================================================
    // CAST RAW MEMORY
    // ==================================================

    std::cout
        << "\n\n====================================\n";

    std::cout
        << "STEP 2 : CAST MEMORY\n";

    std::cout
        << "====================================\n";



    Person* object_ptr =
        (Person*)raw_memory;



    std::cout
        << "\nobject_ptr value             : "
        << object_ptr
        << '\n';



    std::cout
        << "\nIMPORTANT:\n";

    std::cout
        << "still NO REAL OBJECT\n";



    // ==================================================
    // CONSTRUCTOR CALL
    // ==================================================

    std::cout
        << "\n\n====================================\n";

    std::cout
        << "STEP 3 : CONSTRUCTOR CALL\n";

    std::cout
        << "====================================\n";



    // --------------------------------------------------
    // THIS IS THE ACTUAL MAGIC
    // --------------------------------------------------

    new(object_ptr) Person();



    std::cout
        << "\nIMPORTANT:\n";

    std::cout
        << "NOW OBJECT LIFETIME STARTED\n";



    // ==================================================
    // RETURN OBJECT
    // ==================================================

    return object_ptr;
}



// ==========================================================
// INTERNAL MEMBER ACCESS VISUALIZATION
// ==========================================================

void show_internal_layout(Person* person)
{
    std::cout
        << "\n\n====================================\n";

    std::cout
        << "STEP 4 : INTERNAL MEMBER LOGIC\n";

    std::cout
        << "====================================\n";



    // --------------------------------------------------
    // BASE ADDRESS
    // --------------------------------------------------

    char* base =
        (char*)person;



    std::cout
        << "\nbase object address          : "
        << (void*)base
        << '\n';



    // --------------------------------------------------
    // OFFSETS
    // --------------------------------------------------

    std::cout
        << "\nCompiler internally knows:\n";

    std::cout
        << "age offset  = 0\n";

    std::cout
        << "name offset = depends on layout\n";



    // --------------------------------------------------
    // MANUAL ADDRESS CALCULATION
    // --------------------------------------------------

    int* age_ptr =
        (int*)(base + 0);



    std::string* name_ptr =
        (std::string*)(base + sizeof(int));



    std::cout
        << "\nage_ptr                     : "
        << age_ptr
        << '\n';



    std::cout
        << "name_ptr                    : "
        << name_ptr
        << '\n';



    // --------------------------------------------------
    // VALUES
    // --------------------------------------------------

    std::cout
        << "\n*age_ptr                    : "
        << *age_ptr
        << '\n';



    std::cout
        << "*name_ptr                   : "
        << *name_ptr
        << '\n';
}



// ==========================================================
// DESTROY OBJECT
// ==========================================================

void destroy_person(Person* person)
{
    std::cout
        << "\n\n====================================\n";

    std::cout
        << "STEP 5 : DESTROY OBJECT\n";

    std::cout
        << "====================================\n";



    // --------------------------------------------------
    // MANUAL DESTRUCTOR
    // --------------------------------------------------

    person->~Person();



    std::cout
        << "\nOBJECT LIFETIME ENDED\n";



    // --------------------------------------------------
    // FREE RAW MEMORY
    // --------------------------------------------------

    std::free(person);



    std::cout
        << "RAW MEMORY FREED\n";
}

// MAIN
// ==========================================================

int main()
{

    // CREATE OBJECT
    // --------------------------------------------------

    Person* person =
        create_person_object();



    // --------------------------------------------------
    // VERIFY OBJECT
    // --------------------------------------------------

    std::cout
        << "\n\n====================================\n";

    std::cout
        << "VERIFY OBJECT\n";

    std::cout
        << "====================================\n";



    std::cout
        << "\nperson pointer              : "
```
