# What does Person* mean?

Compiler now thinks:

```text id="a9"

```

# Then compiler already knows layout

Suppose:

```cpp id="a10"
class Person
{
    int age;
    std::string name;
};
```

Compiler already knows:

| Member | Offset |
| ------ | ------ |
| age    | 0      |
| name   | 8      |

🔥
