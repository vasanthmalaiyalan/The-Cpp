உங்கள் குறியீட்டில் உள்ள பிழைகள் C++ இன் மிக முக்கியமான இரண்டு பாதுகாப்பு விதிகளால் ஏற்படுகின்றன. அவை ஒவ்வொன்றாக என்ன, எப்படிச் சரிசெய்வது என்று பார்ப்போம்.

### 1. `sign-compare` பிழை (Warning)

**பிழை:** `index < v.size()`

* **காரணம்:** `index` என்பது `int` (Signed). ஆனால், `v.size()` என்பது `std::vector::size_type` (இது பொதுவாக `unsigned long` எனப்படும் **Unsigned** வகை).
* C++ இல் ஒரு Signed எண்ணையும் Unsigned எண்ணையும் ஒப்பிடும்போது, கம்பைலர் எச்சரிக்கை செய்யும். ஏனெனில், `index` மதிப்புக் குறைவாக இருந்தால் (எ.கா: -1), அது Unsigned ஆக மாற்றப்படும்போது மிகப்பெரிய நேர்மறை எண்ணாக மாறிவிடும். இதனால் ஆபத்தான விளைவுகள் ஏற்படலாம்.

**சரிசெய்யும் முறை (Fix):**
`v.size()` என்பதை `int` ஆக மாற்றி (Cast) ஒப்பிடவும் அல்லது `index`-ஐ `std::size_t` ஆக மாற்றவும்.

```cpp
// சிறந்த வழி: static_cast பயன்படுத்துவது
if (0 <= index && static_cast<std::size_t>(index) < v.size() && v[index] != 0)

```

### 2. `sequence-point` பிழை (Undefined Behavior)

**பிழை:** `std::cout << ++n << ' ' << ++n << '\n';`

* **காரணம்:** இது ஒரு **Undefined Behavior**. ஒரே எக்ஸ்பிரஷனுக்குள் (Expression) நீங்கள் ஒரு வேரியபிளை (`n`) பலமுறை மாற்றி (Increment), அதே வேரியபிளைப் பயன்படுத்த முயற்சி செய்கிறீர்கள்.
* C++17 க்கு முன்பு, இந்த `<<` ஆப்பரேட்டர் இடமிருந்து வலமாகத்தான் இயங்கும் என்ற உறுதியான விதி இல்லை. எனவே, கம்பைலர் எந்த `++n` ஐ முதலில் இயக்கும் என்று சொல்ல முடியாது. இதனால் `n` இன் மதிப்பு 2 ஆகுமா அல்லது 3 ஆகுமா என்பதில் குழப்பம் ஏற்படும். இதையே "Sequence point error" என்கிறார்கள்.

**சரிசெய்யும் முறை (Fix):**
ஒரே வரியில் மாற்றாமல், தனித்தனியாகச் செய்யுங்கள்.

```cpp
// பாதுகாப்பான முறை
std::cout << ++n << ' ';
std::cout << ++n << '\n';

```

### உங்கள் குறியீட்டிற்கான திருத்தப்பட்ட பகுதி:

```cpp
// [Short-circuit evaluation திருத்தம்]
if (index >= 0 && static_cast<std::size_t>(index) < v.size() && v[index] != 0) {
    std::cout << "Valid access\n";
} else {
    std::cout << "Invalid access avoided\n";
}

// [Stream evaluation திருத்தம்]
int n = 1;
std::cout << ++n << ' ';
std::cout << ++n << '\n'; // இப்போது பிழை வராது

```

### சுருக்கமான குறிப்பு (Pro Tip):

`C++` இல் எப்போதும் **"ஒரு எக்ஸ்பிரஷனில் ஒரு வேரியபிளை ஒருமுறை மட்டுமே மாற்றுங்கள்"** என்பது மிக முக்கியமான விதி. இந்த விதியை மீறினால், அது எந்த கம்பைலரில் வேலை செய்தாலும், அது நிரந்தரமற்ற (Undefined) குறியீடாகவே கருதப்படும்.

இனி உங்கள் `g++` கட்டளையை இயக்கினால், எந்த பிழையும் இல்லாமல் வெற்றிகரமாக ரன் ஆகும்! இது போன்ற லோ-லெவல் பிழைகளை நீங்கள் கண்டுபிடித்ததே உங்கள் C++ அறிவின் முதிர்ச்சியைக் காட்டுகிறது. வேறு ஏதேனும் சந்தேகம் உள்ளதா?

# BEST BOOK-ORIENTED .CPP EXAMPLE

```cpp id="2nwna0"
#include <iostream>
#include <vector>


int f(int x)
{
    std::cout
        << "f(" << x << ")\n";

    return x + 1;
}


int g(int y)
{
    std::cout
        << "g(" << y << ")\n";

    return y * 2;
}


int main()
{
    int i = 1;


    // ======================================
    // Dangerous expressions
    // ======================================

    // BAD:
    //
    // int x = ++i + i;


    // BAD:
    //
    // f(++i, ++i);


    // ======================================
    // Safe version
    // ======================================

    ++i;

    int x = i + i;


    std::cout
        << "x = "
        << x
        << '\n';


    // ======================================
    // Function evaluation order
    // ======================================

    int fx = f(10);

    int gy = g(20);

    int z = fx + gy;


    std::cout
        << "z = "
        << z
        << '\n';


    // ======================================
    // Short-circuit evaluation
    // ======================================

    std::vector<int> v {1, 2, 3};


    int index = -1;


    if (0 <= index
        && index < v.size()
        && v[index] != 0)
    {
        std::cout
            << "Valid access\n";
    }
    else
    {
        std::cout
            << "Invalid access avoided\n";
    }


    // ======================================
    // Left-to-right stream evaluation
    // ======================================

    int n = 1;

    std::cout
        << ++n
        << ' '
        << ++n
        << '\n';
}
```
