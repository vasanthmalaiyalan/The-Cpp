## Part 1: `text.find(word)`


## Full Function:

```cpp
bool contains_word(const std::string& text,
                   const std::string& word)
{
    return text.find(word) != std::string::npos;
    //     ─────────────────────────────────────
    //     word கிடைத்தால்  → true
    //     கிடைக்கவில்லை   → false
}

// Use:
contains_word("Modern C++ is powerful", "powerful"); // true
contains_word("Modern C++ is powerful", "hello");    // false
```

## `npos` உள்ளே என்ன இருக்கும்?

## Direct Answer:

```cpp
std::string::npos = 18446744073709551615
```

இது `size_t` type-ன் **maximum possible value.**

## உள்ளே எப்படி Define ஆகியுள்ளது:


## ஏன் `-1` போட்டால் `18446744073709551615` ஆகும்?

```cpp
size_t = unsigned type
         negative values இல்லை!

-1 → unsigned-ல் போட்டால்:
     1111 1111 1111 1111 ... (64 bits எல்லாம் 1)
   = 18446744073709551615
   = maximum value of size_t
```

```
Binary:
1111111111111111111111111111111111111111111111111111111111111111
= 18446744073709551615
```

## ஏன் Maximum Value-ஐ "Not Found" Signal-ஆக பயன்படுத்துகிறார்கள்?

```cpp
std::string text = "Modern C++ is powerful";
// text.size() = 22

// 18446744073709551615 என்ற position
// எந்த string-லும் இருக்காது — impossible!
```

## Proof Code:

```cpp
#include <iostream>
#include <string>

int main() {
    std::cout << std::string::npos << "\n";

    size_t x = -1;
    std::cout << x << "\n";
    // Output: 18446744073709551615 — same!
}
```

| | Value |
|---|---|

# BEST .CPP EXAMPLE

```cpp id="9jlwm5"
import std;


// =====================================
// Pass-by-value (copies vector)
// =====================================

void print_by_value(std::vector<int> numbers)
{
    std::cout << "\nInside print_by_value():\n";

    numbers[0] = 999;

    for (int value : numbers)
    {
        std::cout << value << ' ';
    }

    std::cout << '\n';
}


// =====================================
// Pass-by-const-reference
// =====================================

void print_by_const_reference(const std::vector<int>& numbers)
{
    std::cout << "\nInside print_by_const_reference():\n";

    for (int value : numbers)
    {
        std::cout << value << ' ';
    }

    std::cout << '\n';


    // ERROR if uncommented:
    //
    // numbers[0] = 500;
}


// =====================================
// String example
// =====================================

bool contains_word(const std::string& text,
                   const std::string& word)
{
    return text.find(word) != std::string::npos;
}


// =====================================
// Main
// =====================================

int main()
{
    std::vector<int> values
    {
        10,
        20,
        30
    };


    std::cout << "Original vector:\n";

    for (int value : values)
    {
        std::cout << value << ' ';
    }

    std::cout << '\n';


    // pass-by-value
    print_by_value(values);


    std::cout << "\nAfter print_by_value():\n";

    for (int value : values)
    {
        std::cout << value << ' ';
    }

    std::cout << '\n';


    // pass-by-const-reference
    print_by_const_reference(values);


    std::string text = "Modern C++ is powerful";


    bool found =
        contains_word(text,
                      "powerful");


    std::cout << "\nContains word? "
              << found
              << '\n';
}
```
