# Core Idea

Author சொல்வது:

> Function argument passing என்பது
> parameter initialization போல.

---

# Example

```cpp id="8jlwm1"
void f(T x);

f(y);
```

Internally similar to:

```cpp id="4jlwm3"
T x = y;
```

---

# Meaning

Function call:

```cpp id="9jlwm9"
f(y);
```

actually means:

```text id="7jlwm8"
Create local parameter x
Initialize it using y
```

---

# Important Consequence

If:

```cpp id="0jlwm4"
T x = y;
```

legal என்றால்,

```cpp id="3jlwm4"
f(y);
```

also legal.

C++ performs implicit conversion automatically.

# Usually useful

Example:

```cpp id="9jlwm5"

```

```text id="5.0"
```

No problem.

# Dangerous Case — Narrowing

Important concept.

---

# Example

```cpp id="3jlwm3"
g(7.8);
```

Suppose:

```cpp id="5jlwm6"
void g(int x);
```

---

# What happens?

```text id="0jlwm8"
7.8 -> 7
```

Decimal lost.

---

# Same here

```cpp id="7jlwm7"
int x = 7.8;
```

Again:

```text id="4jlwm7"
7.8 -> 7
```

---

# This is called narrowing

Large/richer type:
→ smaller/less precise type.

---

# Why dangerous?

Possible:

* data loss
* precision loss
* unexpected behavior

---

# Compiler Warning

Modern compilers often warn:

```text id="1jlwm7"
possible loss of data
```

---

# Author Advice

If you REALLY want narrowing:

Make it explicit.

---

````
```text id="1jwlw0"
````

```text id="3jwlw1"

```

not:


# Integer Division Trap

Very important beginner trap.

---

# Example

```cpp id="8jwlw5"
double z = x / y;
```

Suppose:

```text id="7jwlw6"
x = 5
y = 2
```

---

# Result?

```text id="0jwlw7"
2
```

NOT:

```text id="6jwlw8"
2.5
```

---

# Why?

Because:
both operands are int.

Integer division happens FIRST.

---

# Then converted

```text id="1jwlw9"
2 -> 2.0
```

---

# Correct Solution

```cpp id="3jwlx0"
double z = double(x) / y;
```

---

# Now

```text id="9jwlx1"
5.0 / 2
```

Result:

```text id="5jwlx2"
2.5
```

---

# Important Lesson

Type of operands controls operation behavior.

---

# Implicit Conversion vs Explicit Conversion

---

# Implicit

Compiler automatic:

```cpp id="7jwlx3"
double d = 5;
```

---

# Explicit

Programmer intentionally converts:

```cpp id="4jwlx4"
double d = double(5);
```

---

# Professional Rule

Important conversions:
prefer explicit.

# BEST .CPP EXAMPLE

```cpp id="8jwlx8"
import std;


// =====================================
// Function taking double
// =====================================

void print_double(double value)
{
    std::cout << "double value = "
              << value
              << '\n';
}


// =====================================
// Implicit conversion examples
// =====================================

void implicit_conversion_demo()
{
    int i = 7;

    double d = i;


    std::cout << "\nImplicit int -> double:\n";

    std::cout << "i = "
              << i
              << '\n';

    std::cout << "d = "
              << d
              << '\n';


    print_double(i);
}


// =====================================
// Narrowing conversion
// =====================================

void narrowing_demo()
{
    double pi = 3.14159;

    int x = pi;


    std::cout << "\nNarrowing conversion:\n";

    std::cout << "pi = "
              << pi
              << '\n';

    std::cout << "x = "
              << x
              << '\n';
}


// =====================================
// Integer division trap
// =====================================

void division_demo()
{
    int a = 5;

    int b = 2;


    double wrong = a / b;

    double correct =
        double(a) / b;


    std::cout << "\nDivision demo:\n";

    std::cout << "wrong   = "
              << wrong
              << '\n';

    std::cout << "correct = "
              << correct
              << '\n';
}


// =====================================
// Character conversion
// =====================================

void char_demo()
{
    char c = 'x';

    int ascii = c;


    std::cout << "\nCharacter conversion:\n";

    std::cout << "char  = "
              << c
              << '\n';

    std::cout << "ascii = "
              << ascii
              << '\n';
}


// =====================================
// Main
// =====================================

int main()
{
    implicit_conversion_demo();

    narrowing_demo();

    division_demo();

    char_demo();
}
```

Good C++ programmers:

* avoid accidental narrowing
* make dangerous conversions explicit
