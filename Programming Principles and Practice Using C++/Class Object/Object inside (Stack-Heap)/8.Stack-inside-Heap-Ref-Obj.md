ஆம் 🔥
நீ கேட்பது:

> vector object உள்ளே இருக்கும் actual `data pointer` value-ஐ எப்படி print செய்வது?

அதாவது:

```text
vector object
+---------------------------+
| data pointer ------------> heap
| size
| capacity
+---------------------------+
```

இதில்:

## `data pointer` value itself print செய்ய வேண்டும்.

---

# Short Answer

```cpp id="jlwm7m"
numbers.data()
```

இதுவே:

## vector உள்ளே இருக்கும் `data pointer` value.

---

# Example

```cpp id="0jlwme"
std::vector<int> numbers {10,20,30};

std::cout << numbers.data();
```

---

# Output

```text id="mjlwmg"
0x5613c24532b0
```

இதுதான்:

## vector object's internal `data pointer`.

---

# Why?

Because internally vector roughly:

```cpp id="7jlwmy"
class vector
{
    int* data;
    size_t size;
    size_t capacity;
};
```

---

# Then:

```cpp id="4jlwma"
numbers.data()
```

basically returns:

```cpp id="qjlwmd"
data
```

---

# Important

| Expression       | Meaning                     |
| ---------------- | --------------------------- |
| `&numbers`       | vector object address       |
| `numbers.data()` | internal heap pointer value |
| `&numbers[0]`    | first heap element address  |

---

# Very Important Insight

இந்த இரண்டும் same usually:

```cpp id="0jlwmm"
numbers.data()
```

and

```cpp id="yjlwmu"
&numbers[0]
```

---

# Because

data pointer points to first element.

---

# BEST DEBUG CODE

```cpp
#include <iostream>
#include <vector>

int main()
{
    std::vector<int> numbers {10,20,30};


    std::cout
        << "\n========== VECTOR OBJECT ==========\n";


    std::cout << "&numbers                : "
              << &numbers
              << '\n';


    std::cout
        << "\n========== INTERNAL DATA POINTER ==========\n";


    std::cout << "numbers.data()          : "
              << numbers.data()
              << '\n';


    std::cout
        << "\n========== FIRST ELEMENT ADDRESS ==========\n";


    std::cout << "&numbers[0]             : "
              << &numbers[0]
              << '\n';


    std::cout
        << "\n========== VALUES ==========\n";


    std::cout << "numbers[0]              : "
              << numbers[0]
              << '\n';


    std::cout << "*(numbers.data())       : "
              << *(numbers.data())
              << '\n';
}
```
