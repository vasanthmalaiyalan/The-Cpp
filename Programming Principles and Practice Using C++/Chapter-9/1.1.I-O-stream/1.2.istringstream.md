## `std::istringstream` என்பது என்ன?

`ifstream` → file-இலிருந்து படிக்கும்

`istringstream` → **string-இலிருந்து** படிக்கும்!

---

## உள்ளே என்ன நடக்கிறது?

```cpp
std::istringstream input_string {"99"};
```

`ifstream` மாதிரியே — ஆனால் file descriptor இல்லை!

```
input_string object
├── "99" என்ற string (buffer-ஆக செயல்படுகிறது)
├── read position (தற்போது '9' இல் இருக்கிறது)
└── error/state flags (failbit, badbit, eofbit)
```

File இல்லை → OS call இல்லை → **string நேரடியாக buffer!**

---

## பயன்படுத்துவது எப்படி?

```cpp
std::istringstream input_string {"99"};

int number {};
input_string >> number;  // "99" → int 99 ஆக மாறுகிறது!

std::cout << number;  // 99
```

---

## எங்கே useful?

```cpp
std::string age_str {"25"};
std::istringstream ss {age_str};

int age {};
ss >> age;  // string "25" → int 25 ✅
```

String-ஆக வந்த data-ஐ **int, double** என்று convert செய்ய மிகவும் useful!

---

**சுருக்கம்:** `ifstream` disk-இலிருந்து படிக்கும், `istringstream` **string-இலிருந்தே** படிக்கும் — மற்றபடி same mechanism!

## `std::istringstream` — Real Example

---

## Situation — User Input Validate செய்யணும்

```cpp
#include <iostream>
#include <sstream>
#include <string>

int main()
{
    std::string input {};
    
    std::cout << "Enter age: ";
    std::cin >> input;   // எல்லாவற்றையும் string-ஆக எடுக்கிறோம்
    
    std::istringstream ss {input};  // string-ஐ stream-ஆக மாற்றுகிறோம்
    
    int age {};
    ss >> age;  // string → int ஆக மாற்ற try செய்கிறது
    
    if (!ss)    // மாற்ற முடியவில்லை என்றால்
    {
        std::cerr << "Invalid! Enter a number.\n";
        return 1;
    }
    
    std::cout << "Your age is: " << age << '\n';
    return 0;
}
```

---

## என்ன நடக்கிறது?

```
User "25" enter செய்தால்:
input = "25" → ss → age = 25 ✅

User "abc" enter செய்தால்:
input = "abc" → ss → int-ஆக மாற்ற முடியாது → failbit set → !ss = true ❌
```

---

## `std::cin >> age` நேரடியாக ஏன் வேண்டாம்?

```cpp
// நேரடியாக
std::cin >> age;
// "abc" enter செய்தால் cin உடனே fail ஆகும்
// cin-ஐ திரும்ப சரி செய்வது கஷ்டம்!

// istringstream மூலம்
std::istringstream ss {input};
ss >> age;
// ss மட்டும் fail ஆகும்
// cin பாதிக்கப்படவே படாது ✅
```

---

**சுருக்கம்:** User input-ஐ முதலில் **string-ஆக** எடுத்து, பிறகு `istringstream` மூலம் **safely convert** செய்வது best practice!


------------------------------------

`istringstream ஆக மாற்றினால் தான் string int இந்த மாதிரி எல்லாம் மாற்ற முடியுமா`


இல்லை! `istringstream` மட்டும் ஒரே வழி இல்லை — வேற வழிகளும் இருக்கிறது.

---

## String → int மாற்ற உள்ள வழிகள்

### 1. `std::stoi` — எளிமையானது
```cpp
std::string s {"25"};
int age = std::stoi(s);  // direct convert!
std::cout << age;  // 25
```

### 2. `std::stod` — double-க்கு
```cpp
std::string s {"3.14"};
double d = std::stod(s);  // 3.14
```

### 3. `istringstream` — validate செய்யணும் என்றால்
```cpp
std::istringstream ss {"25"};
int age {};
ss >> age;  // convert + validate ✅
```

---

## int → String மாற்ற

### `std::to_string`
```cpp
int age {25};
std::string s = std::to_string(age);  // "25"
```

---

## எப்போது எதை பயன்படுத்தணும்?

```
validate வேண்டாம், just convert → stoi / stod
validate வேண்டும்             → istringstream
int/double → string            → to_string
```

---

**சுருக்கம்:** `istringstream` powerful — ஆனால் simple convert-க்கு `stoi`, `stod`, `to_string` போதும்!
