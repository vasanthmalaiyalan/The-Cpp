`istringstream ஆக மாற்றினால் தான் string int இந்த மாதிரி எல்லாம் மாற்ற முடியுமா`

இல்லை! `istringstream` மட்டும் ஒரே வழி இல்லை — வேற வழிகளும் இருக்கிறது.

---

## String → int மாற்ற உள்ள வழிகள்

### 1. `std::stoi` — எளிமையானது
```cpp
std::string s {"25"};
int age = std::stoi(s);  // direct convert!
std::cout << age;  // 25
```

### 2. `std::stod` — double-க்கு
```cpp
std::string s {"3.14"};
double d = std::stod(s);  // 3.14
```

### 3. `istringstream` — validate செய்யணும் என்றால்
```cpp
std::istringstream ss {"25"};
int age {};
ss >> age;  // convert + validate ✅
```

---

## int → String மாற்ற

### `std::to_string`
```cpp
int age {25};
std::string s = std::to_string(age);  // "25"
```

---

## எப்போது எதை பயன்படுத்தணும்?

```
validate வேண்டாம், just convert → stoi / stod
validate வேண்டும்             → istringstream
int/double → string            → to_string
```

**சுருக்கம்:** `istringstream` powerful — ஆனால் simple convert-க்கு `stoi`, `stod`, `to_string` போதும்!

`istringstream பயன்படுத்துவது நோக்கம்?`


## `istringstream` பயன்படுத்துவதன் நோக்கம்

ஒரே வார்த்தையில் சொன்னால் — **ஒரு string-ஐ பல pieces-ஆக பிரிக்க!**

---

## Best Example — ஒரு Line-ஐ பிரிக்கிறோம்

```cpp
#include <iostream>
#include <sstream>
#include <string>

int main()
{
    std::string line {"John 25 75.5"};
    //                 name age weight — எல்லாம் ஒரே string-இல்!

    std::istringstream ss {line};

    std::string name {};
    int age {};
    double weight {};

    ss >> name >> age >> weight;  // தனித்தனியாக பிரிக்கிறது!

    std::cout << "Name   : " << name   << '\n';  // John
    std::cout << "Age    : " << age    << '\n';  // 25
    std::cout << "Weight : " << weight << '\n';  // 75.5
}
```

---

## Real Life — CSV File படிக்கிறோம்

```cpp
std::string line {"John,25,75.5"};

// comma-ஐ space-ஆக மாற்றி
for (char& c : line)
    if (c == ',') c = ' ';

std::istringstream ss {line};

std::string name {};
int age {};
double weight {};

ss >> name >> age >> weight;  // ✅
```

---

## சுருக்கம்

```
ifstream    → file-இலிருந்து    பல pieces எடுக்கும்
istringstream → string-இலிருந்து பல pieces எடுக்கும்
```

**ஒரு string-இல் mixed data இருக்கும்போது — `istringstream` best choice!**
