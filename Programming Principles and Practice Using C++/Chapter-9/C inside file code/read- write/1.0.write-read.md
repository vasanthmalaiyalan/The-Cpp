நீ கேட்டது library usage இல்லை. இந்த functions **internally என்ன concept செய்கிறது** என்பதை pure C-ல் புரிந்துகொள்ள வேண்டும். சரி, ஒவ்வொன்றாக lowest practical level-ல் பார்க்கலாம்.

# 1. `strlen()` எப்படி வேலை செய்கிறது?

நீ:

```c
strlen("Tony")
```

எழுதினால்:

```text
T o n y \0
```

memory-ல் இருக்கும்.

Internal idea:

```c
size_t my_strlen(const char* str)
{
    size_t len = 0;

    while (str[len] != '\0')
    {
        len++;
    }

    return len;
}
```

---

Example:

```c
char text[] = "Tony";
```

Memory:

```text
Address      Value

1000         'T'
1001         'o'
1002         'n'
1003         'y'
1004         '\0'
```

Loop:

```text
T -> len=1
o -> len=2
n -> len=3
y -> len=4
\0 stop
```

Result:

```text
4
```

# 2. `snprintf(...,"%d",45)` எப்படி?

நீ:

```c
snprintf(buffer, 100, "%d", 45);
```

எழுதினால்

```text
45
```

string-ஆ convert ஆக வேண்டும்.

Internal idea:

```c
void my_itoa(int value, char* buffer)
{
    int i = 0;

    while (value > 0)
    {
        buffer[i] =
            (value % 10) + '0';

        value /= 10;

        i++;
    }

    buffer[i] = '\0';
}
```

ஆனால் இது reverse ஆகும்:

```text
45

5
4
```

அதனால் reverse செய்ய வேண்டும்.

Real implementation மிகவும் பெரியது:

```text
%d
%x
%f
%s
%llu
...
```

எல்லாம் handle செய்யும்.

# 3. `read()` எப்படி?

Conceptually:

```c
ssize_t my_read(
    int fd,
    char* buffer,
    size_t size
)
{
    kernel_copy_file_data_to_buffer(
        fd,
        buffer,
        size
    );

    return bytes_read;
}
```

---

Suppose file:

```text
person.txt

Tony
```

Disk:

```text
T
o
n
y
```

---

Call:

```c
char buffer[1024];

read(
    fd,
    buffer,
    1024
);
```

Kernel:

```text
Disk
 ↓
Kernel buffer
 ↓
Your buffer
```

copies data.

Result:

```text
buffer

T
o
n
y
```

---

Simplified simulation:

```c
int my_read(
    const char* file_data,
    char* buffer,
    int max_size
)
{
    int i = 0;

    while (
        file_data[i] != '\0'
        &&
        i < max_size
    )
    {
        buffer[i] =
            file_data[i];

        i++;
    }

    return i;
}
```

# 4. `write()` எப்படி?

Suppose:

```c
write(
    fd,
    "Tony",
    4
);
```

---

Kernel concept:

```text
User Buffer
     ↓
Kernel Buffer
     ↓
Disk
```

---

Simulation:

```c
void my_write(
    char* file,
    const char* text,
    int size
)
{
    int i;

    for (i = 0; i < size; i++)
    {
        file[i] =
            text[i];
    }
}
```

---

Example:

Before:

```text
file

----
```

After:

```text
Tony
```

# 5. `open()` எப்படி?

Real:

```c
fd = open(
    "person.txt",
    O_WRONLY | O_CREAT,
    0644
);
```

---

Kernel internally conceptually:

```c
struct File
{
    char name[100];
    int position;
    int permissions;
};
```

---

Kernel table:

```text
FD TABLE

3 -> person.txt
4 -> notes.txt
5 -> image.png
```

---

Simplified:

```c
int next_fd = 3;

int my_open(const char* filename)
{
    printf(
        "Opening %s\n",
        filename
    );

    return next_fd++;
}
```

---

Call:

```c
int fd =
    my_open(
        "person.txt"
    );
```

Output:

```text
Opening person.txt

fd = 3
```

# Complete Tiny Simulation

```c
#include <stdio.h>

int main()
{
    char fake_file[100];

    const char* text =
        "Tony Stark";

    int len = 0;

    while (text[len] != '\0')
    {
        len++;
    }

    printf(
        "strlen = %d\n",
        len
    );

    for (int i = 0; i < len; i++)
    {
        fake_file[i] =
            text[i];
    }

    fake_file[len] = '\0';

    printf(
        "file contains: %s\n",
        fake_file
    );

    char buffer[100];

    int bytes = 0;

    while (
        fake_file[bytes]
        != '\0'
    )
    {
        buffer[bytes] =
            fake_file[bytes];

        bytes++;
    }

    buffer[bytes] = '\0';

    printf(
        "read result: %s\n",
        buffer
    );
}
```

இந்த code-ல் நீ:

```text
strlen()
write()
read()
```

மூன்றின் core algorithm-ஐ நேரடியாக பார்க்கலாம்.

ஆனால் `open()`, `read()`, `write()`-ன் உண்மையான implementation kernel source code-ல் (Linux-ல் millions of lines) இருக்கும். User-space level-ல் புரிந்துகொள்ள வேண்டிய core idea:

```text
open()
    ↓
gets file descriptor

write()
    ↓
copies user memory → kernel → disk

read()
    ↓
copies disk → kernel → user memory

close()
    ↓
releases file descriptor
```

இதுதான் underlying mechanism.
