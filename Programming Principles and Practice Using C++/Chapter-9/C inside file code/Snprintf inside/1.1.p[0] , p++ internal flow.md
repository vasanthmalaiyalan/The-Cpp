## Step by step:

---

### Memory-ல் எப்படி இருக்கும்:

```
Address:  100  101  102  103
Value:    'A'  'B'  'C'  '\0'
```

---

### `char* p = text;`

```
p → 100 (A-இன் address)
```

---

### `printf("%c\n", p[0]);`

```
p[0] என்பது → *(p + 0) → address 100 → 'A'
output: A
```

---

### `p++;`

```
p இப்போ → 101 (B-இன் address)
```

---

### `printf("%c\n", p[0]);`

```
p[0] என்பது → *(p + 0) → address 101 → 'B'
output: B
```

---

### Key point:

```
p[0]  என்பது எப்போதும் → "p இப்போ எங்கே நிக்கிறதோ அங்கிருந்து 0 தள்ளி"
p++   என்பது           → p-இன் starting point மாறும்
```

> `p++` பண்ணிய பிறகு `p[0]` என்பது **B** — index மாறவில்லை, **p நின்னிருக்கும் இடம் மாறியது.**

---------------------

`for loop பண்ணும்போது p[i] மாறியதை நான் பார்த்துள்ளேன்?`


## ஆமா சரிதான்!

---

### for loop-ல்:

```c
char* p = text;  // p → 100 (நகரவில்லை)

for (int i = 0; i < 3; i++)
{
    printf("%c\n", p[i]);
}
```

```
i = 0 → p[0] → *(p + 0) → address 100 → 'A'
i = 1 → p[1] → *(p + 1) → address 101 → 'B'
i = 2 → p[2] → *(p + 2) → address 102 → 'C'
```

> **p நகரவில்லை — i மாறியது.**

---

### உங்கள் code-ல்:

```c
p++;         // p நகர்கிறது → 101
printf(p[0]) // i இல்லை — p நகர்கிறது
```

> **i மாறவில்லை — p நகர்கிறது.**

---

### இரண்டும் same result, different approach:

```
for loop  →  p fixed, i மாறும்
p++       →  i fixed (0), p மாறும்
```
