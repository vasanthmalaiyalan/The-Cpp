## §9.3 Files — Simple Understanding

Stroustrup இந்த section-ல் சொல்ல வருவது:

> **Memory (RAM) temporary. File permanent.**

Program run ஆகும்போது data RAM-ல் இருக்கும்.

```cpp
int age {24};
```

RAM:

```text
+------+
|  24  |
+------+
```

Program close ஆனால்:

```text
Data gone ❌
```

---

ஆனால் file:

```text
person.txt

Vasanth
24
```

Disk-ல் இருக்கும்.

Computer shutdown ஆனாலும்:

```text
Data still exists ✅
```

இதைத்தான் **persistent storage** என்று சொல்கிறார்கள்.

# What is a File?

Book சொல்வது:

> A file is simply a sequence of bytes.

உதாரணம்:

```text
Hello
```

File-ல்:

```text
Byte 0 = H
Byte 1 = e
Byte 2 = l
Byte 3 = l
Byte 4 = o
```

# Reading a File Steps

Book gives 4 steps.

---

## Step 1 — Know file name

```cpp
const char* file_name {"person.txt"};
```

---

## Step 2 — Open file

```cpp
std::ifstream input_file {file_name};
```

---

## Step 3 — Read data

```cpp
std::string name;
int age;

input_file >> name >> age;
```

---

## Step 4 — Close file

Usually automatic.

```cpp
{
    std::ifstream input_file {"person.txt"};
}
```

Scope ends:

```text
Destructor called
↓
close()
```

Automatic.

This is RAII.

# Best Professional Example

This example demonstrates the entire §9.3 concept.

```cpp
#include <fstream>
#include <iostream>
#include <string>

struct Person
{
    std::string name;
    int age {};
};

bool save_person(const Person& person)
{
    std::ofstream output_file {"person.txt"};

    if (!output_file)
    {
        std::cerr << "Failed to create file.\n";
        return false;
    }

    output_file << person.name << '\n'
                << person.age  << '\n';

    return true;
}

bool load_person(Person& person)
{
    std::ifstream input_file {"person.txt"};

    if (!input_file)
    {
        std::cerr << "Failed to open file.\n";
        return false;
    }

    input_file >> person.name
               >> person.age;

    return static_cast<bool>(input_file);
}

int main()
{
    Person person {};

    std::cout << "Enter name: ";
    std::cin >> person.name;

    std::cout << "Enter age: ";
    std::cin >> person.age;

    if (!save_person(person))
    {
        return 1;
    }

    Person loaded_person {};

    if (!load_person(loaded_person))
    {
        return 1;
    }

    std::cout << "\nData read from file\n";
    std::cout << "Name : "
              << loaded_person.name << '\n';

    std::cout << "Age  : "
              << loaded_person.age << '\n';
}
```

## One-Line Summary of §9.3

> **A file is a persistent sequence of bytes. `ofstream` converts C++ objects into bytes and writes them to a file, while `ifstream` reads bytes from a file and reconstructs C++ objects from them.**
