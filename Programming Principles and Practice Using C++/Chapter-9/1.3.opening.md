இந்த **§9.3.1 Opening a file** section-ல் Stroustrup சொல்லும் முக்கியமான விஷயம்:

> **File-ஐ பயன்படுத்துவதற்கு முன் அதை stream-உடன் connect (open) செய்ய வேண்டும்.**

---

# Three File Stream Types

C++-ல் 3 முக்கிய file streams உள்ளன.

| Type       | Purpose                      |
| ---------- | ---------------------------- |
| `ifstream` | File-லிருந்து படிக்க (Input) |
| `ofstream` | File-க்கு எழுத (Output)      |
| `fstream`  | Read + Write இரண்டும்        |

---

## Visual Model

### Reading

```text
data.txt
    ↓
ifstream
    ↓
Program
```

---

### Writing

```text
Program
    ↓
ofstream
    ↓
result.txt
```

# Example 1: Reading a File

```cpp
std::string file_name {};

std::cout << "Enter file name: ";
std::cin >> file_name;

std::ifstream input_file {file_name};
```

Suppose user enters:

```text
data.txt
```

Internally:

```text
input_file
      ↓
data.txt
```

connection உருவாகிறது.

---

# Why Check `!input_file` ?

```cpp
if (!input_file)
{
    std::cerr << "Cannot open file\n";
}
```

Suppose:

```text
data.txt
```

exists இல்லை.

OS:

```text
open() failed
```

C++ stream enters failure state.

---

Then:

```cpp
if (!input_file)
```

becomes:

```cpp
if (true)
```

---

# Mental Model

Think:

```cpp
std::ifstream input_file {"data.txt"};
```

roughly does:

```text
1. Ask OS to open file
2. Create buffer
3. Attach buffer to file
4. Return stream object
```

# Reading Loop

Book example:

```cpp
for (Point p; input_file >> p;)
{
    points.push_back(p);
}
```

This is a very professional C++ pattern.

---

Equivalent expanded version:

```cpp
Point p;

while (input_file >> p)
{
    points.push_back(p);
}
```

---

Flow:

```text
File
 ↓
Point
 ↓
Vector
```

# Buffer and Flush

Suppose:

```cpp
output_file << "Hello";
```

Usually:

```text
File Buffer
    ↓
Hello
```

First goes into buffer.

Not immediately written to disk.

---

When file closes:

```text
Buffer
   ↓
Disk
```

Data gets flushed.

---

# Very Important RAII Concept

Book emphasizes:

```cpp
void read_file()
{
    std::ifstream file {"data.txt"};

    // use file
}
```

When function ends:

```text
file object destroyed
       ↓
file automatically closed
       ↓
buffer flushed
```

---

No need:

```cpp
file.close();
```

Most of the time.

# Company-Style Example

This is closer to real-world C++.

```cpp
#include <fstream>
#include <iostream>
#include <string>
#include <vector>

std::vector<int> read_numbers(const std::string& file_name)
{
    std::ifstream input_file {file_name};

    if (!input_file)
    {
        throw std::runtime_error("Failed to open file");
    }

    std::vector<int> numbers {};

    int value {};

    while (input_file >> value)
    {
        numbers.push_back(value);
    }

    return numbers;
}

int main()
{
    try
    {
        const auto numbers = read_numbers("numbers.txt");

        for (int value : numbers)
        {
            std::cout << value << '\n';
        }
    }
    catch (const std::exception& exception)
    {
        std::cerr << exception.what() << '\n';
        return 1;
    }
}
```

# Why Stroustrup Prefers Constructor Open?

He prefers:

```cpp
std::ifstream file {"data.txt"};
```

instead of:

```cpp
std::ifstream file;

file.open("data.txt");
```

because:

### Constructor Style

```cpp
std::ifstream file {"data.txt"};
```

File is immediately usable.

No chance of forgetting.

---

### Explicit Open Style

```cpp
std::ifstream file;

// 100 lines later...

file.open("data.txt");
```

Possible bug:

```cpp
file >> value;
```

before open.

# Core Idea of §9.3.1

The whole section can be summarized as:

```text
Open Early
Check Success
Use Stream
Let Scope Close It
```

Professional C++ developers follow this pattern almost everywhere:

```cpp
std::ifstream input_file {"data.txt"};

if (!input_file)
{
    // handle error
}

// use file

// automatic close when scope ends
```

This is one of the first practical examples of **RAII (Resource Acquisition Is Initialization)**, which is one of the most important ideas in modern C++.
