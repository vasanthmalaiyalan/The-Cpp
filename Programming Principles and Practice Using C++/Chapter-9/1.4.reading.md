இந்த **§9.3.2 Reading and writing a file** section-ல் Stroustrup ஒரு மிகவும் முக்கியமான pattern-ஐ கற்றுக்கொடுக்கிறார்:

> **File → Object → Vector → File**

அதாவது:

```text
temperature.txt
        ↓
Reading objects
        ↓
vector<Reading>
        ↓
formatted_output.txt
```

# Why struct Reading?

இந்த இரண்டு values logically ஒன்றாக சேர்ந்தவை.

Bad:

```cpp
int hour;
double temperature;
```

பல இடங்களில் manage பண்ண வேண்டும்.

---

Good:

```cpp
struct Reading
{
    int hour {};
    double temperature {};
};
```

இப்போது:

```cpp
Reading r {3, 59.2};
```

Meaning:

```text
hour        = 3
temperature = 59.2
```

---

# Memory Layout

```cpp
Reading r {3, 59.2};
```

Memory:

```text
+-------------------+
| hour = 3          |
+-------------------+
| temperature=59.2  |
+-------------------+
```

# The Input Loop

Book code:

```cpp
while (ist >> hour >> temperature)
{
    temps.push_back(
        Reading{hour, temperature}
    );
}
```

---

Let's simulate.

File:

```text
0 60.7
1 60.6
2 60.3
```

---

Iteration 1

```cpp
ist >> hour >> temperature;
```

Reads:

```text
hour = 0
temperature = 60.7
```

Creates:

```cpp
Reading{0, 60.7}
```

Stores:

```text
temps[0]
```

---

Iteration 2

Reads:

```text
hour = 1
temperature = 60.6
```

Stores:

```text
temps[1]
```

---

Iteration 3

Reads:

```text
hour = 2
temperature = 60.3
```

Stores:

```text
temps[2]
```

---

File ends.

```cpp
ist >> hour >> temperature
```

fails.

Loop automatically stops.

---

# Why This Loop Is Beautiful

This line:

```cpp
while (ist >> hour >> temperature)
```

means:

```text
Read two values

If success:
    continue

If failure:
    stop
```

No explicit EOF check needed.

This is one of the most common C++ patterns.

# Data Validation

Book adds:

```cpp
if (hour < 0 || hour > 23)
{
    error("hour out of range");
}
```

Why?

Because:

```text
0..23
```

are valid hours.

---

Bad file:

```text
27 60.7
```

---

Result:

```cpp
hour = 27
```

Program detects:

```cpp
27 > 23
```

and reports error.

# Real Company-Style Version

This is closer to modern C++:

```cpp
#include <fstream>
#include <iostream>
#include <string>
#include <vector>

struct Reading
{
    int hour {};
    double temperature {};
};

std::vector<Reading> read_temperatures(
    const std::string& file_name)
{
    std::ifstream input_file {file_name};

    if (!input_file)
    {
        throw std::runtime_error(
            "Cannot open input file");
    }

    std::vector<Reading> readings {};

    int hour {};
    double temperature {};

    while (input_file >> hour >> temperature)
    {
        if (hour < 0 || hour > 23)
        {
            throw std::runtime_error(
                "Hour out of range");
        }

        readings.push_back(
            Reading{hour, temperature});
    }

    return readings;
}

void write_temperatures(
    const std::vector<Reading>& readings,
    const std::string& file_name)
{
    std::ofstream output_file {file_name};

    if (!output_file)
    {
        throw std::runtime_error(
            "Cannot open output file");
    }

    for (const Reading& reading : readings)
    {
        output_file
            << '('
            << reading.hour
            << ','
            << reading.temperature
            << ")\n";
    }
}

int main()
{
    try
    {
        const auto readings =
            read_temperatures("temps.txt");

        write_temperatures(
            readings,
            "formatted_temps.txt");

        std::cout
            << "Temperature data processed.\n";
    }
    catch (const std::exception& ex)
    {
        std::cerr
            << ex.what()
            << '\n';

        return 1;
    }
}
```

# Most Important Lesson of §9.3.2

Stroustrup is teaching three professional habits:

### 1. Represent real-world data with a struct

```cpp
struct Reading
{
    int hour;
    double temperature;
};
```

---

### 2. Read records using stream extraction

```cpp
while (input_file >> hour >> temperature)
```

---

### 3. Validate before storing

```cpp
if (hour < 0 || hour > 23)
```

---

This exact pattern is used everywhere:

```text
CSV files
Log files
Configuration files
Sensor data
Security scan results
Bug bounty reports
Network packet logs
```

Read → Validate → Store → Process → Write

That is the core workflow this section is teaching.
