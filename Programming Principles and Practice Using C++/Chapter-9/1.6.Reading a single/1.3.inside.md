## `std::cin` எப்படி வேலை செய்கிறது?

`std::cin >> value` என்பது **இரண்டு வேலை** செய்கிறது:

1. Value-ஐ store செய்கிறது
2. **Success/Failure-ஐ return செய்கிறது** (stream reference)

---

## Stream ஒரு "State machine"

`cin` எப்போதும் ஒரு **state**-ல் இருக்கும்:

| State | அர்த்தம் |
|-------|---------|
| `good` | எல்லாம் சரி |
| `fail` | தவறான input (எண் எதிர்பார்த்தோம், வேறு வந்தது) |
| `eof` | Input முடிந்துவிட்டது (Ctrl+D) |

---

## `!` ஏன் use ஆகிறது?

```cpp
if (!(std::cin >> value))
```

இதை இப்படி படியுங்கள்:

```
cin >> value    →  stream object return செய்கிறது
                   (value store ஆகிவிட்டது)

bool ஆக மாற்றும்போது:
  success  →  true
  failure  →  false

!(false)  →  true   ← if block உள்ளே செல்லும்
!(true)   →  false  ← if block skip ஆகும்
```

---

## நடைமுறை உதாரணம்

```
Input: "abc"  →  cin fail ஆகும்  →  !(false) = true  →  if உள்ளே
Input: "5"    →  cin success     →  !(true) = false  →  if skip
Input: Ctrl+D →  cin eof        →  !(false) = true  →  if உள்ளே
```

---

## உள்ளே இரண்டு cases ஏன்?

```cpp
if (!(std::cin >> value))
{
    if (std::cin.eof())   // Ctrl+D அழுத்தினார்
    {
        throw ...;        // Program-ஐ நிறுத்து
    }

    if (std::cin.fail())  // "abc" போன்றது தந்தார்
    {
        // Error காட்டு, மீண்டும் கேள்
        std::cin.clear();
        std::cin.ignore(...);
        continue;
    }
}
```

**eof** → User input-ஐ மூடிவிட்டார் → Recover இல்லை → Exception

**fail** → தவறான type → Recover முடியும் → மீண்டும் try

---

## Key Insight

`cin` என்பது வெறும் "data pipe" மட்டுமில்லை — அது **success/failure நிலையையும் சொல்லும்** ஒரு object. `!` operator அந்த நிலையை check செய்கிறது.

------------------------------------------

## இந்த Code என்ன செய்கிறது?

### Step 1: Input வாங்கு, failure check செய்

```cpp
if (!(std::cin >> value))
```
User தந்த input **integer இல்லை** அல்லது **EOF** என்றால் உள்ளே செல்லும்.

---

### Step 2: EOF check

```cpp
if (std::cin.eof())
{
    throw std::runtime_error("Input closed by user");
}
```

**எப்போது?** → User **Ctrl+D** (Linux) அல்லது **Ctrl+Z** (Windows) அழுத்தும்போது

**என்ன ஆகும்?** → இனி input வர வழியில்லை, எனவே exception throw செய்து program-ஐ நிறுத்துகிறோம்

---

### Step 3: தவறான type வந்தால்

```cpp
if (std::cin.fail())
{
    std::cout << "Not an integer. Try again.\n";
```
User `"abc"` அல்லது `"3.5"` போன்றது தந்தால் — error message காட்டு

---

```cpp
    std::cin.clear();
```
`cin`-இன் **error state-ஐ reset** செய்கிறது — இல்லாவிட்டால் cin மேலும் input ஏற்காது

---

```cpp
    std::cin.ignore(
        std::numeric_limits<std::streamsize>::max(),
        '\n');
```
Buffer-ல் மிச்சமிருக்கும் **குப்பை characters எல்லாவற்றையும் அழி** — `'\n'` வரை

உதாரணம்: User `"abc\n"` தந்தால், `"abc"` buffer-ல் தங்கும் — அதை clear செய்கிறோம்

---

```cpp
    continue;
```
Loop-இன் மேலே திரும்பு → மீண்டும் User-கிட்டே கேள்

---

### ஒட்டுமொத்த Flow

```
User input தரும்
      │
      ▼
integer-ஆ?  ──Yes──→  value store → if-ஐ skip → range check செல்
      │
      No
      │
      ▼
EOF-ஆ?  ──Yes──→  Exception → Program முடிவு
      │
      No
      │
      ▼
fail-ஆ?  ──Yes──→  Error msg → clear → ignore → மீண்டும் கேள்
```

## Common State Functions

```cpp
stream.eof()    // EOF வந்துவிட்டதா?
stream.fail()   // Operation தோல்வியடைந்ததா?
stream.bad()    // Serious error (data loss) ஆனதா?
stream.good()   // எல்லாம் சரியா இருக்கா?
stream.clear()  // Error state reset செய்
```

இவை எல்லா streams-க்கும் வேலை செய்யும்:

```cpp
std::cin        // keyboard input
std::cout       // screen output
std::ifstream   // file read
std::ofstream   // file write
std::stringstream // string input/output
```

---

## உதாரணம்

```cpp
std::ifstream file("data.txt");

if (file.fail())
{
    std::cout << "File திறக்கவில்லை!\n";
}

int x;
file >> x;

if (file.eof())
{
    std::cout << "File முடிந்துவிட்டது\n";
}
```

`cin >> value` என்று எழுதுவதே, `file >> x` என்று எழுதுவதே **ஒரே மாதிரி வேலை செய்யும்** — same base class, same functions.

## Inheritance Tree

```
std::basic_ios        ← eof(), fail(), bad(), good()
       │
  ┌────┴────┐
istream   ostream
  │           │
 cin        cout
  │
ifstream   stringstream
```

எனவே நீ `cin`-ல் கற்றது **file, string streams எல்லாவற்றிலும்** directly பயன்படும்.

இந்த **§9.5 Reading a single value** section-ல் Stroustrup ஒரு integer read செய்வது பற்றி மட்டும் பேசவில்லை.

அவர் உண்மையில் கற்றுக்கொடுப்பது:

> **"User input-ஐ எப்படி robust-ஆக handle செய்வது?"**

---

# The Problem

Goal:

```text
User must enter:
1 to 10
```

---

First attempt:

```cpp
int get10()
{
    std::cout
        << "Enter a number (1-10): ";

    int n {};

    while (std::cin >> n)
    {
        if (1 <= n && n <= 10)
        {
            return n;
        }

        std::cout
            << "Out of range. Try again.\n";
    }

    return n;
}
```

Looks okay.

But it has serious problems.

---

# Problem 1: Out-of-Range Value

User enters:

```text
20
```

Program reads:

```cpp
n = 20
```

Not valid.

Need:

```text
Ask again
```

This is recoverable.

---

# Problem 2: EOF

User presses:

Linux:

```text
Ctrl+D
```

Windows:

```text
Ctrl+Z
```

---

Now:

```cpp
std::cin.eof()
```

becomes true.

---

Meaning:

```text
User is done.
No more input.
```

---

As Stroustrup says:

There is usually no point asking again.

The user has closed the input stream.

---

# Problem 3: Wrong Type

User enters:

```text
hello
```

instead of:

```text
7
```

---

istream expects:

```text
integer
```

gets:

```text
h
```

---

Result:

```cpp
std::cin.fail()
```

becomes true.

---

# The Three Error Strategies

Book says every error usually has 3 choices.

---

## Strategy 1

Handle locally.

```cpp
while (true)
{
    // keep asking
}
```

---

## Strategy 2

Throw exception.

```cpp
throw std::runtime_error(
    "Invalid input");
```

---

## Strategy 3

Ignore.

```cpp
int x {};
std::cin >> x;
```

No checking.

Hope for the best.

---

Stroustrup says:

```text
Learning toy programs:
    Maybe

Real programs:
    Never
```

# Best Example Covering Entire Section

This example demonstrates all ideas from §9.5.

```cpp
#include <iostream>
#include <limits>
#include <stdexcept>

int get_number_1_to_10()
{
    while (true)
    {
        std::cout
            << "Enter an integer "
            << "(1-10): ";

        int value {};

        if (!(std::cin >> value))
        {
            if (std::cin.eof())
            {
                throw std::runtime_error(
                    "Input closed by user");
            }

            if (std::cin.fail())
            {
                std::cout
                    << "Not an integer. "
                    << "Try again.\n";

                std::cin.clear();

                std::cin.ignore(
                    std::numeric_limits<
                        std::streamsize>::max(),
                    '\n');

                continue;
            }
        }

        if (value < 1 || value > 10)
        {
            std::cout
                << "Number must be "
                << "between 1 and 10.\n";

            continue;
        }

        return value;
    }
}

int main()
{
    try
    {
        const int value =
            get_number_1_to_10();

        std::cout
            << "Accepted value: "
            << value
            << '\n';
    }
    catch (const std::exception& exception)
    {
        std::cerr
            << exception.what()
            << '\n';

        return 1;
    }
}
```

# Why ignore() Is Needed

Without:

```cpp
std::cin.ignore(...)
```

buffer still contains:

```text
hello
```

---

Next loop:

```cpp
std::cin >> value;
```

immediately sees:

```text
hello
```

again.

---

Infinite error loop.

---

So:

```cpp
clear()
```

fixes stream state.

```cpp
ignore()
```

removes bad characters.

Both are needed.

# Most Important Lesson of §9.5

Stroustrup is teaching a professional mindset:

```text
Reading an integer
≠
cin >> value
```

Real reading means:

```text
Read
 ↓
Check type
 ↓
Check range
 ↓
Handle EOF
 ↓
Recover if possible
 ↓
Return valid value
```

That's why a seemingly simple task like "read an integer from the user" becomes an entire section in the book. In production software, input validation is often more work than the actual computation.
