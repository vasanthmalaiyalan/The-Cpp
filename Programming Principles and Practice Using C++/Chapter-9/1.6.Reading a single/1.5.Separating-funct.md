இந்த **§9.5.2 Separating dialog from function** section-ல் Stroustrup சொல்ல வருவது:

> **"Function-ன் வேலை data process பண்ணுவது. User-கிட்ட பேசுவது (dialog) வேறு வேலை."** 

இது software engineering-ல் மிகவும் முக்கியமான principle.

---

# Previous Version Problem

நம்முடைய function:

```cpp
int get_int(int low, int high)
{
    std::cout
        << "Please enter a number\n";

    while (true)
    {
        int n = get_int();

        if (low <= n && n <= high)
        {
            return n;
        }

        std::cout
            << "Out of range\n";
    }
}
```

# Better Example

```cpp
int get_int(
    int low,
    int high,
    const std::string& greeting,
    const std::string& error_message)
{
    std::cout
        << greeting
        << " ["
        << low
        << ':'
        << high
        << "]\n";

    while (true)
    {
        int value {};

        if (std::cin >> value)
        {
            if (low <= value &&
                value <= high)
            {
                return value;
            }
        }

        std::cout
            << error_message
            << '\n';

        std::cin.clear();
        std::cin.ignore(
            10000,
            '\n');
    }
}
```

# Professional Design

Best practice:

```cpp
int get_int(
    int low,
    int high);
```

---

Only validates.

No printing.

```cpp
int get_int(
    int low,
    int high)
{
    while (true)
    {
        int value {};

        if (!(std::cin >> value))
        {
            throw std::runtime_error(
                "Input failure");
        }

        if (low <= value &&
            value <= high)
        {
            return value;
        }

        throw std::out_of_range(
            "Value out of range");
    }
}
```

---

Then UI layer handles messages.

```cpp
int main()
{
    try
    {
        std::cout
            << "Enter strength [1:10]: ";

        int strength =
            get_int(1,10);

        std::cout
            << "Strength: "
            << strength
            << '\n';
    }
    catch (...)
    {
        std::cout
            << "Invalid input\n";
    }
}
```

# Best Modern C++ Example

```cpp
#include <iostream>
#include <stdexcept>

int get_int(
    int low,
    int high,
    std::istream& input_stream)
{
    int value {};

    if (!(input_stream >> value))
    {
        throw std::runtime_error(
            "Input is not an integer");
    }

    if (value < low ||
        value > high)
    {
        throw std::out_of_range(
            "Value out of range");
    }

    return value;
}

int main()
{
    try
    {
        std::cout
            << "Enter age [1-120]: ";

        int age =
            get_int(
                1,
                120,
                std::cin);

        std::cout
            << "Age = "
            << age
            << '\n';
    }
    catch (const std::exception& ex)
    {
        std::cerr
            << ex.what()
            << '\n';
    }
}
```

# Main Lesson of §9.5.2

Stroustrup is teaching a deeper software-engineering rule:

```text
Bad:

Function
    ├─ Reads data
    ├─ Validates
    ├─ Prints messages

Good:

Function
    ├─ Reads data
    └─ Validates

Caller
    └─ Handles messages
```

This separation makes functions reusable in console apps, GUI apps, web servers, APIs, services, and libraries without rewriting the validation logic.
