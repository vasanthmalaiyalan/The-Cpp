### Stream State - Custom Implementation

```cpp
#include <iostream>
#include <sstream>

// Stream state flags - bit positions
// இவை binary flags, ஒவ்வொன்றும் ஒரு bit
namespace StreamBits
{
    constexpr int goodbit = 0b0000;  // 0 - எல்லாம் சரி
    constexpr int eofbit  = 0b0001;  // 1 - file முடிந்தது
    constexpr int failbit = 0b0010;  // 2 - படிக்க தோல்வி
    constexpr int badbit  = 0b0100;  // 4 - buffer பாதிப்பு
}

class MyStream
{
private:
    int m_state { StreamBits::goodbit };  // தொடக்கத்தில் good நிலை
    std::string m_buffer {};

public:
    MyStream(const std::string& data) : m_buffer(data) {}

    // eof() - eofbit set ஆனதா?
    bool eof()  const { return m_state & StreamBits::eofbit;  }

    // fail() - failbit அல்லது badbit set ஆனதா?
    bool fail() const { return m_state & (StreamBits::failbit | StreamBits::badbit); }

    // bad() - badbit மட்டும் set ஆனதா?
    bool bad()  const { return m_state & StreamBits::badbit;  }

    // good() - எந்த bit-உம் set ஆகவில்லையா?
    bool good() const { return m_state == StreamBits::goodbit; }

    // clear() - எல்லா flags-உம் reset
    void clear() { m_state = StreamBits::goodbit; }

    // ஒரு integer படிக்க முயற்சி
    MyStream& operator>>(int& value)
    {
        if (m_buffer.empty())
        {
            // Buffer காலியாக உள்ளது - EOF + fail
            m_state |= StreamBits::eofbit;
            m_state |= StreamBits::failbit;
            return *this;
        }

        try
        {
            std::size_t characters_read {};
            value = std::stoi(m_buffer, &characters_read);

            // படித்த பகுதியை நீக்கு
            m_buffer = m_buffer.substr(characters_read);

            // இடைவெளிகளை நீக்கு
            while (!m_buffer.empty() && m_buffer[0] == ' ')
                m_buffer = m_buffer.substr(1);
        }
        catch (...)
        {
            // Integer இல்லை - failbit set செய்
            m_state |= StreamBits::failbit;
        }

        return *this;
    }

    void print_state() const
    {
        std::cout << "good(): " << good() << '\n';
        std::cout << "eof():  " << eof()  << '\n';
        std::cout << "fail(): " << fail() << '\n';
        std::cout << "bad():  " << bad()  << '\n';
    }
};

int main()
{
    std::cout << "=== Case 1: சாதாரண படிப்பு ===\n";
    {
        MyStream stream { "10 20 30" };
        int value {};

        while (stream >> value)
            std::cout << "படித்தது: " << value << '\n';

        std::cout << "\nStream நிலை:\n";
        stream.print_state();
    }

    std::cout << "\n=== Case 2: clear() பின் மீண்டும் படிப்பு ===\n";
    {
        MyStream stream { "42 hello" };
        int value {};

        stream >> value;
        std::cout << "படித்தது: " << value << '\n';

        std::cout << "\nclear() முன்:\n";
        stream.print_state();

        stream.clear();

        std::cout << "\nclear() பின்:\n";
        stream.print_state();
    }
}
```

### Core Idea - Bit Operations:

```
m_state value   binary   என்ன நிலை?
─────────────────────────────────────
     0          0000     good ✅
     1          0001     eof
     2          0010     fail
     3          0011     eof + fail  ← EOF படிக்கும்போது இதுவே நடக்கும்
     4          0100     bad
```

`|=` operator மூலம் flags **சேர்க்கப்படுகின்றன**, `&` மூலம் **சோதிக்கப்படுகின்றன் —** இதுவே real C++ stream-உம் உள்ளே செய்வது.

### `stoi` உள்ளே இப்படி எழுதியிருப்பார்கள்:

```cpp
// std::stoi உள்ளே இருக்கும் logic (simplified)
int stoi(const std::string& str, std::size_t* pos)
{
    int result = 0;
    std::size_t i = 0;  // index tracker

    // ஒவ்வொரு character படிக்கிறது
    while (i < str.size() && std::isdigit(str[i]))
    {
        result = result * 10 + (str[i] - '0');
        i++;  // எத்தனை படித்தோம் count செய்கிறது
    }

    // pos என்பது நாம் கொடுத்த &characters_read
    // அந்த address-இல் i-ஐ சேமிக்கிறது
    if (pos != nullptr)
        *pos = i;  // ← இங்கே 2 சேமிக்கப்படுகிறது

    return result;
}
```

### Part 2: `|=` என்றால் என்ன?

இது **bitwise OR assignment:**

```cpp
m_state |= StreamBits::eofbit;

// இதே தான்:

```

### ஏன் இது தேவை?

```
m_state = 0000  (good)

eofbit  = 0001
failbit = 0010

// EOF வந்தால்:
m_state |= eofbit;   → 0000 | 0001 = 0001
m_state |= failbit;  → 0001 | 0010 = 0011
                                      ↑
                              இரண்டும் சேர்ந்து set ஆகும்
                              பழைய flags போகாது
```

### `=` vs `|=` வித்தியாசம்:

```
m_state = eofbit;   → 0001  ← failbit போய்விடும் ❌
m_state |= eofbit;  → 0011  ← failbit இருக்கும்  ✅
```

**சுருக்கம்:** `|=` என்பது பழைய flags-ஐ அழிக்காமல் புதிய flag மட்டும் சேர்க்கும்.

### badbit சோதிக்க (set ஆகவில்லை):

```
m_state    = 0b0011

─────────────────────
```

### Core Idea - AND உண்மை அட்டவணை:

```
1 & 1 = 1  ← இரண்டும் 1 ஆனால் மட்டும் 1
1 & 0 = 0
0 & 1 = 0
0 & 0 = 0
```

---

### சுருக்கம்:

```
m_state = 0b0011
              ││
              │└── bit 0 = eofbit
              └─── bit 1 = failbit

& eofbit  → bit 0 மட்டும் சோதிக்கிறது
& failbit → bit 1 மட்டும் சோதிக்கிறது

ஒவ்வொரு bit தனி "அறை" போல் —
ஒன்றை சோதிக்கும்போது மற்றது தொடப்படவே படாது
```

### சரியான கேள்வி! `fail()` implementation பாருங்கள்:

```cpp
bool fail() const 
{ 
    return m_state & (StreamBits::failbit | StreamBits::badbit); 
}
```

### `fail()` failbit மட்டும் சோதிக்கவில்லை!

```

m_state  = 0b0011
& 0b0110 = 0b0010  ← 0 இல்லை = true = 1 ✅
```

```

இரண்டு காரணங்களில் படிக்க முடியாது:
├── failbit → data இல்லை / wrong type
└── badbit  → buffer பாதிப்பு

இரண்டுமே "fail" தானே!
எனவே இரண்டையும் சேர்த்து சோதிக்கிறது
```

### Real `std::istream` உம் இதே செய்கிறது:

```

std::istream::eof()  → eofbit மட்டும் சோதிக்கிறது
std::istream::bad()  → badbit மட்டும் சோதிக்கிறது
```

**சுருக்கம்:** `fail()` என்பது failbit மட்டும் இல்லை — failbit அல்லது badbit set ஆனாலும் `1` return செய்யும். நம் case-இல் failbit set ஆனதால் `1` வந்தது.

`இது true என்றால் இது இரண்டும் true தானே `if (stream.eof())
    {
        std::cout << "[INFO] Buffer காலி - EOF\n";
        return;
    }

    if (stream.fail())
    {
        std::cout << "[INFO] int அல்லாத character வந்தது\n";
    }
}`?`


### ஆமாம்! இரண்டும் true — ஆனால் `return` காப்பாற்றுகிறது!

```cpp
if (stream.eof())   // true ✅
{
    std::cout << "[INFO] Buffer காலி - EOF\n";
    return;  // ← இங்கே function-இல் இருந்து வெளியே போகிறோம்
             //   fail() check-க்கே போகவில்லை!
}

if (stream.fail())  // ← இங்கே வரவே வராது
{
    std::cout << "[INFO] int அல்லாத character வந்தது\n";
}
```

---

### இல்லாமல் இருந்தால்:

```cpp
if (stream.eof())
{
    std::cout << "[INFO] Buffer காலி - EOF\n";
    // return இல்லை என்றால்...
}

if (stream.fail())  // இதுவும் true — இதுவும் print ஆகும்! ❌
{
    std::cout << "[INFO] int அல்லாத character வந்தது\n";
}
```

```
output:
[INFO] Buffer காலி - EOF
[INFO] int அல்லாத character வந்தது  ← தவறான message!
```

---

### சுருக்கம்:

```
eof() → true
    ↓
print + return   ← function முடிந்தது
    ↓
fail() check-க்கே போகவில்லை ✅
```

**`return` இல்லாமல் இரண்டும் print ஆகும் — அதனால் `return` அவசியம்!**
