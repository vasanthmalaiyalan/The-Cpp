`std::ifstream` மற்றும் `std::ofstream`-ன் **exact real implementation** பல ஆயிரம் lines இருக்கும். அது OS system calls (`open`, `read`, `write`, `close`) + buffering + locale + error handling + stream hierarchy ஆகியவற்றை பயன்படுத்துகிறது.

ஆனால் **core idea**-வை புரிந்துகொள்ள ஒரு simplified custom implementation எழுதலாம்.

Linux-ல் conceptually இது மாதிரி இருக்கும்:

```cpp
#include <iostream>
#include <fcntl.h>
#include <unistd.h>
#include <cstring>

// =====================================================
// SIMPLE OFSTREAM
// =====================================================

class MyOfstream {

private:

    int fd;

public:

    MyOfstream(const char* filename) {

        fd = open(
            filename,
            O_WRONLY | O_CREAT | O_TRUNC,
            0644
        );

        std::cout
            << "[OPEN FOR WRITE]\n";

        std::cout
            << "fd : "
            << fd
            << '\n';
    }

    MyOfstream& operator<<(const char* text) {

        std::cout
            << "[WRITE]\n";

        write(
            fd,
            text,
            strlen(text)
        );

        return *this;
    }

    MyOfstream& operator<<(int value) {

        char buffer[100];

        snprintf(
            buffer,
            sizeof(buffer),
            "%d",
            value
        );

        write(
            fd,
            buffer,
            strlen(buffer)
        );

        return *this;
    }

    ~MyOfstream() {

        std::cout
            << "[CLOSE WRITE FILE]\n";

        close(fd);
    }
};

// =====================================================
// SIMPLE IFSTREAM
// =====================================================

class MyIfstream {

private:

    int fd;

public:

    MyIfstream(const char* filename) {

        fd = open(
            filename,
            O_RDONLY
        );

        std::cout
            << "[OPEN FOR READ]\n";

        std::cout
            << "fd : "
            << fd
            << '\n';
    }

    void read_all() {

        char buffer[1024];

        ssize_t bytes =
            read(
                fd,
                buffer,
                sizeof(buffer) - 1
            );

        if (bytes > 0) {

            buffer[bytes] = '\0';

            std::cout
                << "[FILE CONTENT]\n";

            std::cout
                << buffer
                << '\n';
        }
    }

    ~MyIfstream() {

        std::cout
            << "[CLOSE READ FILE]\n";

        close(fd);
    }
};

// =====================================================
// MAIN
// =====================================================

int main() {

    {
        MyOfstream fout("person.txt");

        fout
            << "Name : Tony Stark\n";

        fout
            << "Age : ";

        fout
            << 45;

        fout
            << "\n";
    }

    {
        MyIfstream fin("person.txt");

        fin.read_all();
    }
}
```

```text
MyOfstream
      ↓
open()
      ↓
kernel file descriptor
      ↓
write()
      ↓
disk

MyIfstream
      ↓
open()
      ↓
read()
      ↓
kernel
      ↓
buffer
      ↓
program
```

## `return *this` என்ன செய்கிறது:

---

### இது இல்லாமல் என்ன ஆகும்:

```cpp
fout << "Name : Tony Stark\n";  // OK
fout << "Age : ";               // OK

// ஆனால் இப்படி பண்ண முடியாது:
fout << "Name : " << "Tony\n";  // ERROR
```

---

### `return *this` இருந்தால்:

```cpp
fout << "Name : " << "Tony\n";

// internally இப்படி:
(fout << "Name : ") << "Tony\n"
        ↓
operator<< "Name : " எழுதும்
return *this  →  fout-ஐயே திரும்ப கொடுக்கும்
        ↓
fout << "Tony\n"  →  மீண்டும் operator<< call ஆகும்
```

---

### `*this` என்றால்:

```
this   →  fout object-இன் address
*this  →  அந்த address-ல் உள்ள object (fout itself)
```

---

### எளிமையாக:

```
fout << "A" << "B" << "C"

Step 1: fout << "A" → எழுது, fout return
Step 2: fout << "B" → எழுது, fout return  
Step 3: fout << "C" → எழுது, fout return
```

> `return *this` என்பது **"என்னையே திரும்ப கொடு"** — அதனால் chain-ஆக `<<` பண்ண முடிகிறது.

# Memory allocate ஆகாதா?

Object memory allocate ஆகிறது.

```cpp
MyOfstream fout("person.txt");
```

இதற்காக:

```text
STACK

fd
```

memory வரும்.

ஆனால்:

```text
heap allocation
```

நடக்க வேண்டிய அவசியம் இல்லை.

---

உதாரணம்:

```cpp
class MyOfstream {

    int fd;
};
```

`sizeof(MyOfstream)`:

```text
4 bytes
```

(அல்லது platform-ஐ பொறுத்து)

அவ்வளவுதான்.

---

இதனால்:

| Operation      | என்ன நடக்கிறது?        |
| -------------- | ---------------------- |
| `new int[100]` | heap memory allocation |
| `malloc()`     | heap memory allocation |
| `open()`       | file open              |
| `read()`       | file read              |
| `write()`      | file write             |
| `close()`      | file close             |

---

அதனால்:

```cpp
MyOfstream fout("person.txt");
```

என்பது:

```text
heap memory create செய்வதற்காக அல்ல

OS-ல் file handle (fd) acquire செய்வதற்காக
```
