## Step by step:

---

### Memory-ல் எப்படி இருக்கும்:

```
Address:  100  101  102  103
Value:    'A'  'B'  'C'  '\0'
```

---

### `char* p = text;`

```
p → 100 (A-இன் address)
```

---

### `printf("%c\n", p[0]);`

```
p[0] என்பது → *(p + 0) → address 100 → 'A'
output: A
```

---

### `p++;`

```
p இப்போ → 101 (B-இன் address)
```

---

### `printf("%c\n", p[0]);`

```
p[0] என்பது → *(p + 0) → address 101 → 'B'
output: B
```

---

### Key point:

```
p[0]  என்பது எப்போதும் → "p இப்போ எங்கே நிக்கிறதோ அங்கிருந்து 0 தள்ளி"
p++   என்பது           → p-இன் starting point மாறும்
```

> `p++` பண்ணிய பிறகு `p[0]` என்பது **B** — index மாறவில்லை, **p நின்னிருக்கும் இடம் மாறியது.**

---------------------

`for loop பண்ணும்போது p[i] மாறியதை நான் பார்த்துள்ளேன்?`


## ஆமா சரிதான்!

---

### for loop-ல்:

```c
char* p = text;  // p → 100 (நகரவில்லை)

for (int i = 0; i < 3; i++)
{
    printf("%c\n", p[i]);
}
```

```
i = 0 → p[0] → *(p + 0) → address 100 → 'A'
i = 1 → p[1] → *(p + 1) → address 101 → 'B'
i = 2 → p[2] → *(p + 2) → address 102 → 'C'
```

> **p நகரவில்லை — i மாறியது.**

---

### உங்கள் code-ல்:

```c
p++;         // p நகர்கிறது → 101
printf(p[0]) // i இல்லை — p நகர்கிறது
```

> **i மாறவில்லை — p நகர்கிறது.**

---

### இரண்டும் same result, different approach:

```
for loop  →  p fixed, i மாறும்
p++       →  i fixed (0), p மாறும்
```

புரிஞ்சுதா?

------------------------------------

`புரியணும் என்றால் இது internally `p++;`எப்படி வேலை செய்து என்று தெரிந்தால் தான் தெளிவாக புரியும்? show that internal code .c ?`


## `p++` internally என்ன செய்கிறது:

---

```c
#include <stdio.h>

int main()
{
    char text[] = "ABC";

    char* p = text;

    printf("Before p++ :\n");
    printf("p address  : %p\n", (void*)p);
    printf("p[0]       : %c\n\n", p[0]);

    // p++ internally இப்படி வேலை செய்கிறது:
    // p = p + 1  (address + sizeof(char) = address + 1)
    p = p + 1;

    printf("After p+1 :\n");
    printf("p address  : %p\n", (void*)p);
    printf("p[0]       : %c\n\n", p[0]);

    // மீண்டும்:
    p = p + 1;

    printf("After p+1 again :\n");
    printf("p address  : %p\n", (void*)p);
    printf("p[0]       : %c\n\n", p[0]);

    return 0;
}
```

---

### Output:

```
Before p++ :
p address  : 0x100
p[0]       : A

After p+1 :
p address  : 0x101
p[0]       : B

After p+1 again :
p address  : 0x102
p[0]       : C
```

---

### Key point:

```
p++  →  internally  →  p = p + sizeof(char)
                               ↓
                        p = p + 1
                               ↓
                        address ஒரு step முன்னே போகும்
```

> `char` = 1 byte, அதனால் +1
> `int*` ஆனால் = +4 bytes
> **type-இன் size-க்கு தகுந்தாற்போல் jump பண்ணும்**

புரிஞ்சுதா?

----------------------------

`p++ internally இப்படி வேலை செய்து ஓகே `p = p + 1;` but இது for loop ஆகும்போது internally எப்படி பார்ப்பது `p[i]  `?`

## `p[i]` internally:

---

```c
#include <stdio.h>

int main()
{
    char text[] = "ABC";

    char* p = text;  // p → address 100

    // p[i] internally இப்படி வேலை செய்கிறது:
    // p[i]  →  *(p + i)

    int i = 0;

    // i = 0
    printf("p[0] = *(p + 0) = *(100 + 0) = *(100) = %c\n", *(p + 0));

    // i = 1
    printf("p[1] = *(p + 1) = *(100 + 1) = *(101) = %c\n", *(p + 1));

    // i = 2
    printf("p[2] = *(p + 2) = *(100 + 2) = *(102) = %c\n", *(p + 2));

    return 0;
}
```

---

### Output:

```
p[0] = *(p + 0) = *(100 + 0) = *(100) = A
p[1] = *(p + 1) = *(100 + 1) = *(101) = B
p[2] = *(p + 2) = *(100 + 2) = *(102) = C
```

---

### Key point:

```
p[i]  →  *(p + i)

p     →  address (100)
i     →  offset
p + i →  புதிய address
*     →  அந்த address-ல் உள்ள value எடு
```

---

### எளிமையாக:

```
p[0]  →  *(100 + 0)  →  100-ல் உள்ளது  →  'A'
p[1]  →  *(100 + 1)  →  101-ல் உள்ளது  →  'B'
p[2]  →  *(100 + 2)  →  102-ல் உள்ளது  →  'C'
```

> `p` நகரவில்லை — `i` மட்டும் மாறி **offset** மாறுகிறது.
