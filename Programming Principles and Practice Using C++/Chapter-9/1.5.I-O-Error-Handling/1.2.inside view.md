## `fill_vector` ல் உள்ள stream state சோதனை விளக்கம்

`for` loop முடிந்த பிறகு, ஏன் loop நின்றது என்று கண்டுபிடிக்க இரண்டு சோதனைகள் நடக்கின்றன.

---

### 1️⃣ `if (input_stream.eof())`

```cpp
if (input_stream.eof())
{
    std::cout << "[INFO] End of file reached\n";
    return;
}
```

**என்ன செய்கிறது:**
- File முழுவதும் படித்து முடிந்துவிட்டால் (EOF = End Of File), loop தானாக நிற்கும்
- இந்த சோதனை அதை கண்டுபிடித்து **சாதாரணமாக return** செய்கிறது
- எந்த error-உம் இல்லை, எல்லா numbers-உம் படிக்கப்பட்டுவிட்டன

**எப்போது நடக்கும்:** `numbers.txt` இல் `1 2 3 4 5` மட்டும் இருந்தால்

---

### 2️⃣ `if (input_stream.fail())`

```cpp
if (input_stream.fail())
{
    input_stream.clear();        // failbit ஐ அழி
    char character {};
    input_stream >> character;   // அடுத்த character படி
```

**என்ன செய்கிறது:** Integer படிக்க முடியாமல் loop நின்றது — ஒரு character வந்துவிட்டது. அது என்ன என்று சோதிக்கிறது.

---

#### 2a — Terminator கிடைத்தால் ✅

```cpp
    if (character == terminator)  // '*' தானா?
    {
        std::cout << "[INFO] Terminator found: " << character << '\n';
        return;  // சாதாரணமாக முடி
    }
```

**எப்போது நடக்கும்:** `1 2 3 * 4 5` — `*` வரும்போது loop நிற்கும், இது valid terminator

---

#### 2b — வேற ஏதாவது வந்தால் ❌

```cpp
    input_stream.unget();                    // character ஐ திரும்ப வை
    input_stream.clear(std::ios::failbit);   // failbit மீண்டும் set செய்
    throw std::runtime_error("Unexpected character in input");
```

**எப்போது நடக்கும்:** `1 2 3 X 4` — `X` என்பது terminator-உம் இல்லை, integer-உம் இல்லை → **Exception**

---

### ஒட்டுமொத்த Flow

```
Loop நிற்கும்
      │
      ├── eof() true?  ──→ File முடிந்தது → return ✅
      │
      └── fail() true? ──→ Character படி
                                │
                                ├── '*' ஆ? ──→ Terminator → return ✅
                                │
                                └── வேறு ──→ Exception ❌
```

சுருக்கமாக: loop நின்றதற்கான **காரணத்தை கண்டுபிடித்து**, அது valid-ஆ இல்லையா என்று முடிவு செய்கிறது.

-------------------------------

``if (input_stream.fail())
{
    input_stream.clear(); `எதனால் தோல்வி ஏற்பட்டது என்னும் தகவல் `input_stream.fail()`இது உள்ளே இருக்குமா அதை கிளியர் செய்த பிறகு தான் `input_stream.clear();` நம்மால் அடுத்ததை read செய்ய முடியுமா? like `char character {};
    input_stream >> character;   // அடுத்த character படி`?`


    ## ஆம், சரியாக புரிந்துகொண்டீர்கள்!

### `fail()` என்பது ஒரு **flag** மட்டுமே

`input_stream.fail()` என்பது உள்ளே எந்த தகவலும் வைத்திருக்காது — அது வெறும் **"failbit set ஆனதா இல்லையா"** என்று சொல்லும் ஒரு boolean சோதனை மட்டுமே.

தோல்விக்கான காரணம் stream-உக்கு தெரியாது — நமக்கும் தெரியாது.

---

### Stream ஒரு **traffic signal** மாதிரி

```
🔴 failbit set → stream "blocked" நிலையில் உள்ளது
                 எந்த read operation-உம் வேலை செய்யாது
                 >> operator உடனே skip ஆகிவிடும்

input_stream.clear() → 🟢 signal மாறுகிறது
                        இப்போது read செய்யலாம்
```

---

### Clear செய்யாமல் என்னாகும்?

```cpp
// failbit set ஆன நிலையில்:
char character {};
input_stream >> character;  // ❌ வேலை செய்யாது!
                            // character மாறாமலே இருக்கும்
                            // stream-ஐ skip செய்துவிடும்
```

---

### Clear செய்த பிறகு:

```cpp
input_stream.clear();       // failbit அழிக்கப்படுகிறது
char character {};
input_stream >> character;  // ✅ வேலை செய்யும்
                            // stream-இல் உள்ள அடுத்த
                            // character படிக்கப்படும்
```

---

### முக்கியமான புள்ளி

`clear()` **stream buffer-ஐ** தொடவே தொடாது — buffer-இல் உள்ள data அப்படியே இருக்கும். வெறும் **status flags மட்டுமே** reset ஆகும்.

```
Buffer:  [ 1 ][ 2 ][ * ][ 3 ]   ← இது மாறவே மாறாது
Flags:   failbit=1 → clear() → failbit=0
```

எனவே clear() செய்த உடனே `*` என்ற character buffer-இல் காத்திருக்கும், நாம் படிக்கலாம்.

### ஏன் `eof()` மற்றும் `fail()` இரண்டும் true?

இது C++ stream-இன் இயல்பான நடத்தை —

EOF-ஐ படிக்க முயன்றால் **eofbit மட்டுமல்ல, failbit-உம்** சேர்த்து set ஆகும்.

```
file: 1 2 3 [EOF]
              ↑
         இதை படிக்க முயன்றால்:
         eofbit = 1
         failbit = 1  ← இரண்டும் சேர்த்து set ஆகும்
```

### ஏன் `fail(): 1` என்று வருகிறது?

EOF-ஐ படிக்க **முயன்றது** — அதுவே காரணம்.

---

### என்ன நடந்தது என்று பாருங்கள்:

```
file: 123  2345  456  12  [EOF]
```

```
loop iteration 1: 123  படித்தது ✅
loop iteration 2: 2345 படித்தது ✅
loop iteration 3: 456  படித்தது ✅
loop iteration 4: 12   படித்தது ✅
loop iteration 5: [EOF] படிக்க முயன்றது ❌
                   ↑
              integer கிடைக்கவில்லை
              eofbit  = 1
              failbit = 1  ← இங்கே set ஆகிறது
```

---

### Core காரணம்:

> `failbit` என்பது **"நான் படிக்க முயன்றேன், ஆனால் valid data கிடைக்கவில்லை"** என்று சொல்கிறது.

EOF-இல் integer படிக்க முயன்றால் — data இல்லை, எனவே **failbit தானாக set ஆகும்.**

```
eofbit  = "file முடிந்தது"
failbit = "படிக்க முயன்றேன், data இல்லை"

இரண்டும் ஒரே நேரத்தில் நடக்கும் — EOF hit ஆனால்
```

### நம் code-இல் ஏன் பிரச்சனை இல்லை?

```cpp
if (input_stream.eof())   // ← இதை முதலில் சோதிக்கிறோம்
{
    return;  // fail() true ஆனாலும், eof() பார்த்து முதலே return
}

if (input_stream.fail())  // ← இது EOF case-இல் வரவே வராது
```

`eof()` check முதலில் இருப்பதால், EOF-இன் போது `fail()` block-க்கு போவதே இல்லை. அதனால் சரியாக வேலை செய்கிறது.
